## 摘要
上下文学习（ICL）使语言模型无需更新权重即可通过演示执行新任务。然而，每次 ICL 推理都需要处理完整的示例集，导致部署效率低下，且 ICL 的运作机制尚不完全明确。先前的工作将 ICL 压缩为从特定层或位置提取的固定激活向量，但这些与输入无关的干预在输出依赖于与输入的细粒度交互的复杂任务上表现不佳。通过分析 ICL 的前向传播，我们证明了每个注意力头的输出都是其上下文掩码对应项的仿射变换，并且该变换的参数对于给定任务的样本而言在经验上是稳定的。基于此，我们引入了任务算子（Task Operator, TO），它将这种变换重现为对注意力输出投影的解析推导更新。在词汇、算法和推理任务中，TO 在现有方法中实现了最佳的整体性能，并大幅缩小了零样本推理与 ICL 之间的差距。我们进一步证明，提取的知识集中在跨层和跨位置的任务特定稀疏电路中，并且对不相交的演示批次进行算子平均化，能够在不扩展上下文窗口的情况下实现有效的多样本扩展。我们的代码可在 https://github.com/gzxiong/task_operator 获取。

## Abstract
In-context learning (ICL) enables language models to perform new tasks from demonstrations without weight updates. However, every ICL inference requires processing the full set of examples, resulting in inefficient deployments, and how ICL works mechanistically is not fully understood. Prior work compresses ICL into fixed activation vectors extracted from specific layers or positions, but these input-independent interventions fail on complex tasks where the output depends on fine-grained interactions with the input. By analyzing the ICL forward pass, we show that each attention head's output is an affine transformation of its context-masked counterpart, and that the parameters of this transformation are empirically stable across samples for a given task. Building on this, we introduce Task Operator (TO), which replays this transformation as an analytically derived update to the attention output projection. Across lexical, algorithmic, and reasoning tasks, TO achieves the best overall performance among prior methods and substantially narrows the gap between zero-shot inference and ICL. We further show that the extracted knowledge concentrates in a task-specific sparse circuit across layers and positions, and that averaging operators from disjoint demonstration batches enables effective many-shot scaling without expanding the context window. Our code is available at https://github.com/gzxiong/task_operator.
