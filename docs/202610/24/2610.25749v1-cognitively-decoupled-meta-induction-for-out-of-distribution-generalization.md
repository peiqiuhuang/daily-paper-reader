## 摘要
上下文学习（ICL）通过以示范（demonstrations）为条件来处理下游任务。该范式严重依赖于查询与示范之间的基于邻近度的匹配，从而限制了其分布外（OOD）性能。为了实现更好的泛化，基于规则的归纳推理在直接回答之前推导任务级规律（我们称之为任务级归纳表示，即TIR）。然而，现有方法在多样化任务中缺乏可泛化的归纳能力。受元学习的启发，我们提出了用于通用任务上基于TIR的归纳推理的认知解耦元归纳（CoDI）方法。CoDI包含一个用于查询盲TIR归纳的认知解耦框架，以及一个用于跨任务归纳器优化的双循环元归纳学习方法。实验表明，CoDI在五个域内（ID）和分布外（OOD）基准测试上实现了显著的性能提升，并且在推理时无需显式归纳即可保持OOD增益。代码已发布于 https://github.com/Yuqian-Wang2277/codi-meta-induction。

## Abstract
In-context learning (ICL) tackles downstream tasks conditioned on demonstrations. This paradigm relies heavily on neighbor-based matching between queries and demonstrations, limiting out-of-distribution (OOD) performance. For better generalization, rule-based inductive reasoning derives task-level regularities, which we term task-level inductive representations (TIR), before directly answering. However, existing methods lack generalizable inductive ability across diverse tasks. Inspired by meta-learning, we propose Cognitive-Decoupling meta-Induction (CoDI) for TIR-based inductive reasoning on general tasks. CoDI comprises a Cognitive-Decoupling Framework for query-blind TIR induction, and a Dual-Loop Meta-Inductive Learning method for cross-task inducer optimization. Empirically, CoDI achieves substantial performance gains on five ID and OOD benchmarks, and preserves OOD gains without explicit induction at inference. Code is available at https://github.com/Yuqian-Wang2277/codi-meta-induction.
