## 摘要
大语言模型（LLM）工作流的性能往往取决于如何选择少量上下文示例来引导模型在任务上的表现。现有方法通过利用成功的推理路径增强提示词来改进这一过程，但其示例选择通常依赖于随机采样或基于指标的排序，忽略了任务的语义结构。我们提出了 ClusterFewshot，这是一种结合语义结构化与效用感知评分的策略，旨在构建具有代表性且高效的少样本示例集。在基于 DSPy 的流水线中进行评估表明，ClusterFewshot 在多个基准测试中显著降低了优化成本，同时在独立的提示词调优和混合提示词-权重优化中，其准确性均优于现有的基于引导（bootstrap-based）的方法。

## Abstract
The performance of large language model (LLM) workflows often depends on selecting a small set of in-context demonstrations to guide model behavior on new tasks. Recent methods improve this process by augmenting prompts with successful reasoning paths. However, their demonstration selection relies on random sampling or metric-based rankings, overlooking the semantic structure of the task. We propose ClusterFewshot, a strategy that combines semantic structuring with utility-aware scoring to construct representative and effective few-shot demonstration sets. Evaluated within DSPy-based pipelines, ClusterFewshot substantially reduces optimization cost across multiple benchmarks, while consistently improving accuracy relative to prior bootstrap-based methods in both standalone prompt tuning and hybrid prompt-weight optimization.

### 1. 核心问题与研究动机
*   **背景**：大语言模型（LLM）工作流（如 DSPy 框架）的性能高度依赖于“少样本提示”（Few-shot prompting）中示例的选择。
*   **痛点**：现有的引导式（Bootstrap-based）方法（如 BFRS、MIPROv2）在选择示例时，主要依赖随机搜索或简单的指标排序，完全忽略了任务数据的**语义结构**。这导致示例集缺乏代表性，且优化过程效率低下、成本高昂。
*   **目标**：通过引入语义感知机制，构建更具代表性、更高效的少样本示例集，从而提升模型在复杂推理任务中的表现。

### 2. 方法论：ClusterFewshot
*   **核心思想**：将示例选择视为一个在语义空间上的结构化优化问题，结合“语义聚类”与“效用评分”。
*   **关键流程**：
    1.  **引导式训练集构建**：运行 LLM 程序，保留成功的推理路径作为候选示例池。
    2.  **语义聚类**：利用预训练的句子编码器（如 `gtr-t5-base`）对示例进行嵌入，通过 K-means 聚类（利用 Silhouette 分数自动确定 K 值）划分语义空间。
    3.  **效用感知评分**：在验证集上进行“单样本评估”（One-shot evaluation），计算每个候选示例对模型性能的贡献度。
    4.  **混合采样策略**：结合“全局 Top-k”和“聚类代表性采样”，平衡示例的性能与语义多样性。
    5.  **最终编译**：在验证集上评估候选集，选择最优组合。

*   **数据集**：GSM8K（数学推理）、HotPotQA（多跳问答）、Iris（分类任务）。
*   **对比方法**：主要对比了 BootstrapFewShotRS (BFRS) 和 MIPROv2。
*   **场景**：涵盖了独立提示词调优、混合提示词-权重优化（BetterTogether 框架）以及 ReAct 代理（Agentic）设置。

### 6. 主要结论与发现
*   **性能提升**：ClusterFewshot 在所有基准测试中均表现出优于 BFRS 和 MIPROv2 的准确率。

### 7. 优点
*   **语义驱动**：将聚类引入示例选择，有效解决了随机采样带来的语义覆盖不足问题。
*   **高效性**：通过“单样本评估”替代了昂贵的子集搜索，大幅降低了计算开销。
*   **模块化**：方法与模型无关，可轻松适配不同的 LLM 和嵌入模型。

### 8. 不足与局限
*   **依赖嵌入质量**：若预训练嵌入模型无法捕捉任务语义，聚类效果会大打折扣。
*   **超参数敏感**：Silhouette 评分最大化引入了额外的超参数（K 值），在大规模数据集上可能增加预处理开销。
*   **验证集依赖**：One-shot 评分依赖于验证集，若验证集本身不具代表性，可能导致过拟合。
*   **动态场景限制**：目前主要针对静态数据集，对于流式数据或动态任务的适应性仍需进一步研究。
