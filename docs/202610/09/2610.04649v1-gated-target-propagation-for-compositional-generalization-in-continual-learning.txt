ABSTRACT 

Continual learning is typically framed as acquiring new knowledge without catas-trophically forgetting previous tasks. However, a flexible continual learner should also be able to reuse and recombine previously acquired knowledge to rapidly solve novel task compositions. We introduce Gated Target Propagation (GaTaP), a continual learning algorithm in which task-specific gating variables—learned through a closed-form inner loop update—selectively suppress or enhance net-work modules. Network parameters are learned in a slower timescale outer loop, using the same local difference target propagation error signal as is used for adapt-ing gating variables. We provide tractable experiments on class-incremental learn-ing scenarios for both multilayer perceptron and convolutional network architec-tures. We show strong performance retention on previously learned tasks, as well as compositional generalization to unseen tasks, achieved through few-shot gain adaptation at inference. We analyze learned gating patterns and find that related tasks exhibit similar gating patterns, suggesting that inferred gates capture mean-ingful, reusable task structure. Overall, GaTaP provides a powerful framework for jointly ameliorating catastrophic forgetting and enabling few-shot compositional generalization in neural network models. 

1 INTRODUCTION 

Continual learning aims to sequentially train models on new experiences while preserving knowl-edge acquired from previous ones. Neural networks, however, often suffer from catastrophic forget-ting : learning a new task can overwrite parameters that are important for earlier tasks, causing their performance to deteriorate (McCloskey & Cohen, 1989; French, 1999; Goodfellow et al., 2013). A large body of work addresses this problem through regularization (Kirkpatrick et al., 2017; Zenke et al., 2017), replay (Lopez-Paz & Ranzato, 2017; Rebuffi et al., 2017; Buzzega et al., 2020), or architectural mechanisms that isolate task-specific parameters (Rusu et al., 2016; Fernando et al., 2017; Mallya & Lazebnik, 2018; Serr` a et al., 2018; Veniat et al., 2021; Rajasegaran et al., 2020). While these approaches can improve retention, continual learning within these studies is typically evaluated only through the ability to remember previously learned tasks. We argue that remembering alone is not sufficient for flexible continual learning. A capable learner should also be able to reuse and recombine previously acquired knowledge to solve novel tasks. For example, after learning to discriminate between MNIST (LeCun et al., 2010) digits 3 and 4, and between 5 and 6, a model should ideally be able to adapt to unseen combinations such as 3 vs. 6 or 4

vs. 5 without relearning the underlying representations. This connects continual learning with com-positional generalization : the ability to solve novel combinations of previously encountered task components (Lake & Baroni, 2017; Elmoznino et al., 2025). From this perspective, continual learn-1arXiv:2610.04649v1 [cs.LG] 3 Oct 2026 ing should not only preserve knowledge, but organize it into reusable computational components that can be rapidly recombined. We introduce GaTaP (Ga ted Ta rget Propagation), a learning framework designed to jointly ad-dress catastrophic forgetting and compositional generalization. GaTaP represents shared knowledge through a collection of subnetworks whose contributions are modulated by task-specific multiplica-tive gain variables, denoted by Γ. These gains act as soft gates that activate or inactivate subnetworks depending on the current task. The same shared weights can therefore support different tasks through different configurations of Γ, providing a mechanism for selective plasticity and knowledge reuse. Training GaTaP networks is a form of supervised meta-learning. For a given task, an inner opti-mization loop selects a gain vector Γ that gates subnetworks (fixed for inner loops), while an outer loop optimization updates subnetwork parameters for an ensemble of tasks, each with their own 

Γ. This separates fast task adaptation from slow, shared-weight learning through a bilevel opti-mization scheme analogous to the inference and parameter-update steps of variational expectation maximization (VEM) (Bernardo et al., 2003). Crucially, optimization is carried out with difference target propagation (Lee et al., 2015). Rather than propagating an output gradient through the entire network, target propagation infers local target states for individual layers, providing a layer-wise credit-assignment mechanism that is local (Bredenberg et al., 2023), compatible with gated modular computation, and aligned with biologically plausible learning (Bengio, 2014). The use of this local learning rule has a distinctive implication for the inner loop: learning optimal gain parameters for a new task reduces to a series of least square problems which can be solved in closed form, enabling adaptation at inference without gradient descent .The compositional generalization capabilities of GaTaP thus manifest at inference time , once the outer loop training is complete and all shared weights are frozen. In this setting, adaptation to either previously learned or novel tasks is performed solely by inferring a new gain configuration Γ from a small support set (a simple closed-form evaluation). Consequently, success on an unseen task directly tests whether the model has acquired reusable computational components: no modification of the shared representation is allowed during adaptation. Our main contributions are: • We formulate continual learning as a joint problem of retention and composition , requiring learned knowledge to remain both stable and reusable for unseen task combinations. • We introduce GaTaP, which separates fast, task-specific routing through sparse gain infer-ence from slower, shared representation learning through target propagation. • We derive a closed-form, sparse update for the task-specific gains and a probabilistic target-inference rule that extends from multilayer perceptron to convolutional architectures. • We show experimentally that GaTaP retains previously learned tasks while adapting to unseen task compositions with frozen shared weights, and that related tasks exhibit similar inferred gating patterns. 

2 RELATED WORK 

Continual learning. Continual-learning methods are commonly grouped into regularization-, replay-, and architecture-based approaches. Regularization methods constrain updates to parame-ters considered important for previous tasks, as in Elastic Weight Consolidation (EWC) (Kirkpatrick et al., 2017) and Synaptic Intelligence (SI) (Zenke et al., 2017). Replay-based approaches instead revisit stored or generated examples from previous tasks, including GEM (Lopez-Paz & Ranzato, 2017), A-GEM (Chaudhry et al., 2018), iCaRL (Rebuffi et al., 2017), and Dark Experience Re-play (Buzzega et al., 2020). While effective at mitigating catastrophic forgetting, these approaches primarily preserve previous knowledge rather than explicitly organizing it into computational com-ponents that can be recombined for novel tasks. 

Modular networks and task-dependent routing. Architectural approaches reduce interference by assigning different parameters or computational pathways to different tasks. Progressive Neural Networks (Rusu et al., 2016) add and freeze task-specific columns, whereas PathNet (Fernando et al., 2017), PackNet (Mallya & Lazebnik, 2018), and Hard Attention to the Task (Serr` a et al., 22018) select, reserve, or protect subsets of a larger network. In many such approaches, catastrophic forgetting is mitigated partly by construction: previously allocated parameters are frozen or future updates are restricted according to a predefined routing or capacity-allocation mechanism. While effective at reducing interference, this shifts an important part of the learning problem—determining which components are relevant to a new task and should therefore be reused or protected—into the architecture or training rules. Particularly related to our work, RPS-Net (Rajasegaran et al., 2020) progressively searches for task-specific paths through a modular network while encouraging the reuse of previously selected paths, thereby enabling forward transfer and reducing interference. Veniat et al. (Veniat et al., 2021) further propose Modular Networks with Task-Driven Priors (MNTDP), in which tasks are represented as compositions of reusable modules. A data-driven prior restricts architecture search to perturbations of paths associated with related previous tasks, enabling efficient transfer and improved scaling to long task sequences. GaTaP shares the motivation of modular reuse but treats pathway selection itself as an inference problem. Rather than prescribing a discrete architecture or a fixed rule specifying which subnet-works should be protected or recruited, GaTaP represents task relevance through sparse multiplica-tive gains Γ inferred directly from a support set. These gains determine which shared subnetworks contribute to the current task and, consequently, which components participate strongly in learn-ing. Thus, the routing and selective-plasticity rules are encoded in learned task-dependent variables rather than imposed externally. At test time, the same mechanism allows new gain configurations to be inferred for previously unseen task compositions while all shared weights remain frozen. 

Compositional generalization. Compositional generalization concerns the ability to systemati-cally recombine previously learned components to solve novel task combinations (Zhou et al., 2024; Lake & Baroni, 2017; Lake et al., 2015). Although modular continual-learning methods naturally promote parameter reuse, transfer to a new task does not necessarily imply compositional gener-alization (Mittal et al., 2022; 2025). We explicitly evaluate whether components acquired during sequential learning can be recombined without modifying the shared representation. For example, after learning to discriminate between MNIST (LeCun et al., 2010) digits 3 and 4, and between digits 5 and 6, GaTaP is evaluated on unseen combinations such as 3 vs. 6 by inferring only a new gating configuration. This provides a direct test of whether continual learning has produced reusable computational structure rather than merely preserved task-specific solutions. 

Target propagation and local credit assignment. Target propagation provides an alternative to standard backpropagation by assigning desired activation states, or targets , to intermediate lay-ers (Bengio, 2014; Lee et al., 2015). Difference Target Propagation (Lee et al., 2015), for instance, propagates corrected activation targets through learned approximate inverses rather than propagat-ing only loss gradients. GaTaP builds on difference target propagation by deriving hidden targets through local Gaussian conditioning under a linearized network model, yielding Kalman-gain up-dates related to Gauss-Newton target methods (Meulemans et al., 2020).

4 EXPERIMENTAL SETUP 

Our experiments are designed to test the two central claims of the proposed framework: whether GaTaP can retain knowledge acquired sequentially, and whether the resulting shared components can be recombined to solve novel task compositions. We therefore focus on controlled class-incremental classification experiments in which both retention and compositional reuse can be measured directly. 

Datasets and architectures. We evaluate GaTaP on MNIST, CIFAR-10, and CIFAR-100, pro-gressively increasing the visual complexity and number of classes. MNIST experiments use a feed-forward gated network, whereas CIFAR-10 and CIFAR-100 use convolutional architectures. The main experiments are formulated as sequences of binary classification tasks. Additional preliminary multi-class experiments are reported in Supplemental Figure S3; these results are intended as an initial test of scalability beyond the binary setting, and a more systematic multi-class evaluation is left for future work. Architecture and hyperparameter details are provided in Appendix A.5. 

Class-incremental task construction. All main experiments use the class-incremental learning setting: tasks are presented sequentially, and the original class identities are preserved throughout learning. For example, an MNIST training stream may sequentially require discrimination between digits 1 and 2, 3 and 4, 5 and 6, and 7 and 8. The model has access only to the current task data during its corresponding training stage. We distinguish between seen tasks , which are presented during sequential training, and unseen compositional tasks , which recombine classes encountered in different training tasks. For instance, after learning 1 vs. 2 and 3 vs. 4, tasks such as 1 vs. 4 or 2 vs. 

3 require a new combination of previously acquired components. 

Training and evaluation protocol. For each task Tj , its data are divided into a support set Sj

and a disjoint query set Qj . During training, Sj is used to infer the task-specific gains Γ⋆j , while 

Qj is used to update the shared weights W through target propagation. After the complete task sequence, all shared weights are frozen. Evaluation on both seen and unseen tasks is then performed by inferring only a new gain configuration from the task support set and measuring performance on its query set. Consequently, performance on unseen compositions cannot be attributed to further learning of the shared representation. 

Evaluation criteria. Retention is measured by the final accuracy on previously seen tasks. Com-positional generalization is measured by query accuracy on unseen class combinations with the shared weights fixed. We additionally analyze the cosine similarity between inferred gain vectors to determine whether tasks sharing classes recruit similar computational routes, and vary the support-set size to evaluate few-shot inference of gain variables. GaTaP-trained models were compared to equivalent architectures trained with backpropagation and EWC (with code adapted from (Chua et al., 2026)).

Structure of the inferred gating configurations. We next investigated whether the inferred task-specific gains encoded meaningful relationships between tasks. If the gains identified reusable com-putational components, then tasks sharing classes should be expected to recruit more similar routes than unrelated tasks. We therefore computed the cosine similarity between the final gain configura-tions of different task pairs and grouped them according to their degree of class overlap. As shown in Fig. 3, Γ similarity tracked task overlap closely on MNIST (near-identical for matching tasks, near-zero for disjoint ones), and a similar trend was observed on CIFAR-10. This indicates that related tasks reuse related computational pathways, while unrelated tasks recruit more distinct ones. 

6 DISCUSSION AND LIMITATIONS 

In this study we have introduced gated target propagation (GaTaP), a learning algorithm capable of both preventing catastrophic forgeting and enabling compositional generalization through a shared mechanism: the rapid optimization of network gains Γ across epochs. Our method can be seen as a generalization of difference target propagation (Lee et al., 2015), as well as other methods that use Kalman-style error corrections to provide closed-loop modification of internal network states prior to learning. Previous work, generally restricted to additive —as opposed to our multiplicative —corrections, have shown that this form of closed-loop control can provide benefits for learning stability, particularly in chaotic dynamical systems (Sa˘ gtekin et al., 2026; Kaleb et al., 2024; Sussillo & Abbott, 2009). Our work builds on these methods by showing how similar error-based feedback signals can be used in concert with gain modulation mechanisms to enable continual learning and compositional generalization. Collectively, these studies demonstrate that error signals used for both control and learning can provide important improvements relative to standard backpropagation-based methods. Interestingly, methods closely related to GaTaP, such as difference target propagation and control-theoretic learning methods, have been proposed as models of learning and synaptic plasticity in the brain (Podlaski & Machens, 2020; Gilra & Gerstner, 2017; Alemi et al., 2018). While our method relies on biologically implausible operations to compute feedback errors (e.g. calculating a Kalman gain matrix), previous work has demonstrated that feedback projections can still enable learning when they adapt through local plasticity to dynamically approximate the analytically optimal feed-back signal (Lee et al., 2015; Meulemans et al., 2021). Therefore, relating GaTaP more concretely to models of learning in the brain remains a promising direction for future work. The present study nevertheless has several limitations. First, computing the Kalman-style target update involves Jacobian–covariance operations that become expensive in larger networks. Our convolutional network implementation uses a diagonal approximation (Appendix A.4) to make this 9computation tractable, introducing a trade-off between inference fidelity and computational effi-ciency. Methods to approximate or amortize the computation of feedback errors may greatly in-crease the computational efficiency of our method. Finally, the current experiments focus on static visual tasks. Extending the framework to temporal models, larger architectures, and more complex task compositions will be important for assessing its generality. 

7 CONCLUSION 

We have introduced GaTaP, a continual-learning framework that jointly addresses knowledge re-tention and compositional reuse. The method separates fast, task-specific adaptation from slower, shared learning: sparse, multiplicative gains infer which subnetworks are relevant to a task, while target propagation updates the shared weights through local target states. After continual train-ing, the shared weights remain fixed and both previously learned and unseen task compositions are solved through gain inference alone, a simple closed form update. Experiments on MNIST, CIFAR-10, and CIFAR-100 show that GaTaP retains previously acquired knowledge, recombines learned components for novel tasks, and produces gating patterns that reflect task structure. These results suggest that continual learning and compositional generalization can be jointly enabled through a shared learning architecture based on rapidly reconfiguring multiplicative gains. A.4 CONVOLUTIONAL NEURAL NETWORKS 

CNNs are needed to evaluate GaTaP on realistic image tasks, where spatial structure and local feature extraction are essential. Extending the framework to convolutions tests whether the same gating and target-inference mechanisms remain effective beyond fully connected networks. Gating in a convolutional layer could be accomplished by assigning one gate per output channel, applying the same gate to all spatial locations , or a separate gate could be assigned for each channel at each spatial position (see Supplemental Figure S1b for a schematic). We begin with the “spatial gating” version, before introducing the “channel gating” version.
