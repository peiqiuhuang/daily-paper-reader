## 摘要
本文研究了随机多层优化问题，其目标函数是多个平滑非凸函数的嵌套组合。我们假设仅能获取每一层函数值及其梯度的随机估计。由于嵌套结构的存在，获取整体梯度的精确估计具有挑战性。为此，我们采用了一种基于动量的估计器，利用小批量（mini-batches）来跟踪每一层的函数值，进而构建动量梯度估计器。我们证明了在寻找 $\mathcal{O}(ε^{-4})$ 阶 $\epsilon$-平稳点时，该方法达到了最优样本复杂度，且避免了现有文献中常用的强平均平滑性假设。此外，通过引入归一化技术，我们在无需依赖问题相关常数来设置超参数的情况下，实现了相同的收敛速率。为了在不使用小批量的情况下达到最优速率，我们进一步开发了一种无批处理方法，该方法结合了一阶近似和用于函数值估计的截断技术。最后，我们通过风险厌恶投资组合优化和分层倾斜经验风险最小化实验，验证了所提方法的有效性。

## Abstract
This paper investigates stochastic multi-level optimization where the objective is a nested composition of several smooth non-convex functions. We assume that only stochastic estimates of the gradient and function values for each level are accessible. Consequently, obtaining an accurate estimate of the overall gradient is challenging due to the nested structure. To address this, we employ a momentum-based estimator with mini-batches to track the function values of each level, which are subsequently used to construct momentum gradient estimators. We establish an optimal sample complexity of $\mathcal{O}(ε^{-4})$ for finding an $ε$-stationary point, avoiding the stronger average smoothness assumption commonly relied upon in prior literature. Furthermore, by employing a normalization technique, we attain the same rate without requiring problem-dependent constants to set hyperparameters. To achieve the optimal rate without mini-batches, we further develop a batch-free method that incorporates a first-order approximation and a clipping technique for function value estimation. Finally, we validate the effectiveness of our proposed methods through experiments on risk-averse portfolio optimization and hierarchical tilted empirical risk minimization.
