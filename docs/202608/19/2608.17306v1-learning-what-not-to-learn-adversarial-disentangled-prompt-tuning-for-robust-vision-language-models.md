## 摘要
虽然对抗提示微调可以高效地增强视觉语言模型的鲁棒性，但我们发现现有方法加剧了在已见类别上的鲁棒泛化过拟合，导致随着训练的进行，模型在未见类别的对抗样本上的性能迅速下降。我们通过实验发现，这种退化源于模型倾向于学习伪鲁棒特征（即不可泛化的捷径）。为了缓解这一问题，我们提出了 ADAPT（对抗解耦提示微调），这是一个遵循“学会不学什么”理念的鲁棒提示微调框架。具体而言，ADAPT 使用一种双提示机制，包含一个目标提示和一组诱饵提示池。在训练过程中，诱饵提示被引导去捕获多样化的伪鲁棒特征，而目标提示则被约束为在嵌入空间中与诱饵提示正交，从而学习鲁棒特征。通过将鲁棒特征与伪鲁棒特征解耦，ADAPT 有效地防止了鲁棒泛化过拟合。我们进一步提供了一项分析，表明正交损失限制了未见类别上伪鲁棒特征偏移的影响，从而提供了测试误差保证。实验结果表明，ADAPT 显著提高了目标提示在未见类别上的鲁棒性。代码可在 https://github.com/cheny02/ADAPT-ACMMM2026 获取。

## Abstract
While adversarial prompt tuning can enhance robustness of vision-language models efficiently, we find that existing methods aggravate robust generalization overfitting on seen classes, leading to a rapid degradation in performance against adversarial examples of unseen classes as training progresses. We empirically identify that this degradation stems from the tendency of the model to learn pseudo-robust features (i.e., non-generalizable shortcuts). To mitigate this, we propose ADAPT (Adversarial Disentangled Prompt Tuning), a robust prompt tuning framework following the philosophy of ``Learning What Not to Learn''. Specifically, ADAPT uses a dual-prompt mechanism with a target prompt and a pool of decoy prompts. During training, the decoy prompts are guided to entrap diverse pseudo-robust features, while the target prompt is constrained to be orthogonal to the decoys in the embedding space to learn robust features. By disentangling the robust features from the pseudo-robust features, ADAPT effectively prevents robust generalization overfitting. We further provide an analysis showing that the orthogonal loss bounds the effect of shifts in pseudo-robust features on unseen classes, yielding a testing error guarantee. Empirically, extensive experiments demonstrate that ADAPT substantially improves the robustness of the target prompt on unseen classes. The code is available at https://github.com/cheny02/ADAPT-ACMMM2026.

### 1. 核心问题与整体含义
*   **研究背景**：视觉语言模型（VLM，如 CLIP）虽然在零样本学习上表现优异，但极易受到对抗样本的攻击。现有的防御手段如对抗训练（AT）虽然有效，但全参数微调成本过高，因此研究者转向了参数高效的“对抗提示微调（Adversarial Prompt Tuning）”。
*   **核心问题**：作者发现现有的对抗提示微调存在**“鲁棒泛化过拟合（Robust Generalization Overfitting）”**现象。即模型在训练过程中，在可见类别（Base classes）上的鲁棒性持续提升，但在未见类别（New classes）上的鲁棒性却迅速下降。
*   **研究动机**：这种退化是因为模型学习到了“伪鲁棒特征（Pseudo-robust features）”，即仅在特定训练集上有效的非泛化“捷径（Shortcuts）”，而非真正的语义鲁棒特征。

### 2. 方法论
*   **核心思想**：遵循“学会不学什么（Learning What Not to Learn）”的哲学，通过**双提示机制**将鲁棒特征与伪鲁棒特征进行解耦。
*   **关键技术细节**：
    *   **双提示机制**：引入一个**目标提示（Target Prompt）**用于最终推理，以及一个**诱饵提示池（Decoy Prompt Pool）**。
    *   **诱饵提示（Decoy Prompt）**：作为“捷径陷阱”，通过最小化分类损失和最大化与手工语义锚点的差异（Dissimilarity Loss），强迫其吸收那些非语义的、不可泛化的伪鲁棒特征。
    *   **目标提示（Target Prompt）**：通过**正交损失（Orthogonal Loss）**约束其在嵌入空间中与诱饵提示正交，从而被迫避开捷径，专注于学习真正的鲁棒语义特征。同时使用语义损失（Semantic Loss）使其保持与预训练知识的一致性。
*   **算法流程**：采用交替优化策略。在每轮迭代中，先生成对抗样本，然后更新随机采样的诱饵提示以捕获捷径，最后在正交约束下更新目标提示。

### 3. 实验设计
*   **数据集**：涵盖 11 个标准数据集（如 ImageNet, Caltech101, OxfordPets, Food101 等）以及 4 个 ImageNet 的分布外（OOD）变体（V2, Sketch, A, R）。
*   **实验场景**：
    1.  **对抗基类到新类泛化**：在基类训练，在新类测试。
    2.  **对抗少样本分类**：1-shot, 4-shot, 16-shot 场景。
    3.  **跨数据集泛化**：在 ImageNet 训练，在其他 10 个数据集测试。
    4.  **对抗领域泛化**：测试模型对分布偏移的鲁棒性。
*   **对比方法（Benchmarks）**：Zero-shot TeCoA（鲁棒微调代表）、APT（文本提示微调）、FAP（多模态提示微调）。
*   **攻击模型**：PGD-100, CW, 以及最强的集成攻击 AutoAttack (AA)。
