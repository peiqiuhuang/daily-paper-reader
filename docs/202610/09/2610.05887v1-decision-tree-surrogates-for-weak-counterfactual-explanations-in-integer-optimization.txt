The concept of counterfactual explanations (CEs) has recently gained increasing at-tention for deriving explanations of mathematical optimization problems. For a given problem, a counterfactual is an ideally minimal change in the mutable problem param-eters such that an optimal solution of the changed problem exists fulfilling some desired criterion. It was shown that so-called weak CEs can be calculated by solving a com-putationally demanding bilevel optimization problem, which is Σ p

> 2

-complete if decision variables and mutable parameters are restricted to integers. Hence, the known exact solution methods are expected to fail on practically relevant problem sizes. In this work we derive a fast heuristic algorithm by approximating the feasible region of the CE problem with a decision tree for which CEs can be calculated more quickly. To this end we analyze the mathematical structure of the feasible region and develop a hand-crafted decision tree which applies splits imitating this structure. Additionally, we develop sev-eral techniques to increase the performance of our method. The practicability of our methods is supported by computational experiments on the knapsack problem and the facility location problem. 

Keywords: explainability; counterfactual explanations; AI & optimization 

# 1. Introduction 

1.1. Motivation 

Mathematical optimization is a central tool for decision making in Operations Research and Man-agement Science and is applied in a wide range of industries covering sectors as logistics, health-

> ∗Corresponding author. Email: sebastian.merten@uni-passau.de

1arXiv:2610.05887v1 [math.OC] 5 Oct 2026 care, finance or disaster management. Often, exact solution methods for a certain optimization model can be developed and implemented, which provide an optimal solution of the corresponding model. However, the achieved “optimality” can give a false sense of explainability. First, the same real-world problem might be approached by different optimization models involving different con-straints, objectives or parameter estimations, leading to different optimal solutions. Second, most of the exact algorithms still lack meaningful explanations for stakeholders which are not technical experts [ABKY26]. Hence, explanations which provide insights on the behaviour of the model and corresponding algorithm for different stakeholders are needed [ABKY26, ZKY +25]. One concept gaining increasing attention which can be used to generate comprehensible explanations for an optimization model are counterfactual explanations (CEs) [KSB21, KBdH26, EKBR25]. Given the currently applied optimization model and an optimal solution which has property A, a counterfac-tual question asks which changes of the problem parameters have to be made such that a solution with property B is optimal. As an example, consider a facility location problem which is used to decide in which districts a health-care facility is opened. Given the optimal decision to open a set of facilities, a stakeholder might ask the question: “Why is there no facility opened in our district?” A counterfactual explanation can give an answer such as, “If the population of your district were 10% higher, the model would have opened a facility in your district.” Only a few methods exist which are able to calculate CEs for problems with integer decision variables. The works of Korikov and Beck study CEs for binary problems where only the objective parameters are allowed to change [KSB21, KB23]. Later, in [EKBR25] exact algorithms were developed for the case of binary problems where both objective and constraint parameters are allowed to change. However, the proposed algorithm is computationally tractable only for small instance sizes and problems where the parameters of a single constraint are allowed to change, while the more general setup is not assumed to scale well for realistic problem sizes. The authors prove that the problem even with a single mutable constraint is Σ p

> 2

-complete and hence tractable exact algorithms for large-scale problems are currently out of reach. 

Our Contributions: In this work, we derive a fast heuristic algorithm to calculate CEs for integer problems where the parameters of multiple constraints are allowed to change. To this end, we analyze the structure of the feasible region of the CE problem and approximate it with a hand-crafted decision tree for which CEs can be calculated quickly. Our main contributions are as follows. (i) We analyze the mathematical structure of the feasible region of the weak CE problem and show that it can be described as a finite union of polyhedra. (ii) We prove that under mild assumptions, an optimal CE lies on a hyperplane parametrized by a feasible solution of the original problem which we attempt to explain. (iii) We develop a decision tree which exploits the latter insight by generating splits which coincide with the hyperplanes potentially containing optimal CEs. (iv) We derive an algorithm to train such decision trees on randomly generated parameter samples and engineer several techniques to improve the accuracy of the decision tree and the computation time of our algorithm. (v) We present experiments on the knapsack problem and the facility location 2problem demonstrating the capability of the proposed method to generate CEs of good quality significantly faster than available benchmarks. 

1.2. Related Literature 

The concept of counterfactual explanations was first introduced for machine learning models in [WMR18] and has been receiving increasing attention since then; see e.g. the surveys [Gui24, VBH +24]. Later, the concept was translated to optimization problems. In [KSB21, KB23] counterfactuals for binary linear optimization problems where only objective parameters are mutable were studied, applying techniques from constraint programming and inverse optimization. In [FPV23] the au-thors study counterfactuals in the context space for a predict-then-optimize approach. Afterward, [KBdH26] identified three types of counterfactuals of interest for optimization problems – weak, strong, and relative CEs – and analyzed them for linear optimization problems with continuous de-cision variables. A fast heuristic based on an alternating direction method was developed in [LS26] to calculate feasible weak CEs for continuous linear optimization problems. Exact methods for weak and strong CEs for integer linear optimization problems were developed in [EKBR25] for the case where mutable parameters may also appear in the constraints. Relative CEs have since been investigated for contextual stochastic optimization [RAF25], and CEs have been used to explain efficiency targets in data envelopment analysis [BRAM24] and to detect the minimum number of constraints to make a problem infeasible in constraint programming [DSA +24]. 

Interpretability in optimization. In contrast to the concept of explainability where a justifica-tion for the selection of a specific solution is required, interpretability requires the utilized model or algorithm to be inherently interpretable. The design of such models must suit the affected stakeholders’ abilities and needs based on their domain knowledge. Due to this requirement, us-ing interpretable methods leads to solutions which can be explained without using further tools. However, the use of interpretable methods often requires simplifications leading to a potential loss in solution quality compared to the use of black-box methods such as industrial MIP solvers. Besides problem-specific approaches [CM22, BOW21] and simple heuristics [NZJT12], the use of interpretable surrogate models has been proposed. The latter include decision trees of restricted size [GH23, GHMS24, LTE24] and sparse linear models [GHM26] mapping instances to solutions. For an extended overview of the current literature on interpretability in optimization we refer to [LC25] and [GHMS24]. 

Other explainability approaches. Beyond CEs and the use of interpretable models, other ap-proaches to ensure explainability in mathematical optimization exist. These include the use of feature selection [AGH +25], local explanations [OKB25], and the enforcement of a solution’s simi-larity to historical decisions [AGH +24]. In two-stage stochastic optimization a so-called certificate, a set of representative scenarios, can also be provided in order to justify solutions [PG26]. Although 3sensitivity analysis [BP16] can be used to provide insights into causal relationships, it is question-able to what extent it actually provides sufficient explanations [ABKY26]. Explanations were also studied for metaheuristics [ZBB +24, FMC +25, CBC +24]. Additionally, the use of LLMs to pro-duce human-accessible explanations has been recently proposed [CCFM +26, ZKY +25, XWH +26]. A summary of the current state-of-the-art methods and a call for interdisciplinary action can be found in [ABKY26].

# 3. Detailed Algorithm 

Our algorithm follows the steps shown in Figure 3, which are described in detail in the following subsections. We first sample a training set of points S = {(Ai, b i)}Ni=1 by using a dynamic sampling scheme where each point is labeled either as feasible or infeasible. We can check if ( Ai, b i) is a feasible CE by checking if min {ˆc⊤x : Aix ≥ bi, x ∈ X } = min {ˆc⊤x : Aix ≥ bi, x ∈ X ∩ D} . (5) After sampling and labeling, we apply a preprocessing that enriches the set of samples by resampling around valid CEs. We then train a decision tree T using the CE-tailored splits as described in the previous subsection. Subsequently, we calculate CEs for each leaf of the tree labeled as feasible by solving problem (4). 3.1. Sampling and Pre-Processing 

Our algorithm first checks if the present parameters ( ˆA, ˆb) are a feasible CE by using (5). If this is the case we can directly return ( ˆA, ˆb) as the optimal CE, since it has distance zero. Hence, in the following we assume that ( ˆA, ˆb) is not a feasible CE. 

Sampling. In the first stage of our method, a dynamic sampling mechanism is applied which draws samples S = {(Ai, b i)}Ni=1 around the parameters ( ˆA, ˆb) of the present problem. While sampling in the immediate neighborhood of ( ˆA, ˆb) seems tempting, since we are interested in finding the closest CE, we might only consider an area which contains no feasible solution for (WCEP). In contrast, sampling in a larger area ensures proper exploration and increases the likelihood of successfully finding a CE, but also increases the risk that it will be far from the optimal solution of (WCEP).

3.2. Training 

In this section we describe a greedy heuristic to determine a decision tree classifying points ( A, b )based on whether they are feasible CEs or not, i.e., whether they are contained in W or not. Utilizing Theorem 1, solution vectors y ∈ X of the underlying optimization problem are used as splits. Following the idea of the CART algorithm [BFOS84], the tree is built by choosing iteratively at each query node the best split w.r.t. to the gini impurity criterion. In contrast to the application of the CART algorithm, where a reasonable pool of splits can easily be precomputed, determining them in our application is challenging in itself since each solution in X provides a potential split and hence the number of splits might be exponential in the dimension of the present problem. Theoretically, the solution in X which minimizes the gini impurity can be calculated by optimizing over X with mixed-integer programming methods. In Appendix B, we present a non-linear mixed-integer programming formulation to compute splits which are locally optimal. As the formulation involves big-M constraints and a large number of binary variables, this procedure is expected to be too computationally expensive. 13 Therefore, instead of finding the optimal split in each iteration of the training process, we select the best split from a pre-computed pool of solutions Xcand ⊂ X . # 5. Conclusion & Outlook 

Recently, the topic of explainability in mathematical optimization has received increasing atten-tion. This is fueled by the desire to increase trust in decisions proposed by black-box algorithms. Nevertheless, few methods currently exist to address this need. One promising concept is the use of CEs for optimization problems. Although heuristics have been developed for the case of LPs, determining CEs for larger IP instances is still practically impossible. In this paper, we present a novel approach to heuristically compute CEs for integer optimization problems. We prove that under classical assumptions the feasible region of (WCEP) is essentially a union of polyhedra and that optimal CEs lie on the boundary of these polyhedra which are parametrized by feasible solutions of the underlying present problem. This allows a novel type of decision tree to approximate this region, enabling us to subsequently generate a CE for this tree at relatively low computational costs. We introduce further pre- and post-processing steps which improve the quality of the calculated CEs. Using Knapsack instances, we benchmark against an exact method for problems with a single mutable constraint and show that we can calculate CEs of similar quality in a fraction of the time. Our ablation study shows that all the component introduced in the pre- and post-processing have an actual effect on the quality of the calculated CE. Of the two version of the proposed CE-DT algorithm, the version querying a single constraint instead of the full constraint matrix was consistently found to perform best. Furthermore, the results empirically prove the applicability of our method to MIPs, surpassing the scope of our theoretical findings which focus on IPs. 28 Future work may include the development of methods to enhance the generation of the training set S. The approach of dynamical sampling apparently has a rate of finding a valid CE in 90% of the cases where the feasibility of (WCEP) is proven. Even though the development of a computa-tionally efficient method guaranteeing to find a CE seems unlikely due to the proven complexity of (WCEP), we believe that further improvements are possible by, for example, the incorporation of domain knowledge. Furthermore, query candidates in the CE-DT algorithm are currently found as a byproduct of sampling. Alternative approaches to generate candidates may further increase the performance of this method. Finally, our method is not designed to verify if the weak CE problem is infeasible. Fast methods to check infeasibility are necessary.

# B. MIQP Formulation for Locally Optimal Splits 

In this section, we present a non-linear mixed-integer programming formulation to determine queries for a decision tree which are locally optimal. In the case, where we require the split to partition some set S = {(At, b t)}Nt=1 by checking if any constraint is violated by a vector x, the optimal vector 

x can be obtained by solving Problem (9). As part of this formulation, binary variables ut indicate whether a data point t ∈ [N ], is feasible for the solution vector x ∈ Zn by being set to one, or infeasible by being set to zero. This allows us to formulate the minimization of the gini impurity implied by a vector x as the objective function. For the sake of clarity, the objective function (9a) is explicitly formulated in line with the definition in Section 3. Note, however, that it can easily be reformulated to a quadratic form by introducing additional auxiliary variables and quadratic constraints, allowing it to be solved using state-of-the-art solver software. Constraints (9b) and (9c) enforce binary variables zit to be one, if constraint

δ ∈ ∆, where |∆| ∈ Z+ represents the iteration limit of the dynamic sampling approach. In Sections 4.2 and 4.3, uniform distributions were used. We define ∆ = {1, . . . , K }. For a given value of δ and each mutable parameter p a value is sampled from the interval [ˆ p − (ˆ p − plb ) · δ

That is, setting δ to zero would only allow to sample the single point ( ˆA, ˆb), whereas setting δ := |∆| would result in sampling from the full mutable parameter space. This allows us to iteratively enlarge the subset of H which is explored in the dynamic sampling process. Furthermore, for a subset of experiments presented in Section 4.2.1, truncated normal distribu-tions were used.
