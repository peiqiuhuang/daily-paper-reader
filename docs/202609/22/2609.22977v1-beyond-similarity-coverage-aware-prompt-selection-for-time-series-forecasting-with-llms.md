## 摘要
基于相似度的检索是在上下文学习、检索增强生成和基于提示的时间序列预测中为大语言模型（LLM）提供条件的主导规则。然而，该规则倾向于集中于近乎重复的候选项，这一问题虽推动了多样性感知检索的研究，但在其他依赖检索的流程中仍未得到深入探究。我们以基于提示的时间序列预测为测试平台来研究这一问题，在该设置下，系统通过相似度检索可学习的提示池。此设置下的主流方法通过余弦相似度检索前 K（Top-K）个条目且缺乏冗余控制，从而产生了对主导时间模式的偏置，同时忽视了稀有但富含信息的事件。为此，我们提出了 CASP-LLM，一种覆盖感知的语义提示框架。该框架将使用率跟踪与饱和门控技术结合为一个不增加任何可学习参数的覆盖正则化项，以此解决这种提示选择偏置。在六个长期基准和 M4 短期基准上的实验表明，CASP-LLM 在大多数数据集-预测界限设置下达到或超越了基于相似度的 LLM 预测模型，但在 Electricity、M4-Monthly 以及少样本长界限设置中例外。一项对照研究将失效模式定位在跨批次使用率层面，而非单次检索内部的冗余：检索内部的多样化策略（如 MMR）并无效果，而在整个训练过程中对锚点使用率进行正则化则切实有效。

## Abstract
Similarity-based retrieval is the dominant rule for conditioning large language models (LLMs) in in-context learning, retrieval-augmented generation, and prompt-based time series forecasting. The rule concentrates on near-duplicate candidates, an issue that has motivated diversity-aware retrieval but remains unexamined in other retrieval-conditioned pipelines. We study this issue using prompt-based time series forecasting as a test bed, where a learned prompt pool is retrieved by similarity. Dominant methods in this setting retrieve top-K entries by cosine similarity without redundancy control, producing a bias toward dominant temporal patterns while overlooking rare but informative events. We propose CASP-LLM, a coverage-aware semantic prompting framework that addresses this prompt selection bias by combining usage-tracking and saturating-gate techniques into a coverage regularizer that adds no learnable parameters. On six long-term benchmarks and the M4 short-term benchmark, CASP-LLM matches or improves on similarity-based LLM forecasters on most dataset-horizon settings, with the exceptions of Electricity, M4-Monthly, and the few-shot long-horizon setting. A controlled study locates the failure mode at the cross-batch usage level rather than per-retrieval redundancy: within-retrieval diversification such as MMR does not help, whereas regularizing anchor usage across training does.

### 1. 核心问题与整体含义（研究动机与背景）

*   **研究背景**：在大语言模型（LLM）应用于时间序列预测（LLM-for-TS）的框架中，主流方法（如 TEMPO、$S^2IP$-LLM）通常会构建一个可学习的软提示词池（Prompt Pool）或语义锚点池（Semantic Anchors），并在运行时通过**余弦相似度（Top-K Cosine Similarity）**检索最相关的提示词来指导 LLM 进行预测。
*   **核心问题（提示词选择偏置）**：基于纯相似度的检索机制存在严重的选择坍缩（Selection Collapse）问题。在训练过程中，Top-K 规则会将选择高度集中在少数主导的时间模式/锚点上，导致模型过度关注常见模式，而忽略稀有但富含信息的异常或边缘事件。作者将此现象定义为**提示词选择偏置（Prompt Selection Bias）**。
*   **深层洞察**：现有针对检索冗余的解决方案（如 MMR、DPP、子模覆盖）多作用于**单次检索内部（Per-Retrieval）**的多样性重排，而本文指出时间序列 LLM 预测中的核心失效模式发生在**跨批次（Cross-Batch）**的训练动态积累层面。因此，需要在训练期对锚点的使用率进行全局调控。

### 2. 论文提出的方法论（CASP-LLM 框架）

CASP-LLM（覆盖感知语义提示框架）的核心思想是：**保持推理阶段的 Top-K 相似度检索规则完全不变，通过在训练期引入一个无新增参数的覆盖率正则化损失（Coverage Regularizer），从几何层面重塑锚点嵌入空间。**

#### 关键技术细节与算法流程：
1.  **语义对齐（Semantic Alignment）**：
    *   **时间序列分支**：将多变量时间序列切块（Patching），并进行加性季节-趋势分解（Trend, Seasonal, Residual），连接后通过可学习线性层映射至 LLM 嵌入空间，池化得到样本级 Query 表示 $\tilde{e}_b$。
    *   **语义锚点分支**：从 GPT-2 的预训练词表嵌入矩阵 $E \in \mathbb{R}^{V \times d}$ 中，利用可学习线性投影矩阵抽取 $V'$ 个代表性向量，构成语义锚点矩阵 $E' \in \mathbb{R}^{V' \times d}$（$V' \ll V$）。
2.  **覆盖感知检索与正则化（Coverage-Aware Retrieval & Loss）**：
    *   **使用率跟踪器（Usage Tracker）**：使用指数移动平均（EMA）追踪训练过程中每个锚点在近期批次中的累积使用率 $\tilde{c}_i^{(t)}$：
        $$\tilde{c}_i^{(t)} = \beta \tilde{c}_i^{(t-1)} + (1 - \beta) \bar{s}_i^{(t)}$$
        其中 $\bar{s}_i^{(t)}$ 为当前 Batch 内锚点 $i$ 的平均截断相似度。
    *   **饱和门控覆盖损失（Saturating Min Gate Loss）**：利用 `min` 门控函数和截断梯度（Stop-Gradient, `sg`）构造覆盖损失：
        $$\mathcal{L}_{cov} = \frac{1}{B} \sum_{b=1}^B \sum_{i=1}^{V'} \min\left(\max(s_{b,i}, 0), \text{sg}[\tilde{c}_i^{(t)}]\right)$$
        *机制*：对于累积使用率 $\tilde{c}_i$ 高的锚点，门控释放相似度惩罚梯度，降低其相似度；对于使用率接近 0 的锚点，门控饱和且不施加惩罚，从而促使模型在训练中探索并激活未充分利用的锚点。
3.  **复合优化目标与预测**：
    *   训练损失由预测损失 $\mathcal{L}_{forecast}$、相似度损失 $\mathcal{L}_{sim}$ 和覆盖损失 $\mathcal{L}_{cov}$ 复合而成：$\mathcal{L}_{total} = \mathcal{L}_{forecast} + \lambda_{sim} \mathcal{L}_{sim} + \lambda_{cov} \mathcal{L}_{cov}$。
    *   选出的 Top-K 锚点作为 Prefix Prompt 拼接在时间序列 Patch 前，输入冻结大部分参数的 GPT-2 解码器中进行自回归/并行预测。

### 7. 局限性与批判性思考

*   **超参数敏感性**：
    *   覆盖损失权重 $\lambda_{cov}$ 与 EMA 平滑因子 $\beta$ 的设定对平衡“相似度准确性”与“覆盖率多样性”至关重要。若 $\lambda_{cov}$ 设置过大，可能导致模型过度牺牲相似度匹配度而盲目追求均匀分布，从而引入噪声提示词。
*   **主干模型单一性**：
    *   论文主实验主要基于 GPT-2 进行验证，尽管证实了其有效性，但对于百亿级参数的大模型（如 LLaMA-3、Mistral）或专用时间序列大模型，覆盖正则化的动态与几何影响仍需进一步评估。
*   **语义映射的本质鸿沟**：
    *   虽然覆盖正则化解决了检索坍缩问题，但锚点本质上仍是从文本词表投影而来。文本嵌入空间与时间序列动力学特征之间的跨模态语义对齐依然存在内在的表征瓶颈。
