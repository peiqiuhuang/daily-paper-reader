## 摘要
双层强化学习（Bilevel RL）是强化学习领域中的一个重要框架，可用于形式化各种类别的问题，例如元学习、分层任务分解以及人类反馈强化学习（RL-HF）。大多数双层强化学习算法要么因为使用带有 Hessian 矩阵的超梯度而缺乏可扩展性，要么因为使用基于惩罚的近似方法而面临高样本复杂度的问题。在这项工作中，我们利用熵正则化折扣强化学习目标函数下 Boltzmann 策略的最优性，提出了一种基于超梯度的双层强化学习算法。我们提出的算法是无 Hessian 的（Hessian-free），在温和的正则性条件下，实现了 $O(ε^{-1})$ 的迭代复杂度和 $\tilde{O}(ε^{-2})$ 的最先进样本复杂度。此外，在收敛性分析中，我们能够移除先前最先进样本复杂度研究中对外层目标函数所要求的 Polyak-Lojasiewicz (PL) 条件假设。

## Abstract
Bilevel reinforcement learning (RL) is an important framework within the literature of RL that can be used to formalize various categories of problems, such as meta-learning, hierarchical task decomposition, and reinforcement learning from human feedback (RL-HF). Most of the bilevel RL algorithms are either not scalable because of using hypergradient with Hessian, or they suffer from high sample complexity because of using penalty-based approximation methods. In this work, we propose a hypergradient-based bilevel RL algorithm using the optimality of the Boltzmann policy for the entropy regularized discounted RL objective function. Our proposed algorithm is Hessian-free and obtains an iteration complexity of $O(ε^{-1})$ and state-of-the-art sample complexity of $\tilde{O}(ε^{-2})$ under mild regularity conditions. Further, in our convergence analysis, we are able to remove the assumption of the Polyak-Lojasiewicz (PL) condition on the outer-level objective function present in the prior state-of-the-art sample complexity work.

*   **可扩展性差**：传统的超梯度（Hypergradient）方法通常依赖于计算 Hessian 矩阵的逆，对于具有大量参数的深度神经网络，计算开销巨大。
*   **样本复杂度高**：为了避开 Hessian 矩阵，一些基于惩罚项（Penalty-based）的近似方法虽然提高了可扩展性，但样本复杂度较差（通常为 $O(\epsilon^{-3})$）。
*   **假设过于严苛**：现有最优分析往往需要外层目标函数满足 Polyak-Łojasiewicz (PL) 条件或内层问题具有唯一解。

### 2. 论文提出的方法论
论文提出了 **AHO（Approximate Hypergradient Optimization）算法**，其核心思想是利用**熵正则化 RL 中 Boltzmann 策略的最优性**来简化超梯度计算。

*   **核心思想**：在熵正则化框架下，最优策略具有 Boltzmann 分布的闭式解。利用这一特性，可以将原本复杂的、包含 Hessian 逆矩阵的超梯度表达式转化为仅包含梯度和值函数的表达式。
*   **关键技术细节**：
    *   **梯度偏移值函数（Gradient Shifted Value Functions）**：定义了 $U^\pi$ 和 $W^\pi$ 作为 Boltzmann 值函数和 Q 函数梯度的代理（Surrogate），通过类似 Q-learning 的递归关系进行估计。
    *   **近似超梯度定理**：推导出了一个无需 Hessian 矩阵的超梯度估计公式，该公式通过采样轨迹和上述代理函数来计算外层奖励参数的更新方向。
*   **算法流程**：
    1.  **内层循环**：固定奖励参数，通过策略梯度法更新策略参数 $\theta$，并使用 Q-learning 估计值函数。
    2.  **外层循环**：利用内层得到的最优策略，通过 AHO 估计的近似超梯度更新奖励参数 $x$。
