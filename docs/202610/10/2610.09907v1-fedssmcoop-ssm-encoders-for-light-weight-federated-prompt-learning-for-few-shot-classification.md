## 摘要
视觉-语言模型（VLMs）凭借其各自领域内包含的互补信息，在广泛的下游视觉任务中展现出强大的性能。尽管性能有所提升，但大多数方法依赖于使用余弦相似度度量来对齐这些领域，这无法在分类阶段之前捕捉到标记级结构和跨模态交互。在联邦约束下的生物医学应用中，这一点尤为关键，因为在这些场景中数据共享受到限制，各站点的标注数据稀缺，且机构间数据差异巨大，导致了显著的统计异质性。为了克服这一问题，我们提出了 FedSSMCoOp，这是一个在保护数据隐私的同时实现多模态学习的联邦少样本图像分类框架。借助基于 SSM 的 Vision Mamba 和 Cross Mamba 模块，并通过在联邦设置中仅优化软提示（soft-prompt）和通信提示（communication-prompt）更新，该框架兼顾了计算效率与性能。重要的是，这消除了使用外部大语言模型（LLM）进行特征对齐的需求。该框架在多个生物医学图像数据集上进行了训练和评估，并对其性能进行了评估。所提出的框架在保持性能稳定的同时，相比基准模型平均轻量化了 1.96 倍。相关脚本即将发布。

## Abstract
Vision-Language Models (VLMs) have shown strong performance across a wide range of downstream vision tasks, thanks to the complementary information contained in the respective domains. Despite the performance gains, most of these approaches rely on aligning these domains using the cosine similarity metric, which fails to capture token-level structure and cross-modal interactions prior to the classification stage. This is especially critical in biomedical applications under federated constraints, where data sharing is restricted, labeled data is scarce at each site, and it differs widely across institutions, leading to substantial statistical heterogeneity. To overcome this issue, we propose FedSSMCoOp, a federated few-shot image classification framework that enables multimodal learning while preserving data privacy. With the help of the SSM-based Vision Mamba and Cross Mamba blocks, and by optimizing only the soft-prompt and communication-prompt updates in the federated setting, the framework prioritizes both computation and performance. Importantly, this eliminates the need to use an external Large Language Model (LLM) for feature alignment. The framework is further trained and evaluated on various biomedical image datasets, and its performance is assessed. The proposed framework delivers stable performance relative to the baselines and is, on average, 1.96 times lighter. The corresponding script will be made available soon.

*   **核心思想**：利用状态空间模型（SSM）替代传统的注意力机制，通过轻量级的提示学习（Prompt Learning）实现联邦多模态对齐。
*   **关键技术**：
    *   **Vision Mamba 编码器**：利用 SSM 的线性复杂度特性，在保持性能的同时降低计算开销。
    *   **Cross Mamba Interaction Block (MIB)**：通过双向扫描机制融合视觉与文本特征，实现跨模态交互，从而替代了对外部 LLM 的依赖。
    *   **联邦提示更新**：仅在客户端与服务器间传输“软提示（soft-prompt）”的增量（delta），冻结视觉和文本编码器，大幅降低通信成本。
*   **算法流程**：服务器广播全局提示 $\bar{P}$，客户端在本地利用 MIB 和软提示进行训练，仅上传提示增量 $\Delta X_p$ 给服务器进行加权聚合。
