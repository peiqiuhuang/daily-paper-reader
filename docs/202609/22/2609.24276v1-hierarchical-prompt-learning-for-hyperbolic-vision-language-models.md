## 摘要
双曲视觉-语言模型（VLM）在自然适合表达层级结构的几何空间中表示图像与文本特征，但它们向下游任务的迁移在很大程度上仍依赖于固定提示。与此同时，现有的提示学习方法将类别标签视为平坦集合，未能利用已有的分类层级结构。为了填补这一空白，我们提出了一种适用于冻结双曲 VLM 的层级提示学习插件。在给定固定离线父类层级结构的前提下，该插件通过独立的父类提示学习器、父类层级监督、双曲蕴涵正则化以及父类反馈 Logit 融合来增强类别提示学习器。我们基于 CoOp、CoCoOp 和 MaPLe 实现了该方法，分别得到 HyPLO、CoHyPLO 和 MaHyPLO。在包含 11 个数据集的标准基准测试中，所有变体均提升了基础到新类的泛化能力和跨数据集迁移能力，且在域偏移下性能仍与对应的提示学习基线相当。6 个层级度量指标及嵌入分析表明，该方法能产生分类一致性更高的预测，并在双曲空间中引导父类、子类与图像嵌入实现符合层级结构的组织。当新类别必须归入固定分类体系时，该方法的增益最大；而在兄弟类之间的细粒度混淆或仅影响图像分布的偏移情况下，增益最小。

## Abstract
Hyperbolic vision-language models (VLMs) represent image and text features in a geometry naturally suited to hierarchy, but their adaptation to downstream tasks has largely relied on fixed prompts. Existing prompt learning methods, meanwhile, treat class labels as a flat set and do not exploit available taxonomic structure. We address this gap with a hierarchical prompt learning plug-in for frozen hyperbolic VLMs. Given a fixed offline parent-class hierarchy, it augments a class prompt learner with a separate parent prompt learner, parent-level supervision, hyperbolic entailment regularization, and parent-feedback logit fusion. We instantiate the method with CoOp, CoCoOp and MaPLe, yielding HyPLO, CoHyPLO and MaHyPLO. Across the standard 11-dataset benchmark, all variants improve base-to-new generalization and cross-dataset transfer, and remain comparable to their prompt learning baselines under domain shift. Six hierarchical metrics and embedding analyses show that the method produces more taxonomically consistent predictions and induces a hierarchy-consistent organization of parent, class, and image embeddings in hyperbolic space. Its gains are largest when novel classes must be placed within a fixed taxonomy, and smallest for fine-grained confusions among sibling classes or shifts affecting only the image distribution.

### 2. 论文提出的方法论

论文提出了一种**与提示学习器无关的双曲层级提示插件（Hierarchical Prompt Plug-in）**。其核心思想是在保留现有类别提示学习器的同时，引入并行父类提示学习器，并在双曲空间中利用几何蕴含约束和层级推理。

#### 关键技术细节：

1.  **双曲空间映射（Lorentz Model）**：
    *   采用 $n$ 维洛伦兹模型 $\mathcal{L}^n$ 表示双曲空间，通过指数映射（Exponential Map $\exp_0^\kappa$）将冻结编码器输出的欧式特征提升至洛伦兹流形。
    *   距离计算使用测地线距离 $d_L(p, q)$ 构建分类 Logit。

2.  **双层提示学习器架构**：
    *   **类别提示学习器**：生成类别嵌入 $z_c$。
    *   **父类提示学习器**：根据固定的离线父类体系，为父类词汇生成父类文本嵌入 $z_p$。
    *   可灵活应用于 CoOp（静态提示 $\rightarrow$ **HyPLO**）、CoCoOp（图像条件提示 $\rightarrow$ **CoHyPLO**）和 MaPLe（多模态提示 $\rightarrow$ **MaHyPLO**）。

3.  **层级训练目标（Composite Loss）**：
    *   **双曲交叉熵损失**：分别计算图像嵌入 $z_{\text{img}}$ 与类别嵌入 $z_c$（$\mathcal{L}_{\text{cls}}$）、父类嵌入 $z_p$（$\mathcal{L}_{\text{par}}$）之间的测地线距离交叉熵。
    *   **双曲蕴含锥正则化（Entailment Cone Regularization, $\mathcal{L}_{\text{ent}}$）**：基于 Ganea 等人的蕴含锥理论，约束“父类-子类”、“子类-图像”及“父类-图像”在双曲空间中的角度关系。若子类/图像落在父类的蕴含锥内则惩罚为零，迫使越抽象的概念越靠近原点（圆锥半角更大）。

4.  **层级推理（Hierarchical Inference）**：
    *   在推理阶段，将父类 Logit 按映射关系广播至其对应的子类，与类别 Logit 进行加权融合：
        $$s_{\text{final}}(c) = \ell_{\text{cls}}(c) + \lambda_{\text{par}} \ell_{\text{par}}(\pi(c))$$
    *   通过父类信号修正跨父类边界的误分类。

5.  **离线层级构建协议**：
    *   对于有原生树状结构的数据集（如 ImageNet 对应的 WordNet）直接提取；对于无原生结构的数据集，通过 LLM（Claude Opus 4.7）结合人工校验，构建固定的“根节点-祖父类-父类-子类”分类体系。

### 8. 论文的局限性与未来改进方向

1.  **对先验层级结构的依赖**：对于缺乏 WordNet 等原生分类树的数据集，构建“父类”依赖大语言模型（如 Claude），虽然进行了人工核验，但在极细粒度或专业领域（如遥感、医疗）中，LLM 抽取的层级体系可能存在偏误。
2.  **固定的深度融合机制**：目前的方法主要基于“父类-子类”两层映射，对于包含多级深度（如界-门-纲-目-科-属-种）的更深层级树，当前的加权推理公式 $s_{\text{final}}(c) = \ell_{\text{cls}}(c) + \lambda_{\text{par}} \ell_{\text{par}}(\pi(c))$ 需要扩展为自适应的多级衰减融合。
3.  **超参数 $\lambda_{\text{par}}$ 的静态设置**：推理阶段的父类 Logit 融合权重在所有类别上是全局固定（静态）的，未来可探索根据图像预测不确定性动态调节父类修正力度的机制。
