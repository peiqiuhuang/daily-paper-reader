## 摘要
由大语言模型（LLM）驱动的人工智能（AI）助教能够提供可扩展的教育支持，但其个性化能力往往有限。本研究提出了一个基于提示工程的框架，用于在不同学科和课程中对基于 LLM/RAG 的通用 AI 助教（如 Jill Watson）实现个性化。该框架通过六个特定于学习者的维度来调整生成响应：自我评估、抽象偏好、冗长程度偏好、感知定向、信息处理风格和理解水平，共生成 96 种不同的学习者画像。此外，系统还使用布鲁姆分类学（Bloom's Taxonomy）分析学生提问，以评估交互层面的认知复杂度。学习者属性与认知评估被编码至结构化提示中，在无需重新训练模型的情况下对 LLM 进行约束和引导。该框架通过基于 NLP 指标的实验以及一项包含 5 名参与者的人工评估实验进行了验证。结果显示，在不同个性化条件下，生成的回答在风格和结构上存在可感知差异，统计分析也识别出了与可测量回答变化相关的学习者属性。这些发现提供了初步证据，表明基于提示的个性化可以支持 LLM 驱动的教育智能体实现自适应行为。

## Abstract
Artificial intelligence (AI) teaching assistants powered by large language models (LLMs) offer scalable educational support but often provide limited personalization. This study presents a prompt-engineering-based framework for personalizing general-purpose LLM/RAG-based AI teaching assistants such as Jill Watson across academic disciplines and courses. The framework adapts responses using six learner-specific dimensions: self-assessment, abstraction preference, verbosity preference, perceptual orientation, information processing style, and level of understanding, yielding 96 distinct learner profiles. Student queries are additionally analyzed using Bloom's Taxonomy to estimate cognitive complexity at the interaction level. Learner attributes and cognitive assessments are encoded in structured prompts that condition the LLM without requiring model retraining. The framework is evaluated through experiments using NLP metrics and a human study with five participants. Results show perceived differences in response style and structure across personalization conditions, with statistical analyses identifying learner attributes associated with measurable response changes. These findings provide preliminary evidence that prompt-based personalization can support adaptive behavior in LLM-powered educational agents.

### 1. 核心问题与整体含义（研究动机和背景）
* **研究背景**：基于大语言模型（LLM）和检索增强生成（RAG）的人工智能助教（如 Georgia Tech 开发的 Jill Watson）能够大规模提供跨学科的教学支持。然而，传统 LLM 助教通常采用统一的回答风格，缺乏针对个体学习者差异的细粒度（微观）自适应能力。
* **核心问题**：如何在**无需重新训练底层大模型**或进行大量领域特定规则编写的前提下，在单次问答（交互）层面上实现实时、灵活、可扩展且符合教育学理论的个性化教学响应？

### 2. 方法论（核心思想与技术细节）
* **核心思想**：提出了一个基于提示工程（Prompt Engineering）的混合个性化框架。该框架将**学习者主动选择的个性化偏好（Adaptability）**与**系统自动判断的认知需求（Adaptivity）**相结合，在运行时动态构建 Prompt 来约束和引导 LLM 生成回答。
* **关键技术细节**：
  1. **6 维学习者画像（共 96 种 Profiles）**：结合 Felder-Silverman 学习风格模型和元认知学说，定义了 6 个个性化维度：
     * *元认知/自我评估 (Self-Assessment)*：初学者 (Beginner)、中级 (Intermediate)、专家 (Expert)。
     * *抽象偏好 (Abstraction)*：深入/技术性 (In-Depth/Technical)、大局/高层级 (Big Picture/High-Level)。
     * *冗长偏好 (Verbosity)*：冗长 (Verbose)、简洁 (Concise)。
     * *感知定向 (Perception)*：感觉型 (Sensory)、直觉型 (Intuitive)。
     * *信息处理风格 (Processing)*：主动型 (Active)、反思型 (Reflective)。
     * *理解水平 (Understanding)*：循序渐进型 (Sequential)、整体全局型 (Global)。
  2. **提问认知复杂度分析**：系统利用微调的 BERT 模型（基于 `bert-base-uncased`，在公开试题数据集上训练，测试准确率 0.92）自动将学生提问划分为布鲁姆认知分类学（Bloom's Taxonomy）的 6 个层级（记忆、理解、应用、分析、评价、创造/综合）。
  3. **提示词工程与 RAG 融合**：在运行时生成包含学习者属性、Bloom 分类标记、课程检索内容（RAG）的结构化 Prompt，指导 LLM 在保持知识库事实准确性的同时，改变回答的语言结构、表现形式和认知深度。

### 3. 实验设计

* **对比基线 (Baseline)**：未应用个性化提示的标准 RAG 响应。
* **实验配置**：每个问题生成 96 种个性化配置 + 1 个基线回答，共计 $30 \times 97 = 2,910$ 个生成回答（使用 GPT-4.1，Temperature 设置为 0 以消除随机性）。

### 6. 主要结论与发现
* **解答 RQ1（是否产生可测差异）**：不同 Prompt 配置生成的回答在保持极高语义一致性（Semantic Grounding）的同时，在词汇重叠度（ROUGE）和表面表达结构上呈现显著差异。
* **解答 RQ2 与 RQ3（维度的贡献与符合度）**：
  * **抽象偏好**与**冗长偏好**对输出结果的改变最为显著（如高抽象/技术性偏好显著增加了文本复杂度；冗长偏好显著改变了字数）。
  * 更高的自我评估水平、冗长偏好、反思型处理风格以及高 Bloom 提问层级，与更高的回答文本复杂度呈现正相关。
  * 人类评估证实，学生能明显感知到“抽象偏好”与“处理风格”调整带来的变化，且其感受与 Prompt 设定的预期目标高度一致。

### 7. 优点与亮点
* **免微调与轻量部署**：完全基于 Prompt 工程，无需消耗昂贵算力微调 LLM，可实时解耦并无缝集成至现有的 RAG 架构（如 Jill Watson）。
* **结合教育学理论**：将 Felder-Silverman 学习风格模型与 Bloom 认知层次模型相结合，使得个性化提示词设计具有坚实的教育学理论支撑。
* **混合适应机制**：打破了单一的“系统驱动”或“用户驱动”模式，实现了学习者偏好设定与系统认知诊断的有机结合。

### 8. 不足与局限
* **人类评估样本量过小**：仅 5 名评估员，且均来自同一门课程，缺乏统计学上的广泛代表性，无法检验多维度组合时的交互效应。
