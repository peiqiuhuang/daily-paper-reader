## 摘要
将预测系统适应不断变化的世界，传统上意味着重新训练。我们探讨了这样一个问题：时间序列预测中持续学习不同机制的任务是否可以用一段文本来表示：即一个由结果驱动的反省机制不断演化、并被用于冻结的大语言模型预测器提示词中的引导块。在一个更新的多模态基准测试（每周搜索指数、每日货币、每日大宗商品，每个时间窗口均配有网络检索的新闻）上，我们在严格的污染控制下运行了类 GEPA 的提示词演化，以防止时间序列基准测试中常见的数据泄漏：预测器的知识截止时间早于每一个被评估的时间窗口。Llama-3.3-70B 所承载的一个 900 字的演化引导块在保留数据上击败了时间序列基础模型（TSFMs）（几何平均 MASE 为 0.776，而 TabPFN-TS-3 为 0.898），能够无明显损失地迁移到更新的模型，且更新成本只需几美元而非 GPU 天。我们对该循环进行了特征分析：循环外收益集中在第一次反省中，循环内改进会使循环外收益被高估 2-3 倍，除非有未接触过的监控器进行仲裁，并且仅关注错误的优化目标会悄然抑制文本模态。我们提供了两个扩展。首先，将引导块编译为带有可调用工具 TSFM 的可执行代码，以确定性的方式恢复了大部分收益。其次，消融实验表明，这种优势在短预测视野下会进一步扩大，且移除新闻文本并不会损害受引导的预测器的性能，这与文本的价值在学习过程中被蒸馏进策略中的现象相一致。我们认为，持续提示词演化是多模态预测中替代重新训练的一种实用且免训练的方法。

## Abstract
Adapting a forecasting system to a changing world classically means retraining. We ask whether the task of continually learning regimes for time series forecasting can be represented by a piece of text: a guidance block, evolved by outcome-driven reflection and used in a frozen LLM forecaster's prompt. On a refreshed multimodal benchmark (weekly search indices, daily currencies, daily commodities, each window paired with web-retrieved news), we run GEPA-style prompt evolution under strict contamination control to prevent the data leakage common in timeseries benchmarks: the forecaster's knowledge cutoff predates every evaluated window. A 900-word evolved guidance carried by Llama-3.3-70B beats TimeSeries Foundation Models (TSFMs) on held-out data (GM MASE 0.776 vs. 0.898 for TabPFN-TS-3), transfers to more recent models without measurable loss, and costs dollars rather than GPU-days to update. We characterize the loop: out-of-loop gains concentrate in the first reflection, in-loop improvements overstate out-of-loop gains 2-3x unless an untouched monitor arbitrates, and error-only objectives silently suppress the text modality. We provide two extensions. First, compiling the guidance into executable code with a TSFM as a callable tool recovers most of the gain deterministically. Second, ablations show the advantage widens at short horizons and that removing the news text does not hurt the guided forecaster, consistent with the text's value being distilled into policy during learning. We argue that continual prompt evolution is a practical, training-free alternative to retraining for multimodal forecasting.

* **核心问题**：传统的时序预测系统在面对现实世界的环境变化（如结构性断裂和政权更迭）时，通常需要通过微调或重新训练来适应，这伴随着极高的计算成本。大语言模型（LLMs）虽然能处理非结构化文本，但数值预测能力较弱；时序基础模型（TSFMs）擅长数值序列，却孤立于现实世界的非结构化背景。
* **整体含义**：论文探讨了能否将多模态时序预测中“持续学习不同机制”的任务，转化为**一段由结果驱动的反思机制不断演化、并注入冻结的 LLM 预测器提示词中的文本（引导块）**。这提供了一种免训练（Training-Free）、成本低廉且高度可解释的替代重新训练的新范式。

### 2. 论文提出的方法论：核心思想、关键技术细节与流程
* **核心思想**：冻结所有模型的权重，将模型的“学习状态”保存在提示词（Prompt）中。通过结果驱动的反省演化循环，将观测到的预测错误转化为文字指导，并利用严格的选择机制进行保留。
* **关键流程（GEPA 风格的提示词演化循环）**：
  1. **预测（Forecast）**：干净的、带有时间截止控制的 LLM 预测器（如 Llama-3.3-70B）结合当前指导文本 $g$ 预测一个小批次（Minibatch）的训练窗口，并输出附带的理性解释。
  2. **反思（Reflect）**：反思器 LLM（如 Claude）读取完整的执行轨迹（原始历史、完整新闻、预测与实际路径、误差等），自由重写指导文本 $g$（仅受通用、前瞻性规则和字数限制）。
  3. **门控（Gate）**：子代指导必须在其自身的小批次上击败父代，否则被丢弃。
  4. **选择（Select）**：存活的候选者在固定的选择集上打分，基于实例级帕累托前沿（Pareto front）保留在至少一个窗口上表现最佳的候选者，父代按获胜次数采样。
* **扩展方法**：
  * **代码编译扩展**：将指导文本编译为确定性的 Python 代码，并允许代码将 TSFM（如 TabPFN）作为可调用工具。
  * **持续部署协议**：在每个时期结束后进行监控、至多四轮有门控的反思演化、保守提升（仅当验证集超越旧版时晋升）和基于域的路由更新，以平衡稳定性与可塑性。

1. **效果超越 TSFMs**：在未见过的保留数据上，Llama-3.3 配合约 900 字的演化引导提示词（$G_{num}$）在整体 GM MASE 上击败了主流时序基础模型（0.776 vs TabPFN-TS-3 的 0.898）。

3. **循环的动态特征**：循环外的收益主要集中在第一次反思中；如果不使用未接触的监控器，循环内的改进会将真实收益高估 2-3 倍；纯粹以误差为目标的优化会悄然抑制文本模态。
4. **短视界优势更明显**：随着预测视界（Horizon）缩短，演化提示词的优势进一步扩大（$h=3$ 时优势最显著）。
5. **文本的蒸馏效应**：在推理时移除新闻文本并不会损害受引导预测器的性能，这表明新闻文本中对决策有用的信息在学习过程中已经被蒸馏进了策略（规则）中。

### 7. 优点：方法或实验设计上的亮点
* **免训练持续学习（Training-Free）**：通过修改提示词而非权重来实现持续学习，极大降低了计算成本，更新过程具备完全的可读性、可 diff 性和可审计性。
* **严格的时间污染控制**：严防数据泄漏，确保模型评估真实反映零样本与持续适应能力。
* **提示词编译为代码（Code Compilation）**：成功将自然语言指导编译为确定性代码，并允许 LLM 将 TSFM 作为工具调用，兼顾了规则的逻辑严密性和基础模型的数值计算优势。

### 8. 不足与局限
* **基准单一**：当前的所有发现均基于 TimesX 这一特定的多模态时序基准测试家族。
* **策略偏向保守**：由于 MASE 目标的特性，演化出的策略高度偏向“谨慎型”（如平坦预测、阻断动量），可能在某些剧烈趋势突变中反应迟钝。
* **文本模态的边际效应**：消融实验表明推理时丢弃文本不影响效果，这意味着当前检索到的新闻文本在很多情况下可能已被市场定价或冗余，文本主要在学习阶段提供校准作用。
