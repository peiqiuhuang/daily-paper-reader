## 摘要
域泛化（DG）旨在提高模型对任何未见域的泛化能力。为了实现这一目标，现有的DG方法主要集中在从给定的源域中学习域不变特征或提示。然而，这些方法严重依赖于源域数据，而收集和标注大规模的单源或多源数据集往往是不可行的，这限制了DG的实际应用。为了应对这一挑战，我们提出了域提示学习（DoP），这是一种构建在大规模视觉-语言模型（如CLIP）之上的零样本域泛化方法，它无需访问源域数据即可识别未见目标域中的未见类别。本质上，DoP通过文本和视觉模态的提示来学习目标域知识，从而在测试时自适应框架下克服文本-视觉模态中的域偏移。具体而言，DoP首先通过文本域学习（TDL），利用风格间多样性损失和风格内一致性损失，在文本空间中隐式学习各种风格标记来模拟各种分布偏移。随后，DoP采用视觉域学习（VDL），借助自监督学习利用测试视觉数据，进一步精炼由TDL生成的与目标域相关的风格标记。在流行的DG基准数据集（如PACS、VLCS、OfficeHome和DomainNet）以及ImageNet上进行的广泛实验表明，我们的DoP始终优于最先进的DG方法。代码可通过以下网址获取：https://github.com/shiming-chen/DoP。

## Abstract
Domain generalization (DG) aims to improve   the generalization of the model to any unseen domains. Targeting this goal, existing DG methods mainly focus on learning domain-invariant features or prompts from the given source domains. However, these methods rely on source-domain data, and collecting and annotating large-scale single- or multi-source datasets is often infeasible, limiting the practical applicability of DG. To tackle this challenge, we propose {\underline{Do}}main \underline{P}rompt Learning (DoP), a method built on a large vision-language model (e.g., CLIP) for zero-shot domain generalization, which recognizes unseen classes in unseen target domains without access to source-domain data. DoP essentially learns the target domain knowledge via prompt both in text and visual modalities to overcome the domain shift in text-visual modalities under the test-time adaptation formulation. Specifically, DoP first takes text domain learning (TDL) to simulate various distribution shifts by learning diverse style tokens implicitly in the text space with inter-style diversity loss and intra-style consistency loss. Subsequently, DoP employs visual domain learning (VDL) to further refine the target-domain-relevant style token generated by TDL by making use of the test visual data with self-supervised learning. Extensive experiments on popular DG benchmark datasets (e.g., PACS, VLCS, OfficeHome, and DomainNet) and ImageNet show that our DoP consistently outperforms the state-of-the-art DG approaches. Codes are available at: https://github.com/shiming-chen/DoP.

### 2. 论文提出的方法论
DoP 的核心思想是**在文本和视觉两个空间中联合学习目标域知识**，并通过测试时自适应（Test-Time Adaptation）框架动态选择和精炼提示。整体框架包含三大模块：
* **文本领域学习（TDL）**：
  * 在没有目标域数据的情况下，通过提示词在文本空间中隐式模拟各种分布偏移，生成一组风格 Token（$\{S_k\}_{k=1}^K$）。
  * 采用**风格间多样性损失（$L_{\text{diversity}}$）**（通过促使不同风格特征正交来减少冗余，增加覆盖面）和**风格内一致性损失（$L_{\text{consistency}}$）**（通过对比学习使同风格文本样本聚拢、异风格远离）来优化风格 Token。
  * 根据测试图像与各风格提示的余弦相似度，动态选择与当前测试图像最相关的目标风格 Token（$S^*$）。
* **视觉领域学习（VDL）**：
  * 针对文本空间学习可能存在的偏差，利用测试图像的视觉信息对选定的风格 Token $S^*$ 进行显式微调（即构建领域提示词 “A $S^*$ style of a [class]”）。
  * 通过自监督学习（基于增强视图预测的熵最小化，并利用置信度阈值过滤高熵噪声块），在测试时仅优化选定的风格 Token，而冻结预训练的 CLIP 编码器。
* **类别预测**：
  * 利用经过 VDL 精炼后的领域提示词输入 CLIP 的文本编码器，结合视觉编码器的特征，通过标准的余弦相似度和 Softmax 计算最终的类别预测概率。

### 6. 论文的主要结论与发现
* **无需源数据即可实现强泛化**：DoP 在不使用任何源域图像的情况下，在多个基准测试中表现出色，其平均准确率在多数主流数据集上超越了依赖源域数据训练的传统 DG 方法和现有的 VLM 零样本方法。
* **跨模态联合学习的有效性**：仅靠文本空间或视觉空间的自适应无法彻底解决跨模态偏移，而“文本空间多样化隐式学习 + 视觉空间测试时自适应精炼”的组合能够显著提升未见领域的识别准确率。
* **计算效率与效果的平衡**：通过动态选择最相关的单个风格 Token 进行针对性微调，既保证了适应能力，又大幅降低了测试时的计算冗余。

### 7. 优点
* **实用性强**：摆脱了对源域训练数据的依赖，完美契合现实世界中无法获取源数据的隐私或数据稀缺场景。
* **设计优雅**：巧妙地将文本空间的多样化风格合成与视觉空间的测试时自适应（TTA）结合，有效弥合了文本-视觉模态间的领域偏移。
* **高效性**：相比需要优化大量提示参数的测试时方法（如 TPT），DoP 仅对检索出的单个 Token 进行轻量级微调，兼顾了高性能与高效率。
