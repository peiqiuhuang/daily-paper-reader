## 摘要
文本技能可以扩展工具使用智能体的能力，但冗长的技能描述会增加计算成本。软提示词（Soft prompts）提供了一种紧凑的替代方案，然而从整个成功轨迹中学习也可能引入不必要的行为改变。我们发现，文本技能的有效作用高度集中在轨迹位置的一小部分子集上。基于这一观察，我们提出了行为定位（Behavioral Localization）方法，通过对比启用和未启用文本技能的冻结智能体，来识别技能既能增加成功标记（token）可能性又能对下一个标记分布产生有意义改变的位置。我们利用这些定位的位置来监督一个简短的软提示词。在使用冻结的 Qwen3.6-35B-A3B 智能体进行的 SpreadsheetBench 实验中表明，前 10% 的轨迹位置捕获了总正面技能收益的 96.12%。在共享提示词设置下，选择性监督将成功率从使用完整轨迹的 30.36% 提升至 36.79%。在任务特定条件下，使用前 10% 的定位位置实现了 57.38% 的成功率，优于完整文本技能以及策略内（on-policy）OPCD 基线。这些结果表明，一小部分与行为相关的轨迹位置可以为软技能提供有效的监督。

## Abstract
Text skills can extend the capabilities of tool-using agents, but long skill descriptions increase computational costs. Soft prompts provide a compact alternative, yet learning from entire successful trajectories may also introduce unnecessary behavioral changes. We find that the useful effect of a text skill is highly concentrated in a small subset of trajectory positions. Based on this observation, we propose Behavioral Localization, which compares the frozen agent with and without the text skill to identify positions where the skill both increases the likelihood of successful tokens and meaningfully changes the next token distribution. We use these localized positions to supervise a short soft prompt. Experiments on SpreadsheetBench with a frozen Qwen3.6-35B-A3B agent show that the top 10\% of trajectory positions capture 96.12\% of the total positive skill gain. In the shared prompt setting, selective supervision improves success from 30.36\% with full trajectory to 36.79\%. Under task-specific conditions, using the top 10\% localized positions achieves 57.38\%, outperforming both the full text skill and the on-policy OPCD baseline. These results show that a small set of behaviorally relevant trajectory positions can provide effective supervision of soft skills.

* **背景**：在工具使用智能体（Tool-Using Agents）中，通过自然语言文本技能（Text Skills）或长提示词来适配新任务虽能扩展能力，但会导致计算成本剧增、上下文开销变大，且容易受措辞敏感性影响。

### 2. 论文提出的方法论（核心思想与技术细节）
* **核心思想**：提出**行为定位（Behavioral Localization）**方法，通过对比基础智能体在“有文本技能”与“无文本技能”状态下的下一个 Token 概率分布，筛选出对技能学习真正起关键作用的稀疏轨迹位置，以此来监督短软提示词的训练。
* **关键步骤与形式化定义**：
  1. **定义三种条件下的 Next-Token 分布**：
     * $p_s^t = p_\theta(\cdot | S, x, \tau_{<t})$ （有文本技能）
     * $p_n^t = p_\theta(\cdot | x, \tau_{<t})$ （无文本技能/基础模型）
     * $p^t = p_\theta(\cdot | P, x, \tau_{<t})$ （软提示词）
  2. **正向增益（Positive Gain, $G_{it}$）**：衡量添加技能后，成功真实 Token ($y_t^i$) 概率提升的程度：
     $$G_{it} = \log p_s^t(y_t^i) - \log p_n^t(y_t^i)$$
  3. **分布偏移（Distributional Shift, $JS_{it}$）**：利用 Jensen-Shannon 散度衡量全词表下一个 Token 分布的变化：
     $$JS_{it} = \frac{1}{2} D_{KL}(p_s^t \parallel m_{it}) + \frac{1}{2} D_{KL}(p_n^t \parallel m_{it}), \quad m_{it} = \frac{1}{2}(p_s^t + p_n^t)$$
  4. **定位分数（Localization Score, $U_{it}$）**：结合上述两者计算综合得分 $U_{it} = G_{it} \cdot JS_{it}$，选择得分最高的前 $k\%$ 位置作为训练监督目标。
  5. **损失函数设计**：在选定的核心位置上最小化文本技能与软技能分布的 KL 散度；在未选定的保留位置上，以无技能模型作为行为锚点（Behavioral Anchor），减少不必要的行为漂移。
