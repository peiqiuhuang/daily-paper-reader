Abstract 

Federated Prompt Tuning (FPT) adapts large vision–language models by freezing the pretrained backbone and optimizing only lightweight prompt parameters across clients. Although this design improves communication and parameter efficiency, it creates an overlooked security risk. Since the backbone is shared and frozen, a malicious client can induce backdoor behavior through the representation space while keeping its uploaded prompt updates close to benign ones. We propose 

ShadowFPT , a targeted backdoor attack that exploits this frozen-backbone attack surface. ShadowFPT first pretrains a learnable Shadow Trigger against the frozen CLIP visual encoder, using either auxiliary public data or the malicious client’s local data, so that triggered inputs are steered toward the target class in representation space. During federated prompt tuning, the malicious client adapts the trigger under the current global prompt and then optimizes its local prompt on both clean and triggered samples. Only prompt parameters are uploaded to the server, while the trigger and frozen encoders remain local. By shifting most of the attack burden from prompt updates to trigger-induced representation steering, ShadowFPT achieves targeted misclassification while preserving prompt-space stealthiness. Across multiple datasets, aggregation rules, and non-IID federated partitions, ShadowFPT increases the attack success rate from 19.81% to 90.36% in our main setting, while maintaining clean accuracy. It remains effective across textual, visual, and joint vision–language prompt tuning. These results identify frozen backbones as stealthy and underexplored backdoor surfaces in federated prompt tuning, suggesting that defenses based only on prompt-update anomaly detection are insufficient. 

1 Introduction 

Large vision–language models (VLMs), such as CLIP Radford et al. [2021], learn transferable image–text representations and have become a standard foundation for multimodal recognition and adaptation. Adapting these models in distributed environments, however, remains difficult because full fine-tuning of large pretrained backbones is computationally expensive and communication-intensive. Prompt tuning addresses these limitations by keeping the pretrained backbone fixed and optimizing only a small set of learnable prompt parameters Khattak et al. [2023a]. This parameter-efficient formulation is particularly well suited to federated learning. In Federated Prompt Tuning 

(FPT), clients update lightweight prompts using private local data and communicate only prompt parameters to the server, while the VLM backbone remains frozen. Backdoor attacks remain a persistent security threat in federated learning. Classical attacks, such as BadNets Gu et al. [2017] and Blended Chen et al. [2017], poison training data with attacker-designed triggers, causing the trained model to retain high clean accuracy while predicting an attacker-specified target label on triggered inputs. In federated learning, malicious clients can further inject backdoors

through their local model updates, making attack persistence under server aggregation a central challenge. Prior work has studied this problem in standard and personalized federated learning, including A3FL Zhang et al. [2023] and Bad-PFL Fan et al. [2025]. Backdoor risks have also been examined in vision–language models and prompt learning. For example, BadCLIP attacks multimodal contrastive learning by guiding both visual and textual embeddings Liang et al. [2024]. However, backdoor attacks against federated prompt tuning remain insufficiently understood. In particular, existing studies largely overlook the security risk that arises when the server aggregates only lightweight prompt parameters while all clients rely on a shared frozen VLM backbone. Most federated backdoor defenses operate on the updates communicated by clients. Representa-tive methods identify updates that are close to the client majority Blanchard et al. [2017], remove coordinate-wise outliers Yin et al. [2018], downweight clients with highly similar update direc-tions Fung et al. [2018], calibrate client updates using trusted server data Cao et al. [2020], or combine clustering, clipping, noise injection, and certification to improve robustness Nguyen et al. [2022]. Recent work extends this update-centered view to federated prompt learning. For example, SABRE-FL detects malicious clients through anomaly analysis in embedding space Khan et al. [2025]. Despite their methodological differences, these defenses share a common assumption that backdoor behavior will manifest as detectable anomalies in uploaded updates or in representations derived from them. This assumption becomes fragile in FPT. The server observes only low-dimensional prompt updates, while the dominant representation geometry is determined by the shared frozen VLM backbone. A malicious client can therefore shift much of the backdoor effect to the interaction between the trigger and the frozen representation space, while keeping its uploaded prompt updates close to benign ones. This creates a security gap between where the backdoor behavior is realized and what the server can observe. The same frozen backbone that enables efficient adaptation also provides a stable and underexplored attack surface for stealthy backdoor injection. Motivated by this observation, we propose ShadowFPT , a targeted backdoor attack for federated prompt tuning that exploits the shared frozen CLIP visual encoder as a representation-level attack surface rather than relying on conspicuous prompt updates. ShadowFPT consists of two stages. First, it pretrains a learnable Shadow Trigger using either auxiliary public data or the malicious client’s local data. The trigger is optimized to steer triggered images toward the target class in the frozen CLIP representation space by aligning final image embeddings with the target text anchor and intermediate visual features with target-class layer-wise prototypes. Second, during federated training, the malicious client adapts the Shadow Trigger under the current global prompt and then optimizes its local prompt on both clean and triggered samples to implant the targeted backdoor. Only prompt parameters are uploaded to the server, while the trigger and frozen encoders remain local. By shifting much of the attack effect from uploaded prompt updates to trigger-induced representation steering, ShadowFPT achieves targeted misclassification while keeping malicious prompt updates close to benign updates. We evaluate ShadowFPT across multiple datasets, aggregation rules, and non-IID partitions. In the main setting, ShadowFPT improves attack success by 70.55 percentage points while largely preserving clean accuracy. It remains effective across textual, visual, and joint vision–language prompt tuning, and prompt-space analyses show that malicious updates stay close to benign ones. These results reveal frozen backbones as stealthy backdoor surfaces and challenge defenses based solely on prompt-update anomaly detection. The main contributions of this paper are as follows: • We identify a frozen-backbone backdoor surface in FPT, showing that targeted backdoor behavior can be realized through trigger-induced representation steering while malicious prompt updates remain close to benign updates. • We propose ShadowFPT , a targeted backdoor attack that shifts the attack burden from conspicuous prompt-space poisoning to representation-level manipulation of the shared frozen backbone. • We introduce the Shadow Trigger , a target-directed trigger learned through target-text alignment and layer-wise visual prototype alignment, enabling triggered images to move toward the target class in the frozen representation space. 2• We evaluate ShadowFPT across textual, visual, and joint vision–language prompt tuning under non-IID federated settings, demonstrating high attack success, minimal clean-accuracy degradation, and strong prompt-space stealthiness. 

2 Related Work 

Federated Prompt Tuning. Vision–language models (VLMs), such as CLIP, learn transferable image–text representations and provide strong foundations for multimodal adaptation Radford et al. [2021]. Prompt tuning adapts these models efficiently by freezing the pretrained backbone and optimizing only a small set of prompt parameters. Representative CLIP-based approaches include textual prompt tuning Zhou et al. [2022b,a], visual prompt tuning Jia et al. [2022], joint vision– language prompt learning Khattak et al. [2023a], and semantic regularization Khattak et al. [2023b]. This parameter-efficient paradigm naturally extends to federated learning, where clients communicate prompt parameters rather than full model updates. Recent studies on federated prompt tuning investigate cooperative prompt learning Guo et al. [2023b], personalization Guo et al. [2023a], text-driven prompt generation Qiu et al. [2024], personalization–generalization trade-offs Cui et al. [2024], mixture-of-experts prompts Luo et al. [2025], and multimodal visual prompt tuning Singha et al. [2025]. These works primarily focus on communication efficiency, personalization, and generalization under heterogeneous client data. In contrast, the security risks of federated prompt tuning, especially its vulnerability to backdoor attacks, remain insufficiently understood. 

Backdoor Attacks. Backdoor attacks aim to make a model behave normally on clean inputs while predicting an attacker-specified target label on inputs containing a trigger. Classical attacks achieve this behavior by poisoning training data with visible or blended triggers Gu et al. [2017], Chen et al. [2017]. In federated learning, the backdoor must also persist through local training and server aggregation, which has motivated attacks based on stealthy poisoned updates, persistent backdoor injection, adaptive optimization, collusive trigger design, and personalized federated learning Lyu et al. [2023], Zhang et al. [2022, 2023], Lyu et al. [2024a], Fan et al. [2025].Backdoor vulnerabilities have also been studied in vision–language models. For example, BadCLIP manipulates multimodal contrastive representations through visual and textual embedding guidance Liang et al. [2024]. Existing attacks, however, are largely built around data poisoning, model-update manipulation, or direct prompt-parameter poisoning. FPT presents a different regime in which both the trainable and communicated parameters are small, and local optimization is lightweight. These constraints leave limited capacity for conventional backdoor injection through uploaded updates, motivating our investigation of a more concealed representation-level attack surface. 

Backdoor Defenses. Federated defenses against malicious clients have largely followed the paradigm of Byzantine-robust aggregation. Classical methods, such as Krum Blanchard et al. [2017], Trimmed-Mean Yin et al. [2018], and Bulyan Guerraoui et al. [2018], mitigate malicious behavior by suppress-ing abnormal client updates through robust statistics and outlier filtering. Subsequent approaches improve robustness under heterogeneous or unreliable clients using geometric aggregation, trust bootstrapping, or sparsification Pillutla et al. [2022], Karimireddy et al. [2022], Cao et al. [2020], Xu et al. [2025]. Defenses designed specifically for federated backdoors further target poisoned global models. FLAME combines client clustering with model clipping Nguyen et al. [2022], while CRFL provides certified robustness against federated backdoors Xie et al. [2021]. Recent studies also investigate secure aggregation and detectability, privacy-constrained robustness under heterogeneity, system- and optimization-level mitigation, and dynamic behavior-based identification Huang et al. [2025], Zhang et al. [2025]. Despite their methodological differences, these defenses largely share the assumption that malicious behavior will appear as detectable abnormalities in uploaded updates or in representations derived from them. This assumption becomes fragile in FPT. Under non-IID data, benign prompt updates may vary substantially across clients, while the backdoor effect can be shifted into the interaction between the trigger and the shared frozen representation space rather than being exposed through conspicuous prompt updates. This gap motivates our investigation of frozen-backbone representation spaces as stealthy backdoor surfaces in federated prompt tuning. 33 Method

Threat Model. We consider a targeted backdoor attack against FPT with a frozen vision–language backbone. The adversary aims to preserve the clean accuracy of the global model while causing triggered inputs, xδ = A(x, δ ), to be classified as an attacker-specified target class yt. The malicious client has access to local target-class samples, denoted by Ryt , which are used to guide target-directed trigger optimization. During local training, the malicious client can optimize both its local prompt parameters and the trigger δ, but uploads only prompt parameters to the server. The adversary cannot modify the frozen image encoder, the frozen text encoder, the global training protocol, or the server-side aggregation rule. We assume a white-box threat setting in which the malicious client knows the frozen backbone architecture. 

3.2 Overview of ShadowFPT 

ShadowFPT backdoors FPT through a two-stage procedure. It first learns a Shadow Trigger against the frozen CLIP representation space, and then uses this trigger to implant targeted backdoor behavior during malicious local prompt training. Figure 1 provides an overview of the ShadowFPT. Before federated training, the adversary optimizes a learnable trigger δ on a pretraining dataset Ds,which can be either auxiliary public data or the malicious client’s local data. The optimized trigger, denoted by δshadow , is trained to steer triggered images toward the target class in the frozen CLIP representation space, as described in Section 3.3. During federated training, the malicious client initializes the trigger with δshadow and adapts it under the current global prompt, allowing the trigger to remain aligned with the evolving federated prompt. The adapted trigger is then applied to a subset of the malicious client’s local data, and the local prompt is optimized on both clean and triggered samples so that triggered inputs are classified as the target class. After local optimization, the malicious client uploads only the prompt parameters to the server, while the trigger remains local. This injection procedure is detailed in Section 3.4.

3.4 Backdoor Injection in FPT 

During federated training, ShadowFPT uses the pretrained Shadow Trigger to implant targeted backdoor behavior into the federated prompt. At communication round t, the malicious client receives the current global prompt P t from the server and initializes its local prompt as Pa ← P t. It then performs two sequential local steps. First, it adapts the trigger under the current global prompt. Second, it optimizes the local prompt on poisoned local data. 

Trigger adaptation. In the first attack round, the malicious client initializes the trigger with δshadow 

and then updates it locally across subsequent rounds. At round t, the prompt is fixed to the current global prompt P t, and only the trigger is optimized. We construct the target text anchor under the current global prompt as: z(t)target = fT (yt; P t). The trigger is adapted using the same representation-level objective as in Shadow Trigger pretraining: 

L(t)adapt = L(t)text + λlL(t)layer . (9) Here, L(t)text aligns triggered image embeddings with the current target text anchor z(t)target , while L(t)layer 

keeps intermediate visual features close to the target-class visual prototypes defined in Section 3.3. This step produces a prompt-adapted trigger δ(t).

4 Experiments 

4.1 Experimental Setup Federated Setting. All methods use a frozen CLIP model with ViT-B/16 as the backbone. Unless otherwise specified, we use textual prompt tuning as the default FPT setting, denoted by FPT-L Li et al. [2024]. To evaluate whether ShadowFPT transfers across different prompt parameterizations, we also consider visual prompt tuning (FPT-V) Jia et al. [2022] and joint vision–language prompt tuning (FPT-VL) Khattak et al. [2023a]. Following FedTPG Qiu et al. [2024], we simulate a non-IID federation with 20 clients. Each client holds samples from five classes, and the class sets are disjoint across clients. All clients participate in every communication round. Unless otherwise stated, a single client is malicious, and the target class is set to the first class of each dataset. All methods are trained for 20 communication rounds with one local epoch per round, batch size 32, and learning rate 0.0035 for local prompt optimization. We report clean accuracy (Acc) on benign test samples and attack success rate (ASR) on triggered non-target test samples. 

ShadowFPT Variants. We evaluate two variants of ShadowFPT that differ in the data used for Shadow Trigger pretraining. ShadowFPT-I pretrains the Shadow Trigger using only the malicious client’s local data, whereas ShadowFPT-II uses auxiliary public data, instantiated as 100 randomly sampled ImageNet classes. We do not assume semantic overlap between the auxiliary ImageNet classes and the downstream target classes. Both variants use a 32 × 32 trigger patch placed at the bottom-right corner of the image. The Shadow Trigger is optimized with learning rate 0.01 during pretraining and 0.001 during federated trigger adaptation. 6Datasets. We evaluate ShadowFPT and all baselines on Caltech101 Fei-Fei et al. [2004], Oxford Flowers Nilsback and Zisserman [2008], and UCF101 Soomro [2012]. These datasets cover generic object recognition, fine-grained flower classification, and human action recognition, respectively. 

Attack Baselines. We compare ShadowFPT with three groups of attack baselines. The first group includes generic backdoor attacks, namely BadNets Gu et al. [2017] and Blended Chen et al. [2017]. The second group includes federated backdoor attacks, namely Neurotoxin Zhang et al. [2022], A3FL Zhang et al. [2023], FCBA Liu et al. [2024], and CerP Lyu et al. [2023]. The third group includes personalized federated backdoor attacks, namely Bad-PFL Fan et al. [2025] and 

PFedBA Lyu et al. [2024b]. 

Defense Baselines. We evaluate defenses covering several aggregation and filtering mechanisms. The first category is standard aggregation, represented by FedAvg McMahan et al. [2017]. The second cat-egory is Byzantine-robust aggregation, including Krum Blanchard et al. [2017], TrimmedMean Yin et al. [2018], and Bucketing Karimireddy et al. [2022]. The third category includes adaptive or similarity-based filtering methods, namely LaSA Xu et al. [2025] and FoolsGold Fung et al. [2018]. We also evaluate trust-based aggregation with FLTrust Cao et al. [2020], as well as backdoor-specific defenses, including FLAME Nguyen et al. [2022] and CRFL Xie et al. [2021].

4.3 Ablation Study Role of Pretraining and Injection. We assess the roles of Shadow Trigger Pretraining and Backdoor Injection in FPT on Caltech101. As shown in Figure 4, Random Trigger achieves only 21.32% average ASR, indicating that an arbitrary trigger is insufficient to induce a strong backdoor. Shadow Trigger without Injection increases the average ASR to 49.75%, suggesting that pretraining already learns target-directed behavior in the frozen CLIP representation space, but remains fragile under defenses such as Krum (25.17%) and FLTrust (31.99%). The full ShadowFPT further raises the average ASR to 90.36%, with large gains under Krum (+59.54) and FLTrust (+60.55). These results show that pretraining provides a transferable initialization, while Backdoor Injection is necessary to convert it into a robust federated backdoor. 

Role of Representation-Level Alignment. We further examine the two representation-level objec-tives used in Shadow Trigger Pretraining. As shown in Figure 5, target-text alignment alone and layer-wise visual alignment alone achieve 66.38% and 59.25% average ASR, respectively, indicating that both provide useful target-directed guidance. However, each objective alone remains fragile under defenses, such as CRFL for Target-text Only (20.08%) and FoolsGold for Layer-wise Only (20.73%). In contrast, the full ShadowFPT objective reaches 90.36% average ASR, improving over the two single-objective variants by 23.98 and 31.11 percentage points. These results show that target-text alignment provides semantic target guidance, while layer-wise visual alignment stabilizes the triggered representation trajectory, together producing a more robust Shadow Trigger. 95 Conclusion 

This paper identifies a frozen-backbone backdoor surface in FPT. Unlike conventional federated backdoor attacks that rely primarily on anomalous uploaded updates, ShadowFPT exploits the shared frozen CLIP representation space and shifts much of the attack burden to trigger-induced representation steering. We propose a two-stage attack in which a Shadow Trigger is first pretrained through target-text and layer-wise visual alignment, and then adapted during FPT while only prompt parameters are uploaded to the server. Across multiple datasets, aggregation and defense rules, and textual, visual, and joint vision–language prompt tuning, ShadowFPT achieves consistently high targeted attack success with limited clean accuracy degradation. Prompt-space analyses further show that its malicious updates remain close to benign prompts, explaining why update-centered defenses are insufficient. Our results suggest that securing FPT requires moving beyond prompt anomaly detection and accounting for the interaction between triggers and frozen representation geometry. More broadly, this work highlights a security risk of FPT: freezing the backbone reduces trainable parameters, but does not eliminate backdoor attack surfaces.
