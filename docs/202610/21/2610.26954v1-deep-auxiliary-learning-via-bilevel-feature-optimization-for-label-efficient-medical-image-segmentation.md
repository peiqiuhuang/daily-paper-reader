## 摘要
辅助学习（AL）可以通过利用相关的辅助任务来提升主任务的性能，通常被认为是多任务学习的一种特殊情况。现有的辅助学习方法通常需要人工标注的辅助标签，这增加了标注成本，在专家标注成本高昂的医学图像领域尤为明显。在这项工作中，我们研究了是否可以使用其标签自动衍生自现有分割标注的辅助任务来提升分割性能，从而无需额外的人工标注。为此，我们提出了一种新颖的辅助学习框架，将其构式化为一个双层优化问题。我们的方法通过特征通信模块实现任务之间的高效知识迁移，从而增强主要的分割任务。我们在有限标签设置下的三个医学图像分割基准上对该方法进行了评估。结果表明，该方法在性能上持续优于现有最先进的方法，实现了卓越的标签效率。代码已在 https://github.com/FupingWu90/ALBO 公开。

## Abstract
Auxiliary learning (AL), which can improve the performance of a primary task by leveraging related auxiliary tasks, is commonly regarded as a special case of multi-task learning. Existing AL approaches typically require manually annotated auxiliary labels, increasing annotation costs, particularly in medical imaging where expert labeling is expensive. In this work, we investigate whether segmentation performance can be improved using auxiliary tasks whose labels are automatically derived from existing segmentation annotations, requiring no additional manual labeling. To address this, we propose a novel auxiliary learning framework, formulated as a bilevel optimization problem. Our method enables effective knowledge transfer between tasks via a feature communication module, enhancing the primary segmentation task. We evaluate the method on three medical image segmentation benchmarks under limited-label settings. The results demonstrate consistent improvements over state-of-the-art methods, achieving superior label efficiency. The code is publicly available at https://github.com/FupingWu90/ALBO.

    *   将主分割任务置于上层（目标任务），辅助任务置于下层。通过不对称的优化目标，确保辅助分支的更新仅在有利于主任务的前提下进行，以此防止负迁移。
