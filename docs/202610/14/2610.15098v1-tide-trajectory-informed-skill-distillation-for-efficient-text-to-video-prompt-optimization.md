## 摘要
文本转视频（T2V）模型对提示词的具体性高度敏感，而迭代提示词优化通常仅在推理时通过重复的视频生成和视觉-语言模型评估来提升生成质量。我们提出了 TIDE 框架，该框架将这种高昂的搜索过程蒸馏为一种可解释且可复用的提示词重写“技能”。TIDE 将提示词重写建模为一组源条件规则模块，每个模块针对不同的语义维度。蒸馏完成后，冻结的技能只需调用一次大语言模型（LLM）即可激活相关规则并同时生成正向与负向提示词，随后仅需进行一次 T2V 生成，无需测试时视觉搜索或骨干网络微调。TIDE 仅使用 100 个提示词经过 14 小时的演化，就实现了与计算成本高昂的基于搜索的方法相当的提示词优化性能。此外，当迁移到先前未见过的视频生成模型时，TIDE 的表现优于专门为这些模型设计或训练的现有方法。代码可在 https://github.com/xiningin/TIDE_T2V 获取。

## Abstract
Text-to-video (T2V) models are highly sensitive to prompt specificity, while iterative prompt optimization typically improves generation quality only through repeated video generation and vision-language model evaluation at inference time. We propose TIDE, a framework that distills this costly search process into an interpretable and reusable prompt-rewriting Skill. TIDE formulates prompt rewriting as a set of source-conditioned rule modules, each targeting a distinct semantic dimension. Once distilled, the frozen Skill activates the relevant rules and generates both positive and negative prompts in a single LLM call, followed by only one T2V generation, without test-time visual search or backbone fine-tuning. Evolved using only 100 prompts over 14 hours, TIDE achieves prompt-optimization performance comparable to computationally expensive search-based methods. Moreover, when transferred to previously unseen video-generation models, TIDE outperforms existing approaches specifically designed or trained for those models. Code is available at https://github.com/xiningin/TIDE_T2V.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
TIDE 的核心思想是将昂贵的迭代优化“轨迹”蒸馏为可解释、可复用的提示词重写“技能”（Skill），分为技能架构、轨迹生成和经验蒸馏三个阶段：

* **核心思想与架构（Skill Architecture）**：
  * 放弃单一的整体重写策略，将技能分解为多个独立的**语义维度**（如动作规范、镜头构图、身份保持、意图等）。
  * 技能由系统提示词、源触发器规范（Source-trigger specifications）和规则模块集合组成。
  * 公式化表示为修订 $t$ 下的元组：$S^{(t)} = \left( s_{\text{sys}}, \{r_d^{(t)}\}_{d \in D} \right)$，其中每个规则 $r_d^{(t)} = (\tau_d, a_d, \iota_d, \nu_d, \kappa_d)$ 包含触发谓词、责任轴、重写指令、负向提示词的条件构件项以及能力范围。
* **推理流程（Prompt Rewriting）**：
  * 给定原始提示词 $x$，触发匹配器（Trigger Match）评估激活相关的语义维度规则。
  * 冻结参数的 LLM 重写器仅调用一次，结合激活的规则同时生成增强的正向提示词 $p^+_{\text{en}}$ 和规则条件化的负向提示词 $n_{\text{en}}$。
  * 随后仅进行**单次 T2V 视频生成**，无须测试时的视觉搜索或骨干网络微调。
* **迭代优化轨迹生成（Trajectory Generation）**：
  * 借鉴 VISTA 的视觉反馈循环，从初始提示词开始渲染视频，裁判打分并提供批评，反思者转化为建议，通过多候选锦标赛选择下一轮候选。
  * 保留完整的优化记录（轨迹 $T_i$）作为后续蒸馏的丰富监督信号（包含中间批评、建议、候选对比等）。
* **经验聚合规则精炼（Experience-Aggregated Rule Refinement）**：
  * 提出“Patch Proposer”（补丁提出者）从轨迹中提取可复用的维度特定补丁。
  * 为防止单一样例的噪声导致不稳定，补丁被存入独立的维度特定补丁池 $Q_d$ 中。当池中累积满 $B$ 个补丁时，规则优化器通过公式 $r_d^{(t+1)} = \mathcal{U}(r_d^{(t)}, Q_d[:B])$ 将其合成为完整的规则替换。
  * 引入**抗饥饿调度策略（Anti-Starvation）**，优先更新最久未更新的规则，平衡各维度的优化。

### 6. 论文的主要结论与发现
* **高效性与性能兼顾**：TIDE 仅需 100 个提示词和 14 小时的单次演化，便能将迭代搜索（如 VISTA）的经验蒸馏到紧凑的技能中，在不进行测试时视觉搜索的前提下，达到甚至略微超越高计算成本迭代搜索方法的性能（VBench2 平均分 78.60 vs 78.37）。
* **出色的跨模型泛化能力**：在单个模型（SANA-Video）上训练得到的重写技能，可以直接零样本迁移（Zero-shot Transfer）到未见过的视频生成模型（如 Wan2.2 和 CogVideoX1.5），并在多数控制导向维度（如多对象理解、人类动作、空间关系）上超越专门为这些模型设计或微调的现有方法。
* **负向提示词蒸馏至关重要**：消融实验证明，维度条件化的负向提示词蒸馏对整体性能影响最大（缺失时平均分下降 1.84），能够有效抑制结构与时间伪影。

### 7. 优点：方法或实验设计上的亮点
* **开创性的“轨迹蒸馏”思路**：跳过了传统直接拟合初始与优化终点的方法，充分利用了中间的批评、建议、锦标赛对比等多维反馈轨迹，监督信号更丰富。
* **可解释与模块化设计**：将复杂的提示词重写解耦为独立的源触发规则模块，不仅避免了整体策略的黑盒化，还便于规则的针对性更新和审计。
* **推理高效且模型无关（Model-Agnostic）**：推理时仅需单次 LLM 调用和单次视频生成，完美摆脱了测试时繁重的视觉搜索循环，极具工业界落地实用价值。

### 8. 不足与局限
* **长尾维度训练不足**：由于蒸馏自仅有 100 个提示词的小规模轨迹集，那些触发频率较低的语义维度规则可能未得到充分精炼（Under-refined）。
* **潜在偏差风险**：蒸馏出的规则可能不可避免地带有特定训练主干模型（SANA-Video）或评估裁判模型（Qwen3.6-35B）的固有偏见。
* **模态单一**：当前框架仅聚焦于纯文本到视频的视觉优化，尚未涉及音频感知的视频生成优化。
