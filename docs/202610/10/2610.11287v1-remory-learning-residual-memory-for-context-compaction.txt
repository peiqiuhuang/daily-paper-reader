Abstract 

Long-horizon agents compact their history to continue within a finite context window, but a textual summary alone may not support every subsequent decision. We introduce R EMORY , a neural memory network that supplements the summary with a bounded sequence of soft memory tokens. Given the history and summary, the network learns to generate tokens that help a frozen LLM approximate the continuation it would produce with the full history. The tokens are conditioned on the summary and appended after it, forming an analogue of a residual connection along the sequence dimension. On SummHay, R EMORY 

improves source attribution at nearly unchanged insight coverage and approaches the full-context joint score using only 5.2% of the input positions. Across long-horizon agent benchmarks, Qwen3.8-27B and GLM-5.3-Flash show consistent gains with residual memory. Both models also exhibit substantially fewer repeated tool outputs and tool errors on BrowseComp and Terminal-Bench 2.1. 

# 1 Introduction 

Long-horizon agents work within a finite context window. As observations, tool outputs, and decisions accumulate, they must compact their history to continue. A common practice today is to replace earlier interaction with a textual summary. For example, popular coding agents such as Claude Code and Codex CLI provide /compact to free context space (Anthropic, 2026; OpenAI, 2026a). The summary becomes a checkpoint from which the agent resumes its work. Input length follows a sawtooth pattern: it grows with interaction, drops at compaction, and grows again (Figure 2a). A textual checkpoint changes how prior context is available to the agent. Preserving the main thread does not guarantee that the summary will support every subsequent decision, and the relevance of earlier context can change as the task unfolds. We do not assume that the information needed beyond the summary can be identified or enumerated in advance. The challenge is to sustain useful access to prior context across compaction without keeping the entire interaction in the active window. Human cognition illustrates how a limited active workspace can support sustained work. While contemporary agent contexts span roughly 0.2–1.0 million token positions, human working memory holds only a few chunks under controlled conditions (Baddeley, 2012; Cowan, 2001). Yet people can pursue complex projects over months or years, repeatedly drawing on details, experience, and learned skills in long-term memory (Ericsson & Kintsch, 1995; Squire & Dede, 2015). This ability depends on access to stored knowledge as well as active maintenance. We introduce R EMORY , a neural memory network for context compaction. Given a history and its generated summary, we train the network to generate a bounded sequence of soft memory tokens that can be appended after the summary, helping a frozen LLM approximate the continuation it would produce with the full history. We call this residual memory because the soft tokens are both conditioned on the summary and appended after it, forming an analogue of a residual connection along the sequence dimension. The summary supplies a readable checkpoint, while the learned tokens supplement it during subsequent decisions. Exact records remain accessible through ordinary archive and file-retrieval tools. On SummHay, residual tokens improve source attribution at nearly unchanged insight coverage. This supports an associative interpretation: the memory helps connect recovered claims to supporting evidence. Across long-horizon agent benchmarks, Qwen3.8-27B and GLM-5.3-Flash show consistent gains with residual memory. Residual memory also reduces repeated tool outputs and tool errors for both models on BrowseComp and Terminal-Bench 2.1. 2.1 A memory supplement to the summary 

Residual memory is constructed by conditioning on a generated summary and appending learned soft tokens after it (Figure 3(a,b)). At compaction boundary i, Hi contains the previous summary and residual memory, when present, together with the interaction since the last boundary. Given the new summary Si, the memory network constructs 

Mi = Cϕ(Hi; Si), |Mi| ≤ m. (1) 

Mi is a sequence of vectors in the frozen actor’s input space. The concatenation [Si; Mi] forms an analogue of a residual connection along the sequence dimension. The actor reads persistent instructions, this sequence, and then new interaction. The same process repeats at later compactions, allowing memory to carry information across successive boundaries. Archive excerpts enter through ordinary tool results. The network uses frozen actor features and learned queries to predict memory vectors in parallel, with gated cross-attention to the summary. Each block of up to 1,024 source positions produces 64 soft tokens. Hierarchical compression bounds the final memory at 4,096 slots while preserving source order. Source encoding and intermediate representations may be larger. For Qwen3.8-27B, we adapt the DFlash architecture (Chen et al., 2026); for GLM-5.3-Flash, we use DFlash-2 with grouped dynamic convolutions (Inco AI, 2026). The resulting memory networks have 1.94B and 1.502B trainable parameters, respectively. Their output is continuous memory rather than vocabulary tokens. Gradients through the frozen actor train this interface without changing the actor’s parameters.

Stage I: reconstruction. The teacher receives a source passage and an instruction to repeat it. The student replaces the passage with its soft memory and receives the same instruction. Both predict the source text, teaching the memory network to preserve source information. We use text fields from MMFineReason-Full-2.3M (Lin et al., 2026). 

Stage II: summary-conditioned continuation. Starting from Stage I, the teacher receives the original interaction history. The student receives the corresponding fixed summary and memory constructed from that history. Both predict the same subsequent assistant response. The memory encoder never receives the future response. This stage uses reasoning and coding trajectories, including prompts from Open-PerfectBlend (Labonne, 2024), with precomputed summaries and Qwen-generated responses. Examples follow a curriculum ordered by preceding-context length. In both stages, the teacher and student share the same frozen actor pθ. # 3 Experiments 

3.1 Source attribution after compaction 

SummHay evaluates query-relevant insight recovery and source attribution from long document collec-tions (Laban et al., 2024). We evaluate all 92 queries from ten collections with Qwen3.8-27B under four representations: raw context, summary alone, summary plus an additional text supplement (summary++), and summary plus residual memory. Summary++ uses the same additional-position budget as the memory condition. The actor, query, decoding, and base summary are fixed across the compacted conditions. Answer generation has no tools, archive access, or source retrieval; gold insights and citations are used only for scoring. Coverage measures recovered insights; citation F1 measures attribution; the joint score combines both. We use GPT-5.6-Sol with the benchmark coverage prompts. Coverage and joint score average over all 621 reference insights, while citation F1 averages over covered insights. 3.2 End-to-end agent performance 

We evaluate BrowseComp research tasks (Wei et al., 2025), Terminal-Bench 2.1 command-line tasks (Merrill et al., 2026), AutomationBench workflows (Shepard & Salimans, 2026), and JobBench professional tasks (Li et al., 2026b). Each within-actor comparison holds weights, the Codex CLI harness, prompts, tools, decoding, budgets, and compaction policy fixed; both configurations can retrieve exact history. Qwen and GLM use 262,144-position and one-million-position context windows, respectively. The intervention adds up to 4,096 residual slots at compaction. We use the full task sets: 1,266 BrowseComp and 89 Terminal-Bench tasks for both actors (one run), and 600 AutomationBench and 65 JobBench tasks for Qwen (five runs). Terminal-Bench and AutomationBench use task verifiers; BrowseComp and JobBench use matched GPT-5.6-Sol judges. Residual checkpoints complete both training stages. Qwen improves by 9.8 points on AutomationBench and 7.6 on JobBench (Table 2), extending the gains to business workflows and professional-task rubric credit. It gains 4.5 points on Terminal-Bench and 3.0 on BrowseComp; GLM gains 3.3 and 4.1, respectively (Table 3). The improvements therefore also hold for a stronger actor with a larger context window. Published frontier scores in Figure 1 provide context; the controlled evidence comes from the within-actor comparisons. Repeated tool outputs fall by 17.9–29.8% and errors by 25.3–49.7% across the four actor–benchmark pairs in Table 3. 3.3 The first action after compaction 

We examine 488 paired next actions from 100 sampled Qwen BrowseComp trajectories, holding the persistent prompt and summary fixed. Following rubric-based planning evaluation (Yu et al., 2026), GPT-5.6-Sol compares anonymized actions against criteria fixed from the preceding history. Candidate reasoning is withheld and counterfactual calls remain unexecuted. Residual actions receive 345 wins (70.7%), 21 ties (4.3%), and 122 losses (25.0%). With the checkpoint fixed, the preference links the memory channel to the first post-compaction decision. It is a judgment of proposed actions, not a measurement of the outcomes those counterfactual actions would have produced. 

3.4 Case studies 

Live Trading. Live Trading follows two concurrent Qwen paper-trading accounts under the same context policy. At the September 23 cutoff, settled ROI is −11 .86% without residual and +5 .11% with it; logged generation costs are $303.81 and $170.30. ROI counts resolved markets against an initial $20,000 bankroll. These two trajectories differ in market selection and timing, limiting return comparisons. Both accounts retain the growth-and-reset pattern (Figure 4). Compactions fall from 56 to 45 alongside fewer responses (5,336 versus 3,013). Per 1,000 responses, compactions instead rise from 10.5 to 14.9: the lower total accompanies less interaction. Mean live context decreases from 105,372 to 101,185 positions including memory. Fewer calls and smaller contexts explain the lower generation spend in this record.

# 4 Related Work 

Agent memory often combines summaries with retrieval. ReadAgent pairs episode gists with original passages, while MemGPT separates working and archival memory (Lee et al., 2024; Packer et al., 2023). ReSum uses periodic summaries for long-horizon search; AgentFold learns multi-scale context management within agent trajectories (Wu et al., 2025; Ye et al., 2025). R EMORY keeps the textual checkpoint and retrieval interface, and learns an additional continuous representation conditioned on the checkpoint. AutoCompressors, Gist Tokens, and ICAE learn continuous representations of longer text (Chevalier et al., 2023; Mu et al., 2023; Ge et al., 2024). LCLMs scale encoder–decoder compression and support selective expansion of compressed segments (Li et al., 2026a). Distribution matching provides a behavioral criterion for prompt compression (Wingate et al., 2022); recurrence and memory tokens retain information across segments (Dai et al., 2019; Bulatov et al., 2022). Our objective applies this predictive criterion to the information gap left by a summary, training the supplement through a frozen actor’s continuation predictions. 

# 5 Conclusion 

REMORY learns a bounded memory supplement for contextual compaction. The summary provides a readable account of prior work, soft tokens carry additional predictive information, and retrieval supplies exact records when needed. Reconstruction followed by summary-conditioned continuation trains this interface while leaving the actor unchanged.
