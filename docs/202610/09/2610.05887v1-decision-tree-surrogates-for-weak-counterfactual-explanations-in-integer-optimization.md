## 摘要
反事实解释（CEs）的概念近期在推导数学优化问题的解释方面受到了越来越多的关注。对于给定的问题，反事实是指对可变问题参数进行理想的最小化更改，使得更改后的问题存在满足某些期望准则的最优解。研究表明，所谓的弱反事实解释可以通过求解一个计算量巨大的双层优化问题来计算，当决策变量和可变参数被限制为整数时，该问题是 Σ_2^p 完全的。因此，已知的精确求解方法预计难以处理实际规模的问题。在这项工作中，我们推导了一种快速启发式算法，通过决策树来近似反事实解释问题的可行域，从而能够更快速地计算出反事实解释。为此，我们分析了可行域的数学结构，并开发了一种人工设计的决策树，其分割方式模拟了这一结构。此外，我们还开发了几种技术来提高该方法的性能。通过对背包问题和设施选址问题的计算实验，验证了我们方法的实用性。

## Abstract
The concept of counterfactual explanations (CEs) has recently gained increasing attention for deriving explanations of mathematical optimization problems. For a given problem, a counterfactual is an ideally minimal change in the mutable problem parameters such that an optimal solution of the changed problem exists fulfilling some desired criterion. It was shown that so-called weak CEs can be calculated by solving a computationally demanding bilevel optimization problem, which is $Σ_2^p$-complete if decision variables and mutable parameters are restricted to integers. Hence, the known exact solution methods are expected to fail on practically relevant problem sizes. In this work we derive a fast heuristic algorithm by approximating the feasible region of the CE problem with a decision tree for which CEs can be calculated more quickly. To this end we analyze the mathematical structure of the feasible region and develop a hand-crafted decision tree which applies splits imitating this structure. Additionally, we develop several techniques to increase the performance of our method. The practicability of our methods is supported by computational experiments on the knapsack problem and the facility location problem.
