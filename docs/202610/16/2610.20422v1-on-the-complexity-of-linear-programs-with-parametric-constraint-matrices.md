## 摘要
尽管针对右端向量含参数的线性规划的灵敏度分析已经十分成熟，但涉及含参数约束矩阵的情况却鲜有研究。为了填补这一空白，我们研究了约束矩阵线性依赖于某个标量参数的线性规划。我们的目标是在固定的参数范围内计算这些参数化线性规划的最小和最大最优值。这相当于求解两个双层规划。通过证明其NP困难性以及属于NP类，我们表明这两个优化问题的判定版本都是NP完全的。此外，我们确定了参数矩阵的三个充分条件，在这些条件下，双层规划不再具有NP困难性。我们为这两个问题引入了一种重新表述方法，连同用于低层可行性条件的基于Farkas的证书，并比较了在标准基准实例上求解它们的执行时间。实验突显了一个实际的二分性。尽管两个双层优化都是NP困难的，但计算与线性规划最小值相对应的参数值是快速的，而计算与最大值相对应的值则不然。我们将这种不对称性与参数化等式约束联系起来，其自由对偶变量使得最大化重新表述的松弛保持无界。

## Abstract
While sensitivity analysis for linear programs with parametric right- hand side vectors is well established, cases involving parametric constraint matrices remain less explored. To address this gap, we investigate linear programs where the constraint matrix depends linearly on a scalar parameter. Our goal is to compute the minimum and maximum optimal values of these parametric linear programs within a fixed parameter range. This corresponds to solving two bilevel programs. We show that both decision versions of these optimization problems are NP-complete by proving both NP-hardness and membership in NP. We additionally identify three sufficient conditions on the parametric matrix under which the bilevel programs are no longer NP-hard. We introduce a reformulation for both problems, together with a Farkas-based certificate for the lower-level feasibility condition, and compare the execution time for solving them on standard benchmark instances. The experiments highlight a practical dichotomy. Although both bilevel optimizations are NP-hard, computing the parameter value corresponding to the minimum of the linear program is fast, whereas computing the value corresponding to the maximum is not. We relate this asymmetry to the parametric equality constraints, whose free dual variables leave the relaxation of the maximum reformulation unbounded.

### 6. 论文的主要结论与发现
* **计算复杂性不对称（Pragmatic Dichotomy）**：虽然理论上 Min-Min 和 Max-Min 都是 NP-hard，但在实际求解中表现出极大的不对称性：Min-Min 问题绝大多数可以快速求解（中位数时间小于 1 秒），而 Max-Min 问题的重构求解非常困难（仅不到一半能证明最优）。
* **根源在于等式约束**：难解的实例几乎全部包含“参数化等式约束”。由于等式约束对应的对偶变量是自由变量，导致 McCormick 松弛下的双线性项无界，求解器无法提供有限的对偶边界。
* 施加人工对偶变量边界（Box）虽然可以让求解器快速收敛，但会将问题转化为一个松弛近似模型。

### 7. 优点
* **理论完整**：不仅给出了严格的 NP-complete 证明（包含多项式时间可验证证书），还通过 Farkas 引理严谨地处理了双层规划中常被忽略的下层可行性边界问题。
* **洞察深刻**：成功解释了理论 NP 困难性与实际求解难度之间的差异，并将难点精准定位到“参数化等式约束引起的对偶变量无界性”上。

### 8. 不足与局限
* **求解局限性**：通用的全局优化求解器（如 Gurobi）在面对含有自由对偶变量的双线性重构模型时效率低下，现有的精确重构方法在含有参数化等式约束的大规模实例上缺乏实用性。
* **近似与精确的权衡**：虽然引入对偶变量边界（Box）可以解决求解停滞问题，但这改变了原问题的本质，导致结果变为近似下界而非精确解。
