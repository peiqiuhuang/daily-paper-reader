## 摘要
提示微调（Prompt tuning）通过冻结预训练骨干网络并仅更新一小部分可学习的提示，提供了一种参数高效的基础模型（FMs）微调方法。这一特性使得提示微调特别适用于去中心化联邦学习（DFL），因为在去中心化联邦学习中交换全模型更新的成本可能极其高昂。然而，在 DFL 中应用提示微调引入了新的挑战。从异构本地数据中学习到的提示集可能无法按索引对齐，导致标准的去中心化平均算法不再适用。此外，算法在理论上应能保证达成共识，并朝着共享目标方向取得进展。在这项工作中，我们首次对 DFL 中的提示微调进行了研究。我们将去中心化提示微调形式化为提示度量上基于 Wasserstein 距离的优化问题，从而捕获了提示的集值结构。随后，我们提出了 D-FROST，这是一种基于最优传输（OT）的去中心化提示微调算法，它通过基于传输的匹配将邻域提示合并为紧凑的代表性提示集。我们进一步分析了 D-FROST，界定了客户端之间的 Wasserstein 共识误差，并建立了网络级提示重心收敛至平稳点邻域的收敛性。在异构客户端数据上的实验证明了 D-FROST 在去中心化提示微调中的有效性。

## Abstract
Prompt tuning provides a parameter-efficient way to adapt foundation models (FMs) by freezing the pretrained backbone and updating only a small set of learnable prompts. This property makes prompt tuning especially suitable for decentralized federated learning (DFL), where exchanging full-model updates can be prohibitively expensive. However, prompt tuning in DFL introduces new challenges. Prompt sets learned from heterogeneous local data may not be index-wise aligned, making standard decentralized averaging unsuitable. In addition, the algorithm should be theoretically guaranteed to achieve consensus and make progress toward the shared objective. In this work, we provide the first study of prompt tuning in DFL. We formulate decentralized prompt tuning as a Wasserstein-based optimization problem over prompt measures, which captures the set-valued structure of prompts. We then propose D-FROST, an optimal-transport-based (OT-based) decentralized prompt-tuning algorithm that merges neighborhood prompts into compact representative prompt sets through transportation-based matching. We further analyze D-FROST by bounding the Wasserstein consensus error across clients, and establishing convergence of the network-level prompt barycenter to a neighborhood of stationarity. Experiments under heterogeneous client data demonstrate the effectiveness of D-FROST for decentralized prompt tuning.

### 2. 核心方法论（D-FROST 算法设计与理论）

#### 核心思想
将去中心化提示词微调重新形式化为 **Wasserstein 概率度量空间上的优化问题**。将每个客户端维护的提示词集合视为提示词嵌入空间上的离散经验概率分布，通过最优传输（Optimal Transport, OT）几何匹配邻域提示词，替换传统的坐标平均。

#### 关键技术流程与算法框架（D-FROST）
在每一轮通信中，每个客户端 $u$ 执行以下步骤：
1.  **本地提示词更新（Local Update）**：客户端冻结骨干网络，使用本地数据对可学习提示词集 $\tilde{\omega}_u^{(t)}$ 进行多步梯度下降更新。
2.  **邻域信息交换（Neighbor Exchange）**：客户端与通信图拓扑中的邻居节点交换更新后的提示词，构建本地邻域提示词集合 $\Omega_u^{(t)}$。
3.  **基于 OT 的提示词融合（OT-based Merge Step）**：
    求解一个带熵正则化和 $L_2$ 正则化的最优传输匹配问题，将庞大的邻域提示词集合降维融合为固定预算（$n$ 个）的代表性提示词集 $\Phi = \{\phi_i\}_{i=1}^n$。该过程采用交替优化求解：
    *   **传输步骤（Transport Step）**：固定代表性提示词，根据空间匹配距离 $C_{ai} = \frac{1}{2\sigma^2}\|z_a - \phi_i\|^2$ 和熵正则化系数 $\varepsilon$，通过 Softmax 闭式解计算邻域提示词到代表性提示词的软分配传输矩阵 $P^{(s)}$。
    *   **重心步骤（Barycenter Step）**：固定传输矩阵 $P^{(s)}$，利用加权平均和 $L_2$ 正则项（系数 $\lambda$）闭式更新代表性提示词向量 $\phi_i^{(s)}$。

#### 理论分析与保障
*   **局部 OT 求解器的稳定性**：证明了交替 OT 求解器在 $S$ 次内迭代后，相邻迭代间的更新量以 $O(1/\sqrt{S})$ 的速率衰减（定理 1）。
*   **Wasserstein 网络共识界**：证明了客户端之间的 Wasserstein 共识误差 $\epsilon^{(t)}$渐进收敛于一个有界邻域，其界的大小取决于邻域融合近似误差 $\delta_n^2(S)$、本地梯度方差以及网络图的谱混合因子 $\rho$（定理 2）。
*   **全局平稳性收敛**：证明了网络级提示词重心在 $T$ 轮通信后，能以 $O(1/T)$ 的速率收敛至 Wasserstein 平稳点的有界邻域内（定理 3）。

### 3. 实验设计

*   **数据集与划分**：
    *   **FourDataset**：涵盖 MNIST-M, Fashion-MNIST, CINIC-10, MMAFEDB 4 个视觉域，共 37 个类别，部署于 40 个客户端。
    *   **FiveDataset**：涵盖 CIFAR-10, MNIST, Fashion-MNIST, SVHN, NotMNIST 5 个域，共 50 个类别，部署于 50 个客户端。
    *   **数据异质性设置**：Dirichlet 分布划分（$\alpha=0.5$ 和极端偏斜的 $\alpha=0.1$）以及**极端 Non-IID 分割**（每个客户端 99% 的数据集中在单一类别）。
*   **骨干网络与设置**：预训练 ViT-B/32（冻结），附加 $n=10$ 个维度为 $d=768$ 的可学习提示词 Token。
*   **基线方法（Baseline）**：
    *   **D-PSGD-PT**（去中心化并行 SGD 的提示微调版）
    *   **DFedAvgM-PT**（带动量的去中心化联邦平均的提示微调版）
    *   **DFedSAM-PT**（基于锐度感知最小化的去中心化联邦提示微调版）
    *   此外，在消融实验中还对比了结合 L2P 提示词选择机制的改进增强版基线（+ 标识）。
*   **网络通信拓扑**：环形拓扑（Ring）、网格拓扑（Grid）、Erdős-Rényi 随机图、$\kappa$-正则图（默认随时间动态采样），以及全连接图（Fully Connected）。

### 5. 核心实验结果与主要发现

*   **准确率显著提升**：
    *   在 FourDataset 和 FiveDataset 的各类 Non-IID 划分（$\alpha=0.5, \alpha=0.1$ 以及极端单类别倾斜）下，D-FROST 的分类准确率均显著超越传统加权平均基线（如 D-PSGD-PT、DFedAvgM-PT 和 DFedSAM-PT）。
    *   即便是与集成了提示词选择机制增强后的基线相比，D-FROST 依然保持明显的性能优势，验证了基于最优传输进行提示词几何匹配与降维融合的有效性。
*   **对网络拓扑的高鲁棒性**：
    *   在环形（Ring）、网格（Grid）、随机图（ER）及 $\kappa$-正则图等多种去中心化拓扑结构下，D-FROST 均展现出稳定的收敛速度和高准确率。
    *   拓扑连通度增加（如邻居数 $\kappa$ 增大）能进一步提升收敛性能，但即便在稀疏拓扑（如环形网络）中，D-FROST 也能维持较强抗漂移能力。
*   **消融实验分析**：
    *   **求解迭代次数 $S$**：局部 OT 求解器仅需较少内迭代次数（如 $S=3 \sim 5$）即可达到稳定效果，过度增加迭代次数对性能提升边际效应递减。
    *   **提示词数量 $n$**：适当增加客户端维护的提示词预算可提供更强的语义表达能力，但超出阈值后性能渐趋平稳，表明算法在较小提示词规模下即可捕获关键领域特征。

### 6. 方法优势、局限性与未来方向

*   **核心优势**：
    1.  **创新性解决对齐难题**：首次将最优传输（OT）引入去中心化联邦提示微调，从几何度量层面解决了无序提示词集的错位问题。
    2.  **通信与计算极轻量**：仅交换小尺寸提示词向量，OT 降维融合的额外计算时间占比极低，非常适合资源受限边缘设备。
    3.  **理论与实证兼备**：提供了严格的 Wasserstein 视角下的网络共识界与平稳点收敛性证明。

    2.  **模态扩展性**：实验主要基于视觉大模型（ViT）验证，尚未在大型语言模型（LLM）或多模态图文交错任务上展开全面测试。
