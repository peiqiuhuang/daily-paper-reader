## 摘要
双层混合整数线性优化问题对分层决策过程进行建模，其中领导者预判追随者的最佳响应。尽管这类问题具有很强的表达能力，但由于下层最优性被嵌入在领导者的可行域中，其计算极具挑战性。值函数重构方法通过包含追随者最优值的约束来替换嵌套的追随者优化，但精确评估该值函数本身可能代价高昂。本文介绍了 Graph4BiLO，这是一种利用图神经网络（GNN）从变量-约束图表示中学习双层值函数的方法。与固定长度的多层感知器（MLP）表示相比，GNN 使用共享的消息传递参数，因此可以使用单个训练好的模型应用于多种问题规模。学习到的 ReLU 网络被精确编码为混合整数线性约束，并嵌入到近似的单层公式中。随后，通过修复步骤针对选定的领导者决策重新求解追随者问题，以恢复双层可行的追随者响应。我们在具有 20 到 100 个物品的背包阻断实例上，将 Graph4BiLO 与精确求解器 MibS 以及基于学习的 Neur2BiLO 方法进行了评估。Graph4BiLO 在所有测试规模上都获得了与 Neur2BiLO 相当的目标值，同时避免了使用特定规模的神经网络。一项额外的分布外实验证明了从 20 个物品的训练实例到此前未见的 40 和 60 个物品实例的零样本迁移。然而，在每个图节点嵌入消息传递会显著增加生成的混合整数公式的规模和求解时间。这些结果揭示了可推广至不同规模的图表示与在优化模型中嵌入 GNN 的计算成本之间的核心权衡。

## Abstract
Bilevel mixed-integer linear optimization problems model hierarchical decision processes in which a leader anticipates the optimal response of a follower. Although expressive, these problems are computationally challenging because lower-level optimality is embedded in the leader's feasible region. Value-function reformulations replace the nested follower optimization with a constraint involving the follower's optimal value, but evaluating this value function exactly can itself be expensive. This paper introduces Graph4BiLO, a graph neural network (GNN) approach for learning bilevel value functions from variable--constraint graph representations. In contrast to fixed-length multilayer perceptron (MLP) representations, the GNN uses shared message-passing parameters and can therefore be applied across multiple problem sizes with a single trained model. The learned ReLU network is encoded exactly as mixed-integer linear constraints and embedded in an approximate single-level formulation. A repair step subsequently re-solves the follower problem for the selected leader decision to recover a bilevel-feasible follower response. We evaluate Graph4BiLO on knapsack interdiction instances with 20--100 items against the exact MibS solver and the learning-based Neur2BiLO method. Graph4BiLO obtains objective values comparable to Neur2BiLO across all tested sizes while avoiding size-specific neural networks. An additional out-of-distribution experiment demonstrates zero-shot transfer from 20-item training instances to previously unseen 40- and 60-item instances. However, embedding message passing at every graph node substantially increases the resulting mixed-integer formulation size and solve time. These results identify a central tradeoff between size-generalizable graph representations and the computational cost of embedding GNNs within optimization models.

#### 1. 核心问题与整体含义
双层混合整数线性优化（BMILP）描述了一种分层决策场景：领导者先行动，追随者在给定领导者决策下做出最优响应。这类问题在计算上极其困难（$\Sigma^P_2$-hard），因为下层的最优性条件被嵌套在领导者的约束中。传统的值函数重构方法虽然能将其转化为单层问题，但精确计算下层值函数 $\phi(x)$ 往往需要反复求解复杂的离散优化问题。
**研究动机：** 现有的机器学习近似方法（如 Neur2BiLO）多采用多层感知器（MLP），这导致模型与特定问题规模（变量数量）绑定。本文旨在开发一种基于图神经网络（GNN）的通用近似器，能够利用优化问题的图结构实现跨规模的泛化。

#### 2. 方法论
Graph4BiLO 的核心思想是将优化实例转化为图，学习值函数，并将其嵌入到单层优化模型中。
*   **变量-约束图构建：** 将问题表示为异构图，包含三类节点：领导者变量 ($x$)、追随者变量 ($y$) 和约束 ($c$)。边根据系数矩阵的非零模式建立，并添加了领导者与追随者变量之间的“快捷边”以捕捉直接干预关系。
*   **异构 GNN 架构：** 使用异构消息传递机制（HeteroConv），允许不同类型的节点和边拥有独立的学习参数。通过多层消息传递捕捉局部结构，随后通过全局池化与广播（Pooling-and-Broadcast）操作为每个节点提供全局上下文。
*   **MILP 嵌入与求解：** 训练完成后，将基于 ReLU 激活函数的 GNN 精确编码为混合整数线性约束（使用 Big-M 法）。将此代理模型嵌入领导者的单层模型中进行求解。
*   **修复步骤：** 由于 GNN 只是近似，求解出的追随者响应可能并非真正最优。框架保留领导者决策，重新精确求解一次下层问题，以确保最终方案的双层可行性。

*   **数据集/场景：** 实验聚焦于经典的“背包阻断问题”（Knapsack Interdiction），规模涵盖 20 到 100 个物品。

#### 6. 主要结论与发现
*   **跨规模泛化：** Graph4BiLO 实现了显著的零样本迁移能力，单一模型在未见过的更大规模问题上表现远超 MibS。
*   **性能权衡：** 虽然 GNN 提供了结构感知能力，但将其嵌入 MILP 会导致约束和变量数量激增。对于 100 规模的问题，嵌入的 ReLU 激活可能引入数万个辅助变量，导致求解时间大幅增加。
*   **深度陷阱：** 增加 GNN 层数并不一定提高预测精度，反而会因为“过度平滑”导致节点特征同质化，并显著增加下游优化负担。

#### 7. 优点
*   **通用性强：** 解决了神经网络代理模型必须与问题规模绑定的痛点，实现了“一次训练，多处使用”。
*   **结构感知：** 通过变量-约束图捕捉了优化问题的代数结构，比简单的特征向量更具解释力和表达力。
*   **端到端流程：** 提供了从图构建、学习到精确嵌入和修复的完整闭环。

#### 8. 不足与局限
*   **可扩展性瓶颈：** 嵌入 GNN 后的单层 MILP 规模巨大，导致在大规模问题上的求解速度远慢于基于 MLP 的方法。
*   **计算成本：** 尽管节省了重复训练的时间，但在单次推理求解时的计算开销限制了其在实时决策场景中的应用。
*   **任务单一：** 目前仅在背包阻断问题上进行了验证，对于更复杂的非线性或非凸双层问题的适用性尚待研究。
