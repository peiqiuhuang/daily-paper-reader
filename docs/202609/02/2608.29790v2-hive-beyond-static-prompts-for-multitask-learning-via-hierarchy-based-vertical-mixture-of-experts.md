## 摘要
随着大语言模型（LLM）规模的不断扩大，参数高效微调（PEFT）已成为全参数适配的一种实用替代方案。提示微调（Prompt tuning）虽然有效，但现有方法要么采用扁平的提示结构，要么采用固定提示组合的层级结构，限制了自适应提示的专业化。为了解决这一局限性，我们提出了 HiVe，这是一个在多个层级上对提示进行建模并实现依赖于输入的专业化的提示微调框架。HiVe 在训练期间利用任务间的关系构建提示层级，并在推理时采用垂直混合专家（V-MoE）机制，根据每个输入所需的专业化程度来组合提示。实验表明，HiVe 在各种任务中始终优于强大的提示微调基准模型。

## Abstract
As large language models (LLMs) continue to scale, parameter-efficient fine-tuning (PEFT) has become a practical alternative to full-parameter adaptation. Prompt tuning is effective, but existing approaches either use flat prompt structures or hierarchical structures with fixed prompt composition, limiting adaptive prompt specialization. To address this limitation, we propose HiVe, a prompt tuning framework that models prompts at multiple levels and enables input-dependent specialization. HiVe constructs a prompt hierarchy by leveraging inter-task relationships during training, and employs a vertical mixture-of-experts (V-MoE) mechanism at inference time to compose prompts up to the level of specialization required for each input. Experiments show that HiVe consistently outperforms strong prompt tuning baselines across diverse tasks.

随着大语言模型（LLM）规模的增长，参数高效微调（PEFT）成为主流。其中，**提示微调（Prompt Tuning, PT）**通过学习少量的“软提示”来适配任务。然而，现有方法存在以下局限：
*   **扁平化结构：** 现有的混合专家（MoE）提示方法通常将所有提示视为同一层级的专家，难以同时捕捉通用知识和高度专业化的任务知识。
*   **固定专业化：** 现有的层级提示方法通常采用固定的任务路径，无法根据输入的具体需求动态调整专业化程度（例如，某些简单输入仅需通用提示，而复杂输入需任务特定提示）。
**HiVe** 的提出旨在通过构建**提示层级结构**并结合**垂直混合专家（V-MoE）机制**，实现输入依赖的自适应提示专业化。

### 2. 方法论
HiVe 框架包含三个核心组件，分为两个训练阶段：
*   **残差提示分解（Residual Prompt Decomposition）：** 为了防止信息在底层提示中过度堆叠，HiVe 在训练前/中提取共享表示。它将提示分解为：**基础层（Base）**、**组层（Group）**和**任务层（Task）**。通过减去均值的方式，确保高层提示保留通用能力，底层提示专注于差异化特征。
*   **稳定性驱动的层级构建（Stability-driven Hierarchy Construction）：** 在训练的第一阶段，利用任务提示之间的余弦相似度进行层次聚类（HAC）。通过计算 **ARI（调整兰德指数）** 来监测聚类结构的稳定性，只有当任务分组在多个训练步中保持稳定时，才正式确立三层架构。
*   **垂直混合专家机制（V-MoE）：** 
    *   **路由训练：** 引入路由键（Routing Keys），通过两级交叉熵损失优化，使输入查询（Query）能匹配到最合适的层级。
    *   **推理选择：** 不同于传统 MoE 在平行专家间选择，V-MoE 决定“向下探索多深”。它根据输入动态组合提示（如：仅 Base，或 Base+Group，或 Base+Group+Task），从而平衡通用性与专业性。
