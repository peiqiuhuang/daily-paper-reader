## ABSTRACT 

In-context learning (ICL) allows large language models to use demonstrations without updating their parameters. For interactive agents, demonstrations are tra-jectories of reasoning, actions, and observations that illustrate how to complete a task. Reusing demonstrations in new situations is challenging: directly inputting full trajectories consumes limited prompt space and constrains the overall effec-tiveness, while natural-language summaries require the agent to translate general guidance into specific action choices. Therefore, we study whether expert action choices can directly supervise a reusable scoring rule. We propose CB-Agent, which extends concept-based ICL to sequential action selection. We extract environment-action decisions from expert trajectories and fit a concept vector by maximum likelihood to model the conditional distribution over candidate actions given the context. This model combines the concept with frozen language-model features and priors. During ReAct interaction, the agent uses this distribution to select environment actions without including demonstrations in the action-scoring context. Across TextWorld, ALFWorld, and ScienceWorld, CB-Agent achieves the highest cross-benchmark average among the evaluated methods at all three tested model sizes and ranks first on TextWorld and ScienceWorld at each size. ALFWorld experiments support the learned concept’s contribution beyond prior-only scoring and show further gains when combined with Reflexion. Code is avail-able at https://anonymous.4open.science/r/CB-Agent-DFF9/ .

## 1 INTRODUCTION 

In-context learning (ICL) enables a large language model (LLM) to perform a task using examples in its input, without updating its parameters (Brown et al., 2020). These examples, called demon-strations, typically pair an input with a desired output. For an interactive agent, demonstrations instead record trajectories of actions and observations. Few-shot ReAct includes these demonstra-tion trajectories directly in the prompt to illustrate how reasoning and actions can be combined as new observations arrive (Yao et al., 2023b). The agent must use this experience throughout execu-tion: each decision depends on the interaction so far and can affect the steps that follow. The goal is therefore to reuse demonstration knowledge across changing contexts to complete a new task. Existing approaches improve how language models use experience through demonstration selec-tion, task organization, and feedback. Fine-tuning offers another route, but collecting interaction data or human annotations and optimizing model parameters can be costly (Nakano et al., 2021). Within ICL, retrieval-based selection identifies demonstrations relevant to a query input (Liu et al., 2022). For interactive tasks, StateAct maintains explicit goals and state information to guide deci-sions (Rozanov & Rei, 2025). AdaPlanner refines its plans in response to environmental feedback (Sun et al., 2023). To reuse accumulated experience, ExpeL extracts natural-language insights and combines them with retrieved successful trajectories (Zhao et al., 2024). Reflexion instead maintains verbal reflections on feedback to guide subsequent attempts (Shinn et al., 2023). Demonstrations in

For demonstration-based action selection, we investigate an alternative: using expert choices to fit a reusable scoring rule, rather than relying solely on trajectories or verbal guidance in the action-selection prompt. The central challenge is how experience should affect each action choice. A new task need not repro-duce any demonstrated sequence, and applying language-based insights requires interpreting their guidance in the current situation. For example, advice to avoid repeated searches must distinguish an unproductive revisit from returning to a known location to collect a second object. Expert trajec-tories also provide direct supervision: the action selected in each recorded context. This motivates our central question: can we estimate a reusable action-selection rule directly from demonstrated choices, without first expressing that experience as natural-language rules? Fitting these choices would explicitly connect demonstration learning to the comparison of candidate actions. Numerical task representations provide a foundation for this direction. Task Vectors and Function Vectors show that demonstrated tasks can be represented by vectors that influence a model’s predic-tions (Hendel et al., 2023; Todd et al., 2024). More directly, concept-based ICL (CB-ICL) estimates a shared concept vector over frozen language-model features and provides theoretical analyses of label prediction for individual inputs (Tang et al., 2025). Here, a concept is a numerical vector that weights features for prediction. Adapting this framework to sequential action selection requires ex-tracting decision examples from trajectories and handling contexts and candidates that change with interaction. The concept must express context-dependent preferences, not a fixed ranking of action strings. We introduce CB-Agent, which converts expert trajectories into decision examples comprising a pre-action context, candidate environment actions, and the expert’s choice. We model the condi-tional distribution over candidate actions given the context using an exponential-family model. A concept vector weights frozen LLM features to adjust the language-model prior and is fitted to the expert choices by regularized maximum likelihood. During ReAct interaction, the fitted model selects the highest-probability candidate environment action. ReAct continues to use demonstra-tions for reasoning and think-or-act routing, while the action scorer uses the current context without demonstrations. The concept remains fixed during execution, but action probabilities change with the context and candidates. This procedure supports both environment-supplied candidates in fixed-action-space tasks and model-generated candidates in open-action-space tasks. Our contributions can be summarized as follows: 1. Concept-based learning from trajectory decisions. We adapt CB-ICL to estimate a shared concept from expert environment-action choices. The conditional model combines the learned feature weights with a language-model prior, linking demonstration fitting to candidate scoring without updating LLM parameters or requiring verbal experience sum-maries. 2. Online selection with a reusable concept. We integrate the fitted model into ReAct in-teraction, using one fixed concept with changing contexts and candidates in both fixed and open environment-action spaces. 3. Empirical evaluation and analysis. We evaluate Qwen3-4B, Qwen3-8B, and Qwen3-14B on TextWorld, ALFWorld, and ScienceWorld. CB-Agent achieves the highest cross-benchmark average among the evaluated methods at each model size and ranks first on TextWorld and ScienceWorld throughout. An ALFWorld control comparison supports the contribution of the learned concept beyond the length-adjusted language-model prior. We also examine task-related concept structure and evaluate combinations with Reflexion sep-arately.

In standard few-shot ICL, input–output demonstrations accompany a query input in the prompt, guiding its prediction without updating language-model parameters (Brown et al., 2020). For agents, demonstrations are trajectories of task instructions, actions, and observations. Few-shot ReAct includes reasoning in these trajectories to guide interaction (Yao et al., 2023b). Unlike single-output prediction, interaction requires successive decisions conditioned on the evolving history. 2.2 CONCEPT -B ASED IN-C ONTEXT LEARNING 

Concept-based in-context learning (CB-ICL) estimates a shared concept vector from labeled demon-strations using features from a frozen language model (Tang et al., 2025). The estimated vector weights the features of an input and its candidate labels, allowing demonstrations to inform a com-mon prediction rule. The published CB-ICL analysis uses a linear representation of conditional probabilities. In this work, we adopt an exponential parameterization instead of the linear form, motivated by local information geometry. Under weak dependence, where the joint distribution is close to the product of its marginals in chi-squared divergence, the linear modal decomposition admits a local expo-nential representation, up to higher-order terms (Huang et al., 2024). This representation motivates weighting fixed features in log-probability space. Appendix D gives the derivation and distinguishes this local approximation from the practical concept model. Let m be the positive integer feature dimension, ϕ(x, y ) ∈ Rm a fixed feature vector, and Q0(y) > 0 a fixed base weight. A concept vector α ∈ Rm defines the conditional distribution Pα by multiplying each base weight by a feature-dependent factor and normalizing over labels:

Benchmarks and metrics. We evaluate on TextWorld, a framework for text-based games (Côté et al., 2018); ALFWorld, which expresses household tasks as text-based interaction (Shridhar et al., 2021); and ScienceWorld, which requires agents to carry out scientific tasks in an interactive envi-ronment (Wang et al., 2022). In our TextWorld and ALFWorld settings, the environment supplies environment-action candidates. ScienceWorld uses an open-action-space setting in which the model proposes a finite candidate collection at each step. We report normalized scores for TextWorld and ScienceWorld and success rate over 134 tasks for ALFWorld, all on a 0–100 scale. Avg. is the un-weighted mean of these three metrics, computed before rounding. It is a cross-benchmark summary, not an overall success rate. 

Models and baselines. We use Qwen3-4B, Qwen3-8B, and Qwen3-14B. ReAct interleaves rea-soning and actions, whereas Act-only omits explicit reasoning (Yao et al., 2023b). Self-Consistency provides a comparison based on aggregating sampled responses (Wang et al., 2023). StateAct makes goals and states explicit (Rozanov & Rei, 2025), while ReflAct reflects on the current state relative to the goal (Kim et al., 2025). ExpeL reuses natural-language insights and retrieved trajectories (Zhao et al., 2024). We also include DeltaMem (Tan et al., 2026) and a Trajectory SFT reference that updates model parameters using trajectory data. Reflexion configurations with two attempts are evaluated separately. 

Demonstrations and concept fitting. Qwen3-32B generates the expert trajectories. Each task type uses a fixed set of two trajectories for ALFWorld and ten for TextWorld and ScienceWorld, shared across its test tasks and demonstration-based baselines. The test task’s own expert trajectory is excluded from fitting and parameter selection. For each backbone, CB-Agent fits one concept per task type using Equation (6) and reuses it without test-time updates, keeping the language model frozen. ScienceWorld candidates are sampled by the agent’s own backbone. Appendix B provides collection, fitting, and execution details. 

Evaluation scope. The main comparison evaluates single-trial task performance. We report the two-trial Reflexion comparison separately. Computational costs and the scope of the empirical evi-dence are discussed in Appendix F. 4.2 MAIN RESULTS 

Table 1 shows that CB-Agent achieves the highest cross-benchmark average among the evaluated methods at every model size: 66.6, 72.5, and 75.9 for 4B, 8B, and 14B, respectively. It leads in six of nine model–benchmark combinations, and its scores increase with model size on all three benchmarks. On TextWorld, CB-Agent ranks first throughout, including at 8B where it exceeds the strongest baseline, DeltaMem, by 2.1 points. On ScienceWorld, ExpeL is the strongest baseline at every size, but CB-Agent consistently surpasses it. Thus, the leading results span both environment-supplied and model-generated candidate collections. The experience-based baselines are less con-sistent across environments: ExpeL is strongest on ScienceWorld, whereas DeltaMem is competitive on TextWorld at 8B. ALFWorld shows a different pattern: StateAct leads at 4B and 8B, and ReflAct leads at 14B. CB-Agent improves from 76.9 to 81.3 but remains below these leaders. One possible limitation is that better individual action choices may still leave errors that prevent task completion. Since ALFWorld measures complete-task success, such partial improvements would not increase its reported score. Finally, relative to ReAct, CB-Agent improves eight settings and matches one, with average gains of 2.4, 5.1, and 2.5 points at the three model sizes, computed before rounding. 4.3 VISUALIZATION OF ESTIMATED CONCEPTS

## 5 RELATED WORK 

ICL research explores numerical representations of demonstration knowledge, including Task Vec-tors and Function Vectors (Hendel et al., 2023; Todd et al., 2024). CB-ICL estimates shared concepts for individual-input prediction (Tang et al., 2025); we adapt this framework to sequential action se-lection with changing contexts and candidates. For language agents, ReAct interleaves reasoning and actions (Yao et al., 2023b), while ExpeL reuses language-based insights and trajectories (Zhao et al., 2024), and Reflexion uses verbal feedback across attempts (Shinn et al., 2023). CB-Agent retains ReAct interaction but fits a numerical concept from expert choices to score actions, with-out requiring verbal experience summaries or updating LLM parameters. Appendix E provides an extended discussion. 

## 6 CONCLUSION 

We introduced CB-Agent, which adapts concept-based in-context learning to sequential action selec-tion. It fits a reusable concept from expert environment-action decisions and uses frozen language-model features to score candidates in the evolving interaction context, without first converting expe-rience into verbal rules. Across three benchmarks and three Qwen3 model sizes, CB-Agent achieves 9Under review as a conference paper the highest average score among the evaluated methods. An ALFWorld control comparison supports the contribution of the learned concept beyond prior-only action scoring. Combining CB-Agent with Reflexion further improves ALFWorld success rates, while concept visualizations provide qualita-tive evidence of task-related structure. E.1 IN-C ONTEXT LEARNING AND NUMERICAL TASK REPRESENTATIONS 

ICL uses demonstrations to specify a task without updating the language model’s parameters (Brown et al., 2020; Dong et al., 2024). One line of work improves the selection and ordering of examples in the prompt (Rubin et al., 2022; Lu et al., 2022). For instance, Liu et al. We use expert choices from multiple trajectories to fit a shared concept, then apply it to context-dependent action features during execution. Our objective anal-ysis concerns fitting with fixed features and prior weights, while the sequential behavior is assessed experimentally. E.2 REASONING , S TATE TRACKING , AND ACTION SELECTION 

Chain-of-thought prompting elicits intermediate reasoning (Wei et al., 2022), while tree-based search explores alternative reasoning paths (Yao et al., 2023a). ReAct provides a framework for al-ternating language-based reasoning with actions and environmental observations (Yao et al., 2023b). Subsequent methods change how this interaction is organized. StateAct uses self-prompting and state tracking to maintain task goals and relevant state information (Rozanov & Rei, 2025). ReflAct emphasizes repeated reflection on the relation between the current state and the goal (Kim et al., 2025). AdaPlanner revises plans using environmental feedback and also reuses successful plans as few-shot exemplars (Sun et al., 2023). These are overlapping approaches to improving decisions, rather than mutually exclusive categories: a method can organize the current interaction while also retaining useful experience. Self-Consistency offers a different approach to inference: it samples multiple reasoning paths and selects an answer by aggregating their outcomes (Wang et al., 2023). CB-Agent’s open-action-space procedure also uses multiple sampled replies, but sampling serves to propose candidates for the current decision. Selection uses a concept fitted from expert choices together with language-model prior weights, rather than agreement among sampled answers. Only the selected action is executed. Thus, candidate proposal and candidate selection are distinct parts of our procedure; the proposal mechanism is not a standard component of ReAct. CB-Agent uses ReAct contexts without introducing a separate planning or state-tracking architecture. E.3 LEARNING AND REUSING AGENT EXPERIENCE 

ExpeL and Reflexion show how agents can reuse execution experience through language. ExpeL extracts insights from training-task experience and retrieves relevant past trajectories for subsequent decisions (Zhao et al., 2024). Reflexion converts feedback into verbal reflections retained in episodic memory to guide later trials (Shinn et al., 2023). Their common use of text should not obscure the difference between transferring experience across tasks and adapting across repeated attempts at a task. Nor does freezing the LLM distinguish CB-Agent from these approaches, since they also avoid updating its parameters. Other work reuses executable skills or synthesizes task and state knowledge from trajectories (Wang et al., 2024; Qiao et al., 2024). CB-Agent differs in what is extracted from experience and how it enters the decision rule. Ex-pert action choices supervise a numerical concept through a likelihood objective, and that concept weights action features when comparing candidates. The method does not require an intermediate natural-language summary of the expert experience. In contrast to trajectory-based LLM fine-tuning (Zeng et al., 2024; Chen et al., 2024), the optimized parameters belong to the concept model, not the LLM. This distinction is about the representation and use of experience, not a general claim of superiority over language-based memory or fine-tuning. The concept remains fixed within each test task, while new observations and any retained reflections change the context used for scoring. ## F LIMITATIONS 

Modeling and transfer. CB-Agent models expert action preferences using frozen language-model features. Our theoretical analysis characterizes the concept-fitting objective, while end-to-end task performance is evaluated empirically. The current setting uses demonstrations from the same task type; performance may depend on their quality and coverage. Transfer to unseen task types remains an important direction for future work. 

Candidate selection and computation. In open-action-space tasks, action selection depends on the coverage and quality of generated candidates. Candidate generation, scoring, and concept es-timation introduce additional computation, and our comparisons assess task performance rather than efficiency under matched computational budgets. Demonstrations are omitted from the action-scoring context but remain in ReAct reasoning and routing, so the complete agent remains subject to context-window limits. 

Evaluation scope. Our experiments cover three text-interaction benchmarks and three model sizes within the Qwen3 family. The prior-only control provides evidence for the learned concept’s con-tribution on ALFWorld; extending this analysis to the other benchmarks would clarify its broader applicability. Evaluation across additional model families and tasks, together with repeated-run uncertainty estimates, would further characterize the robustness of the observed gains. 21
