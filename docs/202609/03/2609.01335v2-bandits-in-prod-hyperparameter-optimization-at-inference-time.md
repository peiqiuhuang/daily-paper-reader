## 摘要
许多生产系统只能通过将其用于实时请求并观察带噪反馈来评估配置。现代智能体（Agent）系统是一个突出例子，它们包含模型选择、检索深度、提示词策略和解码温度等推理阶段的选择，但往往缺乏代表性的验证数据。我们将这一设定形式化为在线超参数优化（OHPO），并将其建模为混合与条件搜索空间上的无限多臂老虎机问题。我们提出了 IMABO，这是一个通用框架，它将用于在已采样配置中进行选择的任意 Bandit 策略与用于提出新配置的任意预言机（oracle）结合起来。我们使用 IMOSS 对其进行实例化，这是一种无重置随时策略（restart-free anytime policy），其活动集以 $t^β$ 的速度增长，并证明了其期望累积分位数后悔界为 $O(p_ρ^{-1/β} + T^{(1+β)/2})$，其中 $β\in(0,1)$ 用于控制活动集增长，$p_ρ$ 是所提配置落入搜索空间前 $ρ$ 比例范围内的概率下界。我们将 IMOSS 与三种实用预言机相结合：树状结构 Parzen 估计器（Tree-structured Parzen Estimator）、由单坐标 Bandit 驱动的现任变异预言机（incumbent-mutation oracle），以及预训练的表格基座模型，三者均优于均匀随机预言机基线。从调优传统机器学习模型到配置基于 LLM 的智能体，IMABO 在各种 OHPO 设定下的后悔值表现均优于所有基线。我们的代码实现已在 https://github.com/Tiime-Software/IMABO 开源。

## Abstract
Many production systems can assess a configuration only by using it on live requests and observing noisy feedback. Modern agentic systems are a prominent example, with inference-time choices such as model selection, retrieval depth, prompting strategy, and decoding temperature, yet often with no representative validation data. We formalize this setting as Online Hyperparameter Optimization (OHPO) and cast it as an infinitely many-armed bandit over mixed and conditional search spaces. We introduce IMABO, a general framework that combines any bandit policy for choosing among already sampled configurations with any oracle for proposing new ones. We instantiate it with IMOSS, a restart-free anytime policy whose active set grows as $t^β$, and prove an expected cumulative quantile-regret bound of $O(p_ρ^{-1/β} + T^{(1+β)/2})$, where $β\in(0,1)$ controls active-set growth and $p_ρ$ lower-bounds the probability that a proposed configuration falls in the top-$ρ$ fraction of the search space. We combine IMOSS with three practical oracles: a Tree-structured Parzen Estimator, an incumbent-mutation oracle driven by a per-coordinate bandit, and a pretrained tabular foundation model, all three improving over the uniform random oracle baseline. IMABO outperforms all baselines in terms of regret across diverse OHPO settings, from tuning classical machine-learning models to configuring LLM-based agents. Our implementation is available at https://github.com/Tiime-Software/IMABO.

* **研究背景**：在现代 AI 和大语言模型（LLM）智能体（Agent）系统中，许多配置项（如模型选择、检索深度 $top\_k$、提示词模板、解码温度等）需要在推理阶段进行调整。然而，生产环境通常缺乏有代表性的离线验证集，系统的真实表现只能通过上线处理实时请求并观察带噪反馈（如用户点击、任务成功率、答案 F1 分数）来评估。
* **核心问题**：传统的离线超参数优化（HPO，如贝叶斯优化、Hyperband）假设可以在离线数据集上反复评估；而传统的在线学习或多臂老虎机（MAB）通常假设臂数有限，或依赖连续空间的度量（Metric），无法直接处理包含离散、连续、类别和条件依赖（树状）的混合超参数空间。
* **形式化定义**：论文将这一场景形式化为**在线超参数优化（Online Hyperparameter Optimization, OHPO）**，并将其建模为混合/条件搜索空间上的**无限多臂老虎机（Infinitely Many-Armed Bandit, IMAB）**问题。在线评估每一次选择都是一次真实服务请求，因此优化的目标是在未知的服务周期内最小化累积后悔值（Cumulative Regret）。

### 2. 论文提出的方法论
#### 核心思想
提出了 **IMABO（Infinitely Many-Armed Bandit with Oracle）** 框架。该框架将算法解耦为两部分：
1. **Bandit 策略（Allocation Policy）**：负责在已采样的“活跃配置集”（Active Set）中选择当前请求使用哪一个配置（平衡探索与利用）。
2. **预言机（Oracle）**：基于历史观察记录，负责在需要扩展候选集时提出全新的配置。

#### 关键技术细节与算法流程
* **IMOSS 算法（Bandit 策略）**：
  * **动态扩充规则**：活跃集 $\mathcal{M}_t$ 的规模按幂律 $t^\beta$ 增长（实验中设置 $\beta = 0.5$，即活跃集规模为 $\lfloor\sqrt{t}\rfloor$）。当 $|\mathcal{M}_t| < t^\beta$ 时调用 Oracle 引入新臂，否则在现有臂中选择。
  * **Anytime MOSS 指数**：每个已存在臂 $x$ 的索引为：
    $$B_t(x) = \hat{\mu}_x + \sqrt{\frac{1+\alpha}{2} \cdot \frac{\max\left(0, \log\left(\frac{t K_t}{n_x}\right)\right)}{n_x}}$$
    其中 $\hat{\mu}_x$ 为经验均值，$n_x$ 为拉动次数，$K_t = |\mathcal{M}_t|$，$\alpha$ 为置信参数（默认 0.1）。
  * **理论保证**：证明了在 Oracle 以概率 $p_\rho$ 建议出 Top-$\rho$ 优质配置的前提下，IMOSS 具有次线性的累积分位数后悔上界：$\mathbb{E}[R_{\rho,+}(T)] = O(p_\rho^{-1/\beta} + T^{(1+\beta)/2})$。
* **实例化预言机（Oracles）**：
  1. **IMOSS-Random**：均匀随机采样作为基线。
  2. **IMOSS-TPE**：利用 MOSS 指数将活跃集分为好/坏两组，拟合树状 Parzen 估计器（TPE）密度比 $\ell(x)/g(x)$ 产生全局候选。
  3. **IMOSS-mutate-KL$\times$PE**：局部变异策略。选择当前经验均值最好的配置 $\hat{x}$，利用 KL-UCB 老虎机选择待变异的维度，再利用一维 Parzen 估计器（PE）采样该维度的变异值。
  4. **IMOSS-TabPFN**：基于预训练表格基座模型（TabPFN-3）作为替代模型。对当前最佳配置 $\hat{x}$ 生成 90% 的单维度变异候选和 10% 随机候选，利用 TabPFN 的预测高分位数（$q=0.975$）挑选最佳新配置。
* **工程扩展**：
  * **延迟与截断反馈处理**：引入有效计数 $\tilde{N}_t = N^{\text{rew}} + p N^{\text{pend}}$（$p$ 为估计的反馈返回率），动态调整扩充频率与置信区界面积。
  * **搜索空间动态演进重置**：当生产环境加入新模型或新参数时，仅重置扩充 schedule，保留历史奖励数据。

### 3. 实验设计
* **实验场景与 Benchmark**：
  1. **合成函数测试（Toy Problems）**：4维 Sin1、Garland、Rastrigin（可分离函数 + 加性高斯噪声）及 Gaussian（非可分离 + 伯努利二值噪声）。

  4. **延迟反馈生产仿真（LCBench / YAHPO-Gym）**：7维混合连续/离散空间（AutoPyTorch MLP 训练），引入与配置预测运行时间相关的概率延迟及 80% 的数据丢失截断。

### 6. 论文的主要结论与发现
1. **IMABO 框架的有效性**：IMOSS 动态扩充策略与自适应 MOSS 分配机制相结合，在所有 OHPO 场景下累积后悔值均显著优于传统的层次

Bandit 算法（如 StoSOO, HOO-T）和离线 HPO 方法（如 TPE-$k$）。
2. **Oracle 策略的比较与最佳实践**：
   * **TabPFN 表现最强**：利用预训练表格模型 TabPFN-3 作为 Oracle 的 `IMOSS-TabPFN` 在绝大多数任务（尤其是连续/混合空间和 LLM 场景）中取得了最低的累积后悔与最佳的搜索效率，证明了大表模型在上下文学习（In-Context Learning）进行替代模型（Surrogate Model）建模的巨大潜力。
   * **局部变异（KL$\times$PE）极具实用价值**：`IMOSS-mutate-KL$\times$PE` 凭借只变异单一维度的策略，在低拉动次数时能极大地控制探索低劣配置带来的代价（低 Cost of other arms），非常适合对线上风险敏感的生产环境。
3. **延迟与缺失反馈的鲁棒性**：在 LCBench 延迟与截断反馈测试中，引入有效计数 $\tilde{N}_t$ 的 IMOSS 能保持稳定的算法扩展 schedule，避免因反馈滞后导致的过度探索或扩展过快问题。
4. **LLM Agent 系统的在线自适应**：在 HotpotQA 的 RAG 智能体实验中，IMOSS-TabPFN 在没有离线 validation 数据集的情况下，仅通过处理在线真实请求，快速定位到了由高效 LLM 模型、优质 Prompt 模板和最佳 $top\_k$ 组成的配置，显著提升了生成回答的 F1 分数，同时节省了不必要的 API 成本。

### 7. 论文的创新点、局限性与启发

#### 核心创新点
1. **理论与架构的解耦（IMABO 框架）**：首次将在线超参数优化（OHPO）形式化为无限多臂老虎机（IMAB）问题，并将算法清晰地解耦为“负责理论收敛保证的 Bandit 分配策略（IMOSS）”与“负责黑盒超参数推荐的预言机（Oracle）”。
2. **融合表格大模型（TabPFN）**：创新性地将前沿的表格基座模型 TabPFN-3 引入在线 Bandit 场景，赋予了 Oracle 无需显式超参数训练即可零样本预测复杂超参数空间结构的能力。
3. **工程落地友好**：针对真实的生产环境，提出了应对反馈延迟、数据丢包以及在线系统超参数空间动态重置（Reset）的完整工程方案。

#### 局限性
1. **计算与上下文开销**：随着在线请求数 $T$ 的增加，TabPFN 模型的 In-Context 上下文会越来越长，推断延迟和算力消耗会增加；TPE 在高维空间下的拟合效率也可能下降。
2. **非平稳环境（Non-Stationary）假设**：目前理论保证建立在平稳分布（Stationary Environment）假设之上。如果生产环境中的用户输入分布发生漂移（Data Drift）或大模型 API 后台发生更新，算法需要进一步结合滑动窗口或漂移检测机制。

#### 对未来研究与工程实践的启发
* **大模型 Agent 的“边服务边调优”**：对于无法构建全面离线测试集的复杂 Agent 系统，上线后直接结合 IMOSS+TabPFN 进行在线无痛调参将成为可能，实现了生产环境下的自适应优化。
* **通用超参数优化新范式**：论文证明了“通用预训练表格模型 + 无限臂 Bandit 理论”是解决复杂、异构、条件依赖搜索空间的最具潜力的范式之一。
