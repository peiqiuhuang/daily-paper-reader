# Anchor and Adapt: Asymmetric Prompt Adaptation for Few-Shot Industrial Anomaly Detection 

Mengyang Zhao, Teng Fu, Haiyang Yu, Ke Niu, Bin Li, and Xiangyang Xue 

Abstract —In few-shot industrial anomaly detection, the few normal target images provide no direct defect supervision, making anomaly prompts difficult to learn from these samples alone. Some vision-language methods therefore use manually specified descriptions to supply explicit anomaly semantics. However, constructing these descriptions requires product-specific effort, and their effectiveness depends on prompt selection. We propose Anchor and Adapt, a two-stage prompt learning framework that separates the acquisition of anomaly semantics from adaptation to target normal appearance. Stage I learns transferable normal and abnormal anchors from annotated auxiliary data. Stage II keeps these anchors fixed and adapts an additional normal branch using the few target normal samples. The inherited and adapted normal branches jointly characterize target normality, with text-anchor regularization encouraging consistency with the generic normal prior and separation from the abnormal anchors. This design retains learned anomaly knowledge while reducing dependence on category-specific anomaly templates, without requiring synthetic anomaly generation. Cross-dataset experiments between MVTec-AD and VisA under 1-, 2-, and 4-shot settings demonstrate competitive detection and localization performance. Controlled ablations assess the roles of transferred anchors, asymmetric adaptation, dual-normal representations, and anchor regularization. 

Index Terms —Anomaly Detection, Few-Shot Learning, Vision-Language Models. 

I. I NTRODUCTION 

Visual anomaly detection aims to identify images and local regions that deviate from normal visual patterns. It plays an important role in automated industrial quality inspection, enabling the detection of defective products and the localization of defects [1]–[4]. Few-shot industrial anomaly detection (FS-IAD) addresses deployment to new product categories where only a few normal samples are available for model adaptation [3], [5]–[8]. For vision-language model based approaches [8], [9], this data constraint places particular importance on how normal and abnormal semantic references are constructed. Vision-language models (VLMs), such as CLIP [10], support FS-IAD by comparing visual features with textual descriptions of normal and abnormal states. The few normal target samples provide no direct defect supervision, making anomaly prompts difficult to learn from these samples alone. The challenge is to obtain useful anomaly semantics while adapting to a new product’s normal appearance from only a few normal samples. The supervision needed to establish anomaly semantics differs from that available for adapting to a new product. Annotated auxiliary data provide direct defect supervision and support learning transferable normal and abnormal semantic references [13]–[15]. The few normal target images, in turn, provide evidence of the new product’s normal appearance. These complementary sources of supervision motivate a two-stage approach: first acquire transferable semantic references from auxiliary data, then adapt to target normality while retaining those references. We therefore propose Anchor and Adapt , a two-stage prompt learning framework that assigns complementary roles to auxiliary anomaly supervision and target normal supervision. Stage I learns generic normal and abnormal anchors from annotated auxiliary data. Stage II uses the few target normal samples to specialize the normal representation. Because these samples directly characterize normal appearance, we adopt asymmetric adaptation: the learned anchors remain fixed, while an additional class-specific normal branch is adapted to the target product. This additional branch complements the inherited generic normal representation. The fixed generic branch retains the transferable normal reference, while the class-specific branch captures the target product’s normal appearance; together, they form a dual-normal representation. Text-anchor regularization guides the adapted prompts toward consistency with the generic normal prior and separation from the abnormal anchors. Low-rank residual updates and additional context tokens provide the capacity for this adaptation. The resulting framework combines learned anomaly semantics with target-specific normal evidence without requiring category-specific anomaly templates or synthetic anomaly generation. A. Vision-Language Models 

Vision-language models such as CLIP [10] and ALIGN [16] learn a shared embedding space for images and text. CLIP aligns visual and textual features through contrastive learning on 400 million image–text pairs. With textual prompts such as “a photo of a dog”, it performs zero-shot classification by matching image and text features using cosine similarity. Selecting effective manual prompts requires task-specific tuning. CoOp [17] replaces context words with learnable vectors optimized using a few labeled images. CoCoOp [18] extends this approach with a lightweight network that generates an input-conditional token for each image. These image-conditioned prompts improve generalization to class shift compared with the static prompts of CoOp. Related vision-language approaches have also been applied to image segmentation [19], video understanding [20], and Chinese text recognition through image– structure alignment [21]. More recently, task-specific VLM adaptation has enabled interactive person retrieval in Cha-tReID [22] and unified medical image analysis in UMIT [23]. For tracking, FDTracker [24] uses language-guided appearance features for object association, while OmniPT [25] integrates pedestrian tracking with interactive semantic understanding. 

B. Industrial Anomaly Detection 

Industrial anomaly detection aims to detect and localize defects in products. Unsupervised approaches learn normality from training images or use synthesized anomalies to obtain additional supervision [26]–[28]. In FS-IAD, the limited number of normal target images places greater emphasis on knowledge transferred from pretrained models or auxiliary data-sets. WinCLIP [11] uses normal and abnormal text ensembles. PromptAD [9] learns normal and abnormal prompts from nor-mal target images through semantic concatenation and margin constraints, using manually specified anomaly descriptions to guide prompt learning. FineGrainedAD [12] introduces fine-grained visual-language alignment. AnoPLe [29] combines multimodal prompt learning with simulated anomalies. Re-sAD [30] learns class-generalizable anomaly representations through residual features. Large vision-language models also support anomaly de-tection and reasoning through normal reference images. IADGPT [31] uses in-context learning to unify industrial ano-maly detection, localization, and reasoning. A. CLIP and Vision-Language Transfer 

CLIP [10] learns a shared embedding space for images and text through large-scale contrastive pretraining. Let f (·) and 

g(·) denote the image encoder and text encoder, respectively. Given an image x and a set of text prompts {ti}Ni=1 , CLIP predicts the probability that x belongs to the class represented by ty as 

p(y|x) = exp ( ⟨f (x), g (ty )⟩/τ )

PNi=1 exp ( ⟨f (x), g (ti)⟩/τ ) , (1) where ⟨· , ·⟩ denotes cosine similarity and τ is the temperature. Since the classifier is constructed from text prompts rather than fixed category-specific parameters, CLIP can transfer to unseen categories by replacing the textual descriptions. This property makes CLIP attractive for few-shot and open-category recognition tasks. 

B. Prompt Learning 

In standard zero-shot classification, CLIP usually relies on manually designed prompts, such as “a photo of a [class] ”. However, prompt wording can strongly affect performance, and searching for effective prompts is often time-consuming. Prompt learning addresses this issue by replacing hand-crafted context words with learnable vectors. For example, CoOp [17] represents a prompt as 

P = [ p1][ p2] . . . [pL][ class ], (2) where p1, . . . , pL are learnable context tokens and [class ] is the class name. By optimizing only a small number of prompt parameters while keeping the pretrained vision-language model frozen, prompt learning provides a parameter-efficient way to adapt CLIP to downstream tasks with limited data. C. CLIP for Few-Shot Industrial Anomaly Detection 

CLIP-based anomaly detection treats normality and abnor-mality as textual concepts. Instead of classifying an image into object categories, these methods compare visual fea-tures with normal and abnormal text features, and use their similarity difference to estimate anomaly scores. For image-level detection, the global image feature is compared with normal/abnormal text prompts. For pixel-level localization, patch features from intermediate visual layers are compared with the same text features to produce anomaly maps. Methods such as AnomalyCLIP [13] and PromptAD [9] follow this paradigm by learning or designing prompts for normal and abnormal states, and some methods further enhance local visual features with V-V attention mechanisms inspired by CLIP-Surgery [37]. The inherited and adapted normal branches jointly represent normality, while text-anchor regularization guides adaptation relative to the fixed references.

We conduct our primary few-shot detection and localization experiments on VisA and MVTec-AD under 1-shot, 2-shot, and 4-shot settings. We additionally evaluate on MPDD to examine the transferability of the proposed framework to metal-part inspection. Ablation studies and qualitative visualizations examine the proposed adaptation design. 

A. Experimental Setup 1) Datasets and Evaluation Metrics: VisA [47] and MVTec-AD [48], which contain 12 and 15 product categories, re-spectively, are commonly used to evaluate few-shot industrial anomaly detection [8], [9], [12], [29]. Following this practice, we use them as our primary benchmarks. We additionally evaluate on MPDD [49], which contains six categories of metal parts, to assess the transferability of our method beyond these two commonly used benchmarks. Following the few-shot protocols of PromptAD [9] and IIPAD [8], for each target category in VisA and MVTec-AD, we sample k ∈ { 1, 2, 4}

normal images from the training split to form the support set. The same support images are used for Stage-II normal-prompt adaptation and visual-memory construction. The full test split serves as the query set and remains fixed across all shot settings. The support and query sets are disjoint, and query images and labels are not used to optimize target prompts. We report image- and pixel-level AUROC, image-level AUPR, and region-level PRO. The table headings I-AUC and P-AUC denote image- and pixel-level AUROC, respectively. On MPDD, the I-AUPR and PRO columns report average precision (AP) and area under the per-region overlap curve (AUPRO), respectively. All results are expressed as percentages; higher values indicate better performance. 

2) Implementation Details: We use CLIP ViT-L/14@336px as the backbone. Multi-level visual features are extracted from layers 6, 12, 18, and 24. In Stage I, we set the context length to 

E = 12 and learn 8 normal prompts and 8 abnormal prompts from the auxiliary anomaly dataset. For cross-dataset evaluation, Stage I uses VisA as the auxiliary dataset for MVTec-AD, and MVTec-AD for VisA and MPDD. Stage II adapts the normal prompts using only the few normal training images from each target category; target test data are excluded from both stages. In Stage II, we introduce 8 adapted class-specific normal prompts, with J = 2 newly learnable tokens and a low-rank residual factorization width of ρ = 8 . The top-K parameter is set to 

K = 7 . The weight of the text-anchor regularization is set to 

λanchor = 0 .1. The first stage is trained for 15 epochs, and the second stage is trained for 150 epochs. All experiments are run on a single NVIDIA Tesla A800 GPU.

FineGrainedAD [12] uses category-specific predefined anomaly descriptions, while AnoPLe [29] uses synthetic anomalous images in joint multi-class training. Our framework learns anomaly references from real auxiliary data and adapts normal prompts for each target category, requiring neither category-specific anomaly templates nor synthetic anomaly generation.

VI. C ONCLUSION 

We presented Anchor and Adapt, a two-stage prompt learning framework for few-shot industrial anomaly detection. Auxiliary anomaly supervision establishes transferable normal and abnor-mal anchors, while target normal supervision adapts product-specific normal appearance. This division reduces reliance on manually specified category-specific anomaly descriptions. Asymmetric adaptation preserves the learned anchors and updates an additional normal branch; the inherited and adapted normal representations jointly provide normal evidence under anchor regularization. Cross-dataset experiments on MVTec-AD and VisA, together with additional MPDD evaluation, demonstrate competitive detection and localization.
