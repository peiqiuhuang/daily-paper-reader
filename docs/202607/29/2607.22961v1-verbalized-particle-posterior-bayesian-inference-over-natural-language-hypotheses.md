## 摘要
语言化机器学习 (VML) 将模型参数化为自然语言提示词，并由大语言模型 (LLM) 以 f(x; theta) 的形式进行评估。该框架具有可解释性，但它仅致力于单一假设，缺乏不确定性度量，且该假设在相同数据的不同优化运行中存在显著差异。我们提出了语言化粒子后验 (VPP)，将语言化学习视为一个贝叶斯推理问题：将一组自然语言假设作为粒子进行维护，使用 Metropolis-Hastings (VPP-MH) 或顺序蒙特卡洛 (VPP-SMC) 进行更新，并通过贝叶斯模型平均进行预测。这两种算法都将 LLM 视为黑盒，无需访问 Logits 或梯度。由此产生了一个独特的结论：在经典的贝叶斯学习中，模型选择位于后验之外；而在 VPP 中，模型结构和参数共享同一个语言空间，且后验分布同时涵盖了两者。我们在回归、分类和规则发现基准测试上对 VPP 进行了评估。在所有基准测试中，它的表现均优于单次 VML 运行，并在大多数测试中达到或超过了独立 VML 运行的最优预言机集成 (oracle-best ensemble)，同时消除了 VML 偶尔产生的灾难性单次运行失败。由于每个粒子都是人类可读的假设，后验本身也是读者可以检查的对象，能够以纯文本形式直观地看到哪些解释得到了数据的支持，哪些被排除了。

## Abstract
Verbalized Machine Learning (VML) parameterizes a model as a natural-language prompt that an LLM evaluates as f(x; theta). The framework is interpretable, but it commits to a single hypothesis with no measure of uncertainty, and that hypothesis varies substantially across optimization runs on the same data. We propose the Verbalized Particle Posterior (VPP), which treats verbalized learning as a Bayesian inference problem: maintain a population of natural-language hypotheses as particles, update them with Metropolis-Hastings (VPP-MH) or Sequential Monte Carlo (VPP-SMC), and predict by Bayesian model averaging. Both algorithms treat the LLM as a black box, requiring no access to logits or gradients. A distinctive consequence follows. In classical Bayesian learning, model selection sits outside the posterior; in VPP both model structure and parameters share a single language space, and the posterior ranges over both. We evaluate VPP on regression, classification, and rule-discovery benchmarks. It improves over a single VML run on every benchmark and matches or exceeds an oracle-best ensemble of independent VML runs on most, while eliminating the catastrophic single-run failures that VML occasionally produces. Because each particle is a human-readable hypothesis, the posterior is itself something a reader can inspect, seeing in plain text which explanations the data supported and which it ruled out.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：现有的“语言化机器学习”（Verbalized Machine Learning, VML）将模型参数化为自然语言提示词（Prompt），虽然具有极高的可解释性，但存在两个致命缺陷：
    1.  **不稳定性**：由于优化过程在离散的语言空间中具有随机性，同一数据集的不同运行结果差异巨大（如线性回归的 MSE 差异可达 44.7 倍）。
    2.  **缺乏不确定性度量**：VML 仅输出单一假设，无法表达模型对预测的把握程度，且容易因单次错误的优化步骤而彻底丢失好的假设。
*   **整体含义**：本文提出 **VPP (Verbalized Particle Posterior)** 框架，首次将贝叶斯推理引入语言化假设空间。它不再追求单一的“最佳”提示词，而是维护一个假设群体（粒子），通过贝叶斯后验更新来捕捉不确定性，并提高模型的稳健性。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：将自然语言假设 $\theta$ 视为随机变量，通过 LLM 作为黑盒评估器，在语言空间内构建后验分布 $p(\theta | D)$。
*   **关键技术细节**：
    *   **似然函数定义**：回归任务使用负均方误差（MSE），分类任务使用平滑的 0-1 损失。由于是黑盒设置，仅根据 LLM 的预测输出计算似然，无需 Logits。
    *   **VPP-MH (Metropolis-Hastings)**：利用优化器 LLM 生成候选假设，通过接受/拒绝步骤（Accept/Reject）过滤掉性能下降的提议，防止模型退化。
    *   **VPP-SMC (顺序蒙特卡洛)**：维护带权重的粒子群。包含**重采样**（淘汰低质量假设）、**似然回火**（Tempering，防止权重塌陷）和**自适应变异**（根据粒子质量调整 LLM 的采样温度）。
    *   **贝叶斯模型平均 (BMA)**：预测时不再依赖单一假设，而是对所有粒子（假设）的预测结果进行加权平均或投票。

### 3. 实验设计

### 5. 实验数量与充分性
*   **实验规模**：每个任务均在 **3 个随机种子**下重复，报告了均值和标准差。
*   **消融实验**：
    *   验证了 **接受/拒绝步骤** 的必要性（去除该步骤会导致性能大幅下降）。
    *   研究了 **粒子数量 $K$**（1, 3, 5, 10）对结果的影响，证明了增加粒子数能显著提升性能。
*   **充分性评价**：实验设计较为客观，对比了“预言机最佳”这一极强的基准，证明了 VPP 的优越性不仅来自计算量的增加，更来自贝叶斯框架对权重的合理分配。

### 6. 主要结论与发现
*   **性能提升**：VPP 在所有基准测试中均优于单次 VML。在多项式回归中，VPP-SMC 将 MSE 降低了 **24 倍**。
*   **消除灾难性失败**：VML 偶尔会产生准确率极低（如 32%）的运行，而 VPP 通过粒子过滤彻底消除了这种极端失败。
*   **不确定性信号**：VPP 能够通过粒子间的分歧提供不确定性度量。在模型完全掌握规则时，粒子趋于一致；在模糊地带，粒子分歧增大。
*   **模型选择自动化**：在 VPP 中，模型结构（如选择线性还是分段函数）和参数推断在同一个语言空间内同时完成。

### 7. 优点
*   **鲁棒性强**：通过贝叶斯框架克服了 LLM 优化过程中的随机性和不稳定性。
*   **高度可解释**：后验分布中的每个粒子都是一段人类可读的文字，用户可以直接查看模型“考虑”了哪些假设以及为什么排除某些假设。
*   **黑盒适用**：不需要访问模型的梯度或 Logits，适用于 API 形式的闭源模型。

### 8. 不足与局限
*   **计算成本高**：由于需要维护多个粒子并进行多次 LLM 调用，推理和训练的时间/金钱成本比单次 VML 高出一个数量级。
*   **算术能力限制**：尽管框架很强，但受限于 LLM 本身的算术能力，在处理高精度数值回归任务时仍存在瓶颈。
*   **任务规模**：目前的实验主要集中在合成数据集和相对较短的序列上，在超大规模真实数据集上的表现尚待验证。
*   **MH 近似风险**：由于无法精确计算语言生成的先验概率 $p(\theta)$，MH 算法中的接受率计算存在理论上的近似，可能导致采样偏离真实后验。
