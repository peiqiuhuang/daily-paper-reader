# Near-Optimal Complexity of Finite-Sum Nonconvex-Strongly-Concave Minimax Optimization 

Qihao Zhou ∗

Abstract 

We characterize, up to logarithmic factors, the minimax expected query complexity of finite-sum nonconvex–strongly-concave optimization under mean-squared averaged smooth-ness. For randomized zero-respecting incremental first-order algorithms, the complexity is 

eΘ( n + min {√n κ, n 3/4√κ} L∆ε−2) throughout κ = L/μ ≥ 1, under exact dual initialization and for 0 < ε 2 ≤ c0L∆, where c0 > 0 is universal. This characterization is our main result. Adual-chain construction provides the lower bound and matches the existing Catalyst upper bound for κ ≥ √n. For 1 ≤ κ ≤ √n, we introduce recursive proximal descent–ascent (RPDA), which re-tains a recursive gradient estimator across proximal subproblems and attains eO(n + √n κL ∆ε−2)with a fixed query budget. Both upper bounds guarantee an expected squared primal gradi-ent at most ε2. Under individual smoothness, we also prove Ω( n + min {κ, √nκ } L∆ε−2) for every κ ≥ 1. It matches the polynomial upper rate for a bilinear subclass when κ ≥ n; the intermediate-condition-number gap remains open.

Algorithm 1 gives the method behind Theorem 3. Its three phases are initialization, proximal iterations, and final refinement; every update is written explicitly below.
