## 摘要
上下文学习（In-context learning）对演示样本的选择高度敏感，然而大多数方法仅通过外部的查询-演示相似度来进行选择。此类标准往往会忽略模型特定的信号：相似的演示样本可能会激活不同的内部特征并导致不同的下游行为。我们提出了 PULSE（基于稀疏编码的配对效用定位），这是一个基于稀疏自编码器（SAE）的框架，旨在识别与演示效用相关的模型内部特征，并将其用于演示样本的选择。利用一个小型的标注发现集，PULSE 对候选演示集进行采样，衡量它们在目标模型下的零样本相对效用，并根据 SAE 特征的激活差异与效用差异的对齐程度对特征进行评分。排名前后的正负坐标构成了一个稀疏的效用定位向量。我们以两种互补的方式使用该向量：作为受控完整集排序的带符号分数，以及作为 PULSE-Retriever，将其幅度转换为特征相关性掩码，以实现可扩展的池级检索。在分类、生成和推理基准测试中，PULSE-Retriever 分别比最强基线提高了 2-3 个准确率点、0.6-0.9 的 BLEU-4 分数以及 3.2 个精确匹配点，同时受控排序验证了所识别的特征编码了预测性的集合级效用信号。特征检查和跨数据集实验表明，所识别的特征捕捉到了与任务相关且受数据集条件限制的模式，同时保留了在不同数据集间部分迁移的效用信号。我们的代码可在 https://github.com/aohenuo/PULSE 获取。

## Abstract
In-context learning is highly sensitive to demonstration choice, yet most methods select demonstrations using external query-demonstration similarity. Such criteria can miss model-specific signals: Similar demonstrations may activate different internal features and downstream behaviors. We introduce PULSE (Paired Utility Localization over Sparse Encodings), an SAE-based framework for identifying model-internal features associated with demonstration utility and using them for demonstration selection. Using a small labeled discovery set, PULSE samples candidate demonstration sets, measures their zero-shot-relative utility under the target model, and scores SAE features by how their activation differences align with utility differences. The top positive and negative coordinates form a sparse utility-localization vector. We use this vector in two complementary ways: as a signed score for controlled complete-set ranking, and as PULSE-Retriever, which converts its magnitude into a feature-relevance mask for scalable pool-scale retrieval. Across classification, generation, and reasoning benchmarks, PULSE-Retriever improves over the strongest baseline by 2-3 accuracy points, 0.6-0.9 BLEU-4, and 3.2 exact-match points, respectively, while controlled ranking validates the identified features encode a predictive set-level utility signal. Feature inspection and cross-dataset experiments suggest that the identified features capture task-relevant, dataset-conditioned patterns, yet retain utility signals that partially transfer across datasets. Our code is available at https://github.com/aohenuo/PULSE.
