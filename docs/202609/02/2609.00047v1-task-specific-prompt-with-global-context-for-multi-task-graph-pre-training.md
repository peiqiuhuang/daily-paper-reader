## 摘要
图提示学习是在低资源场景下将预训练图模型适配到下游任务的一种有效范式。然而，现有的多任务图预训练框架通常使用随机初始化的提示，导致提示空间、代理目标与图结构特征之间的对齐效果较差。这大大削弱了提示表示的任务相关性、结构感知能力和可迁移性。为了应对这一挑战，我们提出了 TPGC，这是一种双重先验提示初始化方案，显式地建模了任务先验与结构先验之间的协同作用。具体而言，任务先验注入模块首先在辅助图上进行简短的同源多任务预训练，使提示初始化能够继承与多个代理任务相关的优化偏好。在任务感知表示的基础上，结构先验注入模块进一步从辅助图中提取可迁移的全局结构上下文，通过聚合具有结构信息的节点嵌入，将其转换为逐层提示向量。在涵盖节点分类和图分类的 6 个主流基准数据集上的广泛实验表明，在少样本设置下，TPGC 的性能始终优于最先进的基准模型，且具有更少的下游可调参数和更短的运行时间。代码可在 https://github.com/Virgilqiu/TPGC 获取。

## Abstract
Graph prompt learning is an effective paradigm to adapt pre-trained graph models to downstream tasks in low-resource scenarios. However, existing multi-task graph pre-training frameworks generally use randomly initialized prompts, leading to poor alignment between the prompt space, pretext objectives and graph structural characteristics. This greatly weakens the task relevance, structural awareness and transferability of prompt representations. To address this challenge, we propose TPGC, a dual-prior prompt initialization solution that explicitly models the synergy between task prior and structural prior. Specifically, the Task-Prior Injection Module first conducts a short homologous multi-task pre-training on an auxiliary graph, enabling prompt initialization to inherit optimization preferences associated with multiple pretext tasks. Built on the task-aware representations, the Structure-Prior Injection Module further extracts transferable global structural context from the auxiliary graph, converting it into layer-wise prompt vectors by aggregating structurally informative node embeddings. Extensive experiments on 6 mainstream benchmarks covering node and graph classification show that TPGC achieves consistently better performance under few-shot settings than state-of-the-art baselines, with fewer downstream tunable parameters and lower runtime. The code is available at https://github.com/Virgilqiu/TPGC

#### 1. 核心问题与整体含义（研究动机和背景）
图提示学习（Graph Prompt Learning）旨在通过引入可学习的提示向量，将预训练的图模型高效适配到低资源（Few-shot）下游任务。然而，现有框架（如 MultiGPrompt）通常采用**随机初始化**的提示。
*   **研究动机**：随机初始化导致提示空间与预训练目标、图结构特征之间缺乏对齐，使得提示表示的任务相关性弱、结构感知力差且迁移性不足。
*   **核心问题**：如何在预训练阶段之前，为提示提供一个包含“任务先验”和“结构先验”的高质量初始起点，从而提升多任务协作效率和下游适配性能。

#### 2. 方法论：核心思想与技术细节
论文提出了 **TPGC** 框架，将提示初始化分解为两个协同模块，并在三个阶段（初始化、目标域预训练、下游适配）中运行：

*   **核心思想**：利用一个与目标图语义/结构相关的**辅助图**（Auxiliary Graph），通过简短的预训练提取先验知识来初始化提示。
*   **关键技术模块**：
    1.  **任务先验注入模块 (TPIM)**：在辅助图上进行仅 **1个 Epoch** 的同源多任务预训练。使共享编码器吸收不同代理任务（如 DGI, GraphCL, LP）的优化偏好，演化为任务感知编码器。
    2.  **结构先验注入模块 (SPIM)**：利用优化后的编码器提取辅助图的全局结构上下文。通过计算节点嵌入与任务全局嵌入的余弦相似度，筛选 **Top-k** 个最具代表性的节点进行加权聚合，生成逐层（Layer-wise）初始提示向量。
*   **算法流程**：
    *   **初始化**：在辅助图上运行 TPIM 和 SPIM，通过投影矩阵解决跨图维度对齐问题。
    *   **目标域预训练**：将初始化的提示注入目标图编码器，进行多任务联合优化。
    *   **下游适配**：冻结预训练提示作为先验，引入少量下游特定提示进行融合微调。

#### 6. 主要结论与发现
*   **性能领先**：TPGC 在绝大多数 Few-shot 设置下均优于 SOTA 方法，尤其在节点分类任务上提升显著。
*   **初始化至关重要**：实验证明，相比随机初始化，TPGC 提供的初始点更接近高密度、有语义的节点簇，显著加快了预训练的收敛速度。
*   **稳定性强**：即使移除下游特定提示，仅靠预训练得到的提示，TPGC 的性能下降也远小于 MultiGPrompt，说明其学习到的提示更具任务感知力和鲁棒性。

#### 7. 优点
*   **视角新颖**：首次从“提示初始化”而非单纯的“提示设计/微调”角度切入，解决了多任务图预训练中的对齐难题。
*   **双重先验协同**：巧妙结合了任务优化偏好（TPIM）与全局结构上下文（SPIM），使提示具备了跨图迁移的能力。
*   **高效轻量**：在提升精度的同时，保持了极低的下游参数量和推理延迟，适合资源受限的应用场景。

#### 8. 不足与局限
*   **异质图限制**：论文提到目前的设计在处理**异质图（Heterophilous Graphs）**（即相连节点标签通常不同的图）时可能存在局限。
*   **辅助图依赖**：该方法依赖于寻找一个与目标图同源或相关的辅助图，若缺乏合适的辅助数据，初始化效果可能会打折扣。
*   **超参数敏感性**：Top-k 采样值等超参数在不同领域数据集上的通用性仍有待进一步探讨。
