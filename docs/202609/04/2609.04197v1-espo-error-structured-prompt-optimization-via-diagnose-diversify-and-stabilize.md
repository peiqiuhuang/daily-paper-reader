## 摘要
像 GEPA 这样的演化提示词优化器面临“提示词膨胀”问题：每次迭代都会追加规则与注意事项，导致生成的提示词长度增至原来的 3 倍，但准确率却没有提高。我们将这一问题归结为三个缺陷——错误观察不完全、搜索多样性有限以及选择机制不可靠——并提出了 ESPO（错误结构化提示词优化）。ESPO 将提示词优化分解为三个阶段：诊断（Diagnose）在单轮内将所有训练错误聚类为结构化模式；提议（Propose）利用四种具有独立偏置的互补策略生成候选提示词；选择（Select）则应用自助法稳定性选择。在七个公开 NLP 基准（Tweet、MMLU、GSM8K、HotpotQA、ScoNe、HoVer 和 PUPA）上，ESPO 的平均准确率相比当前最优方法（SOTA）提高了 3.76 个百分点（74.67% vs GEPA 的 70.91%），在每个数据集上均达到或超越了 GEPA，同时生成的提示词短了 47%（1,004 字符 vs 1,878 字符），且推理速度更快。在四个额外学生模型（Gemma 3 12B、Mistral 14B、Qwen3 32B、Claude Haiku 4.5）上的跨模型实验表明，ESPO 在所有测试模型上均获得了最佳平均准确率，其中在 Qwen3 GSM8K 上的提升最为显著（15.00% $\to$ 91.40%）。泛化界（附录）将每个阶段与测试时差距的对应项联系起来，消融实验证实了一个关键预测：在没有自助法选择的情况下增加多样性实际上会损害性能（$-$1.20%）。

## Abstract
Evolutionary prompt optimizers such as GEPA suffer from prompt bloat: each iteration appends rules and caveats, producing prompts up to 3$\times$ longer yet no more accurate. We trace this to three deficiencies - incomplete error observation, limited search diversity, and unreliable selection - and propose ESPO (Error-Structured Prompt Optimization), which decomposes prompt optimization into three phases: Diagnose clusters all training errors into structural patterns in one round; Propose generates candidates via four complementary strategies with independent biases; Select applies bootstrap stability selection. On seven public NLP benchmarks - Tweet, MMLU, GSM8K, HotpotQA, ScoNe, HoVer, and PUPA - ESPO improves average accuracy by $+$3.76 pp over the state-of-the-art (74.67% vs 70.91% for GEPA), matching or exceeding GEPA on every dataset while producing prompts 47% shorter (1,004 vs 1,878 chars) and faster at inference. Cross-model experiments across four additional student models (Gemma 3 12B, Mistral 14B, Qwen3 32B, Claude Haiku 4.5) show ESPO yields the best average accuracy on every model tested, with the largest gap on Qwen3 GSM8K (15.00% $\to$ 91.40%). A generalization bound (Appendix) grounds each phase in a corresponding term of the test-time gap, and the ablation confirms a key prediction: adding diversity without bootstrap selection actually hurts performance ($-$1.20%).

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **研究背景**：在大语言模型（LLM）的自动化提示词优化（Automated Prompt Optimization）中，GEPA、MIPROv2、COPRO 等演化算法通过“评估-反思-变异-筛选”的循环来提升性能。
*   **核心痛点（提示词膨胀/Prompt Bloat）**：演化类方法在每次迭代中会不断向提示词追加规则和注意事项，导致提示词长度急剧膨胀（可达初始长度的 3 倍以上），但准确率停滞不前。这不仅增加了推理成本和延迟，还容易导致对训练噪声的过拟合。
*   **归因分析（三大结构性缺陷）**：
    1.  **错误观察不完全**：以往方法每轮仅随机采样少量（如 3–8 个）错误样例进行反思，需多轮迭代才能覆盖全部错误模式，导致生成冗余或相互矛盾的“治标不治本”规则。
    2.  **搜索多样性有限**：依赖单一变异算子，难以应对多样的错误类型，只能靠堆叠规则补救。
    3.  **候选选择不可靠**：在较小的验证集（如 ~30 个样本）上直接根据点估计得分挑选候选，极易选中因数据噪声偶然排名靠前的冗长提示词。
*   **整体含义**：论文将提示词优化从“演化搜索”重新定义为**“结构化统计估计”**，提出了 **ESPO** 框架，从理论与实践上系统性解决了提示词膨胀和过拟合问题。

### 2. 论文提出的方法论

ESPO 将提示词优化拆解为三个解耦阶段，并以统计泛化界（Generalization Bound）作为理论支撑：

*   **阶段 1：诊断（Phase 1: Diagnose - 结构化错误诊断）**
    *   收集当前提示词下的**所有训练错误**，利用强反思 LLM 单轮完成错误聚类，归纳出 3–7 种结构化失效模式（包含原因描述、代表性样例和错误频次）。
    *   相比随机采样，单轮全量聚类直接降低了搜索的偏置下限（Bias Floor）。
*   **阶段 2：提议（Phase 2: Propose - 多策略候选生成）**
    *   基于诊断结果，采用 $K=4$ 种互补策略并行生成候选提示词：
        *   **$S_1$ 诊断修正（Diagnostic Revision）**：针对失效模式根因重写规则。
        *   **$S_2$ 紧凑巩固（Consolidation）**：融合冗余规则、精简表达，在不增加长度前提下重写（从构造上防止膨胀）。
        *   **$S_3$ 消融（Ablation）**：软化或删除导致假阳性（Over-triggering）的过度触发规则。
        *   **$S_4$ 事实注入（Factual Injection）**：从错误样例中提取领域事实知识作为上下文。
    *   经过种子生成、交叉重组（Cross-pollination）和针对性精炼，将候选池限制在 Top $N=10$。
*   **阶段 3：选择（Phase 3: Select - 自助法稳定性选择）**
    *   采用 **Bootstrap 稳定性选择**（$B=20$ 次重采样），在验证集上重采样计算胜率，通过多数票（Plurality Vote）选出最稳健的候选提示词。
    *   出现平局时，优先选择更短的提示词（隐式引入最小描述长度 MDL 原则）。
*   **理论视角**：GEPA 可以看作 ESPO 在 $K=1, B=1, m=3$ 时的退化特例；ESPO 证明了泛化误差界由偏置减少（诊断）、极值统计量增益（多样性）和自举集中不等式（稳定性选择）三项共同决定。

### 6. 主要实验结果与核心结论

*   **性能显著超越 SOTA**：

*   **彻底解决提示词膨胀（Prompt Bloat）**：
    *   GEPA 等演化方法优化后的提示词字符数常常膨胀至 **3,000–6,000+ 字符**（为初始长度的 300%–500%）。
    *   ESPO 生成的提示词平均字符数仅为 **800–1,200 字符**（仅为 GEPA 的 **20%–40%**），且结构清晰、无冗余废话，极大地节省了部署后的推理延迟与 Token 成本。
*   **跨模型泛化性极强（Cross-Model Generalization）**：
    *   在 Gemma 3 12B、Mistral 14B、Qwen3 32B 等开源模型上的迁移与优化实验表明，ESPO 优化的提示词具有高度的“模型通用性”，在小型开源模型上同样表现突出，未发生针对特定 API 模型的过拟合。
*   **消融实验（Ablation Study）结论**：
    *   **诊断（Diagnose）**：去掉全量错误聚类、退化为随机抽取样例后，优化效果下降显著，规则开始出现矛盾。
    *   **多样性（Diversify）**：缺少 $S_2$（巩固）和 $S_3$（消融）策略时，提示词长度会迅速反弹膨胀；缺少 $S_4$（事实注入）时，知识密集型任务（如 HoVer/MMLU）性能下降明显。
    *   **稳定性选择（Bootstrap Select）**：若去掉 Bootstrap 筛选、直接使用单次验证集得分选择，提示词的方差剧增，极易选中过拟合的冗长候选。

### 7. 论文的局限性与未来研究方向

*   **局限性（Limitations）**：
    1.  **对反思模型能力有一定依赖**：阶段 1 的错误诊断与聚类依赖强 LLM（如 Claude Sonnet 或 Qwen32B+）的高质量反思能力，若使用能力较弱的模型作为诊断器，聚类质量可能下降。
    2.  **验证集调用的采样开销**：Bootstrap 稳定性选择（$B=20$ 次重采样）虽然保证了稳健性，但在验证集评估阶段需要多次反复运行，导致验证阶段的 API 调用次数增加（尽管总 Token 消耗仍远低于演化方法的多次变异循环）。
    3.  **主要聚焦于客观评价任务**：实验评估主要集中在具有明确 Ground Truth 的任务（分类、推理、问答、数学），在极度开放、难以自动化量化标定的生成任务（如长文写作、多轮对话）上的验证尚需扩大范围。
*   **未来工作（Future Work）**：
    *   将 ESPO 扩展至多模态提示词优化（Vision-Language Prompts）。
    *   设计自适应 Bootstrap 采样机制（根据候选得分差异动态调节重采样次数 $B$，进一步节省算力）。
    *   将结构化诊断思想引入 Agent 复杂工作流（Tool-use Prompting）的自动优化中。
