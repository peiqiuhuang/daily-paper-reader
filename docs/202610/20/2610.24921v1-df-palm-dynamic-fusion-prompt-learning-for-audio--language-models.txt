# DF-PALM: Dynamic Fusion Prompt Learning for Audio–Language Models 

Yulin Sun, Shenghua Li, Yong Dou, Xinwang Liu, Senior Member, IEEE, Cheng Yang, and Kele Xu, Senior Member, IEEE 

Abstract —Few-shot audio classification requires audio– language models to distinguish variable acoustic events from limited labeled data. PALM’s main formulation adapts encoded class representations without changing pretrained encoders, but its class representations remain input-independent and classifi-cation uses audio features without class-conditioned refinement. We introduce DF-PALM, a dynamic feature-space prompting framework that combines audio-conditioned class representations with asymmetric cross-attention for audio refinement. Class rep-resentations are conditioned after text encoding, held fixed across fusion layers for each input, and reused for final scoring. Both pretrained encoders remain frozen, avoiding audio-conditioned text-encoder passes. With PENGI as the frozen backbone, the main 16-shot evaluation covered 11 benchmarks and six baselines. DF-PALM achieved 80.69% mean accuracy and 80.32% macro-averaged F1, exceeding PALM by 4.11 and 4.30 percentage points, respectively. Paired benchmark-level tests supported both gains after Holm correction. Across four shot settings, DF-PALM achieved the highest mean accuracy and macro-averaged F1 among the four evaluated prompt-learning methods. The gains extended to LAION-CLAP and OpenFLAM, with significant im-provements over PALM in both metrics. At 50 candidate classes, operator-counted inference floating-point operations increased by 0.39% relative to PALM. These results support instance-conditioned feature-space adaptation as an effective approach to few-shot audio classification. Our code is publicly available at GitHub https://github.com/sunyulin0421/DF-PALM. 

Index Terms —Audio–Language Models, Few-Shot Learning, Prompt Learning, Audio Classification, Cross-Modal Fusion. 

I. I NTRODUCTION 

# CONNECTING acoustic events with natural language is central to multimodal understanding [1]–[3]. Vision– Language Models have established strong correspondences between visual observations and semantic concepts [4]–[6]. Audio–Language Models (ALMs), by contrast, must align language with signals that unfold over time and vary markedly across recordings. Recordings of the same event can differ in source distance, background interference, and recording conditions [7]–[10]. This variability makes reliable audio– language alignment particularly difficult when only a few labeled examples are available. Prompt learning adapts ALMs without fine-tuning the full backbone, using input-independent contexts or instance-conditioned prompts formed before text encoding [11]–[13].

CoOp and CoCoOp optimize input prompts by propagating gradients through the text encoder while retaining its pre-trained weights. The main PALM formulation instead adapts encoded text features with input-independent class repre-sentations. Acoustic variation motivates conditioning these representations on each input while retaining class-specific information. These prompt baselines classify audio features by similarity to class representations, without using class information to refine the audio features before scoring [11]. Pre-scoring audio–text interaction has been explored through parameter-free alignment and multi-grained corre-spondence learning [14], [15]. The question here is how to combine instance-conditioned class representations with audio refinement after text encoding while keeping pretrained encoders fixed. We present DF-PALM (Dynamic Fusion Prompt Learn-ing for Audio– Language Models), a dynamic feature-space prompt-learning framework for frozen ALMs. DF-PALM com-bines an Instance-Level Dynamic Context Generator with 

Asymmetric Cross-Modal Fusion . The first adds a shared audio-conditioned residual to class-specific contexts after text encoding. The second refines the audio representation against the conditioned class representations, which remain fixed across fusion layers for each input. This design combines in-stance conditioning with class-guided audio refinement in fea-ture space, without requiring audio-conditioned text-encoder passes. Our main contributions are as follows:

A. Audio–Language Representation Learning 

Audio–Language Models (ALMs) learn shared represen-tations that connect acoustic signals with natural-language descriptions [16], [17]. Contrastive models such as Audio-CLIP [8] and CLAP [7], [18] align global audio and text embeddings for zero-shot transfer. Generative ALMs such as PENGI [19] connect audio encoders to pretrained language models through prefixes, adapters, or related interfaces [20], [21]. Despite their broad transfer capabilities, adapting ALMs to data-scarce downstream tasks can still require substantial opti-mization. This has motivated approaches that adapt pretrained representations without updating the full backbone [22], [23]. 

B. Prompt Learning in Multimodal Models 

Prompt learning adapts pretrained models through learnable context parameters rather than full-backbone updates [24], [25]. Initially developed for natural-language models [26], [27], this approach was subsequently extended to multimodal architectures. In vision–language models, CoOp [12] replaces hand-crafted prompts with learnable but input-independent con-text vectors. CoCoOp [13] introduces instance conditioning by generating context vectors from visual features. Because CoCoOp’s conditioned prompts are formed before text encod-ing, their optimization requires gradients to pass through the text encoder. Other developments include multi-modal prompt learning [28] and prompt distribution learning [29]. PALM [11] brings prompt learning to ALMs by optimizing encoded text features rather than input tokens. This design moves learnable adaptation into feature space and leaves the text-encoder parameters unchanged, with input-independent class representations in its main formulation. PALM’s abla-tions also explore audio feedback to encoded text features. DF-PALM builds on this feature-space setting by coupling instance-conditioned class representations with audio refine-ment against a class matrix held fixed across fusion layers and reused for final scoring.

C. Cross-Modal Alignment and Parameter-Efficient Adapta-tion 

Fusion encoders learn interactions between modalities before prediction [30]–[33], and audio–language methods also introduce alignment after pretraining. PAT selects and weights textual prompts and uses text-guided frame-level audio reweighting to improve zero-shot classification without additional trainable parameters [14]. Zhao et al. learn multi-grained audio–text correspondences using a key-value cache, cross-modal contrast, and optimal transport for few-shot audio recognition [15]. DF-PALM learns instance conditioning and asymmetric fusion directly from global audio vectors and encoded class names, retaining both pretrained encoders. Parameter-efficient adaptation also includes inserted adapters [22] and low-rank adaptation (LoRA), which learns low-rank updates to pretrained weight matrices [34]. The three-stage ASPL ∗ variant introduces affine modulation within the audio encoder and combines it with text-side prompt learning [35]. These approaches modify encoder processing through inserted modules or weight updates. DF-PALM places its trainable conditioning and fusion modules after the pretrained encoders, operating on their output representations. Support-set adaptation provides a further approach to few-shot classification using frozen representations. ProKeR com-bines a zero-shot predictor with support information through kernel adaptation [36], whereas FS-AVG averages support audio embeddings into class prototypes [37]. We evaluate both methods with the same PENGI backbone used by DF-PALM. For the selected configurations in the matched ESC-50 8-shot setting, DF-PALM required 1 h 27 min of training, compared with 5 h 51 min for CoCoOp and 1 h 24 min for PALM (Table I). III. B. Instance-Level Dynamic Context Generation 

The Instance-Level Dynamic Context Generator conditions the feature-space context on the global audio representation. A bottleneck network gϕ predicts an input-dependent residual: 

∆z(x) = gϕ(a) = W2ρ(W1a) , (3) where ρ denotes ReLU. We use W1 ∈ R dr ×d and W2 ∈

Rd× dr , with a reduction ratio of r = 16 . The bottleneck reduces the hidden width from d to d/r .The residual is shared across classes and added to each class-specific context vector:

Ti(x) = L2Norm((1 − λi)ti + λizi(x)) . Class-specific mixing and L2 normalization determine how this residual changes each class representation. The shared context generator provides instance conditioning with a parameter count independent of the number of classes. Conditioning follows text encoding and requires no audio-conditioned text-encoder pass; the text-encoder parameters remain frozen.

B. Baselines 

We compared DF-PALM with six baselines spanning zero-shot inference, prompt learning, kernel adaptation, and pro-totype adaptation. For CoOp and CoCoOp, we replaced the image encoder with PENGI’s audio encoder while retaining their prompt-learning procedures. Zero-Shot [19] uses the template “ This is a recording of 

{CLASS }”. CoOp [12] learns input-independent context tokens before text encoding, whereas CoCoOp [13] conditions them on each audio input. PALM [11] optimizes input-independent class representations after text encoding and is the principal feature-space baseline. ProKeR (PENGI) applies the ProKeR kernel formula-tion [36] to frozen PENGI audio and class-text embeddings. FS-AVG (PENGI) [37] averages the 16-shot audio embeddings within each class and classifies by cosine similarity between normalized queries and prototypes, without text embeddings, gradients, or trainable parameters.

DF-PALM combines audio-conditioned feature-space prompts with cross-attention that refines audio representations against fixed, instance-conditioned class representations. Both pretrained encoders remain frozen, confining trainable adaptation to feature space. Across 11 benchmarks using PENGI in the 16-shot setting, DF-PALM achieved the highest mean accuracy and Macro-F1 among the evaluated methods, exceeding PALM by 4.11 percentage points in mean accuracy. It also led the four evaluated prompt-learning methods on both metrics across all four shot settings. DF-PALM improved the cross-benchmark means of both metrics over PALM on all three evaluated audio–language backbones. These results support instance-conditioned feature-space adaptation as an effective approach to few-shot audio clas-sification. B. Support-Set Configuration Selection 

For each benchmark, outer fold where applicable, and seed, DF-PALM selects its fusion configuration within the corresponding 16-shot support set. Four internal folds fit each candidate on 12 examples per class and validate on four. Selection maximizes the mean validation Accuracy across the four internal folds for that run, without pooling scores across outer folds, seeds, or benchmarks. The outer test samples are excluded from both candidate fitting and validation. The procedure uses no labels beyond that run’s 16-shot support set. The search covers eight depths and four head counts with the remaining settings fixed. Each independently selected configuration is retrained on all 16 examples per class and evaluated at epoch 50. All selections yielded L = 3 , H = 4 .The corresponding configuration is retained for the 4-, 8-, and 32-shot runs. CoOp, CoCoOp, and PALM use their reported hyperparameters without additional tuning. ProKeR selects its kernel configuration using a class-stratified 12/4 support split, then refits on all 16 examples per class. In the main 16-shot setting, the methods share the support-label budget while retaining their specified selection procedures.
