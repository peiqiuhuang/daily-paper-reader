Prompt-based adaptation offers several ways to specialize a frozen language model, ranging from natural-language prompt optimization to learned continuous prompts. These methods are usually compared through downstream performance, although similar outputs need not arise from similar internal computations. We study how discrete prompt optimization, prompt tuning, and prefix tuning alter the processing of dense and mixture-of-experts language models. Our analysis shows that the location of the adaptation predicts how task information is carried to the output: optimized text primarily changes response construction, input-level prompts write their influence into content representations, and layer-wise prefixes maintain direct control through attention. In MoE models, these differences further induce distinct expert-routing patterns. At the same time, common representation-level measurements respond strongly to generic context changes and do not reliably distinguish useful adaptations from matched placebos. We argue that understanding prompt adaptation requires separating representation drift from the part of that drift that is aligned with, and causally used by, the model’s task computation. This perspective provides practical guidance for selecting, evaluating, and interpreting prompt adaptation methods. 

## 1 Introduction 

Large language models (LLMs) are increasingly adapted as frozen backbones, allowing one model to support many tasks without storing or serving a separate set of weights for each application. Context becomes the adaptation interface: a task can be specified through a natural-language instruction, learned continuous vectors at the input, or learned states inserted into the attention computation [Agrawal et al., 2026, Lester et al., 2021, Li and Liang, 2021]. The most direct approach searches for a better textual prompt. Early methods optimized individual tokens, while recent systems use language models to propose, critique, and refine complete instructions [Shin et al., 2020, Pryzant et al., 2023]. A complementary line replaces text with trainable continuous states. Prompt tuning learns input embeddings, whereas prefix tuning exposes learned keys and values to every Transformer layer [Lester et al., 2021, Li and Liang, 2021]. These methods optimize the context seen by the same frozen model, but provide different access to its computation. In practice, these methods are usually compared by downstream score. This is insufficient for understanding what the adaptation changed. A gain may arise from a better task decision, more reliable adherence to an output protocol, or a different route through which an existing decision reaches the language-model head. In a mixture-of-experts (MoE) model, the same contextual change can additionally alter which expert parameters process each token [Olson et al., 2025]. Similar outputs therefore need not imply similar internal computations. Research on prompt optimization has made substantial progress in improving task performance, while mechanistic studies of contextual learning have identified task vectors and prompt-induced geometric changes [Agrawal et al., 2026, Todd et al., 2024, Kirsanov et al., 2025]. These directions have largely developed separately. Performance-oriented studies rarely locate the computation that mediates the gain, while representation analyses 1arXiv:2610.18412v1 [cs.LG] 13 Oct 2026 often show that a prompt changes hidden states without testing whether the measured change is sufficient to alter the output [Hewitt and Liang, 2019, Zhang and Nanda, 2024]. We study prompt adaptation from this functional perspective. We compare discrete prompt optimization, prompt tuning, and prefix tuning under a common frozen-model protocol, follow task information through a dense model, and test observational signatures against matched placebos and causal interventions. We then examine sparse models, where a hidden-state change can become a discrete routing decision. Our results support a common account: the insertion site constrains how an adaptation can influence the network, while common metrics often capture broad representation drift rather than the smaller state change sufficient to mediate the adapted output. 

## 2 Related Work 

Continuous prompts. Continuous prompting adapts a frozen model by optimizing trainable states rather than model parameters. Prefix tuning introduced task-specific keys and values that remain available throughout the attention stack [Li and Liang, 2021], while prompt tuning showed that embeddings inserted only at the input become increasingly competitive as model scale grows [Lester et al., 2021]. Deep variants such as P-Tuning v2 extend these states across layers and tasks [Liu et al., 2022]. These methods therefore differ not only in parameter count, but also in the depth at which they can influence computation. Theoretical analyses characterize both the expressive power of prompt-mediated attention and the restrictions imposed by a frozen backbone [Oymak et al., 2023, Petrov et al., 2024]. Their learned states remain difficult to interpret, since nearest-token projections can be unfaithful and human-readable constraints may reduce task performance [Patel et al., 2025]. 

Discrete prompt evolution. A parallel line retains the natural-language interface and searches for better instructions. Prompt sensitivity first motivated gradient-guided trigger selection in AutoPrompt [Shin et al., 2020] and reward-based token generation in RLPrompt [Deng et al., 2022]. With stronger instruction-following models, optimization moved from isolated tokens to complete prompts: APE samples and selects candidate instructions [Zhou et al., 2023], ProTeGi combines textual gradients with beam search [Pryzant et al., 2023], and OPRO conditions an optimizer on previous solutions and scores [Yang et al., 2024]. Later methods jointly optimize instructions, demonstrations, or multistage programs [Opsahl-Ong et al., 2024]. GEPA adds natural-language reflection and evolutionary selection [Agrawal et al., 2026], while SPRIG studies iterative system-prompt optimization and transfer [Zhang et al., 2026]. This progression makes discrete adaptation accessible without gradients through the task model, but most evaluations still describe the resulting behavior rather than the computation that produced it. 

Mechanistic analysis. Mechanistic studies of contextual learning first asked which computations prompts elicit. Induction heads identify circuits that copy contextual patterns [Olsson et al., 2022], simplified Transformers can implement optimization-like updates during the forward pass [von Oswald et al., 2023], and task or function vectors can transfer behavior under intervention [Hendel et al., 2023, Todd et al., 2024]. This work motivated observational diagnostics of prompt-induced computation, including representation geometry [Kirsanov et al., 2025], task descriptions recovered through Patchscopes [Ghandeharioun et al., 2024, Ramati et al., 2025], and hidden-state shifts after system-prompt optimization [Zhang et al., 2026]. Such measurements establish that context changes the network, but not that the measured change produces the output. Linear probes and the tuned lens localize decodable information [Hewitt and Liang, 2019, Belrose et al., 2023]; activation steering and patching test causal sufficiency [Turner et al., 2023, Zhang and Nanda, 2024]; and sparse autoencoders provide a feature basis in which these interventions can be expressed [Huben et al., 2024, Gao et al., 2025]. Our comparison brings these stages together for three adaptation mechanisms under the same task and backbone, using matched placebos to test observational measurements and causal transfer to identify state-level mediators. 

MoE routing. This distinction becomes more explicit in mixture-of-experts models, where a contextual change can alter which parameters process a token. MoE Transformers route each token through a small expert subset, increasing total capacity at approximately fixed active computation [Fedus et al., 2022]. Load-balancing objectives limit concentrated traffic and unused experts [Wang et al., 2024, Tang et al., 2025, Molodtsov et al., 2026], while recent analyses show that routing reflects both token identity and contextual semantics [Olson et al., 2025]. Existing adaptation work mainly modifies weights, routers, or routed adapter modules [Liu et al., 2025]. The response of a frozen router to discrete, input-level, and layerwise prompt adaptation remains underexplored. 2Contributions. Our contributions can be summarized as follows: 

• A mechanistic explanation of prompt adaptation. We go beyond performance comparisons to explain how GEPA, prompt tuning, and prefix tuning change a frozen model’s computation. We trace their influence through attention, hidden states, and expert routing, using controls and interventions to separate useful adaptation from generic context effects. 

• How adaptation acts through attention in dense models. We study dense models to examine how each method changes attention and carries its influence into content representations. Attention masking and state interventions reveal how these changes affect output, while matched placebos show why representation drift alone is insufficient evidence of a useful mechanism. 

• How adaptation changes computational paths in MoE models. We examine the additional lever provided by routing: the same token can pass through different expert networks after adaptation. We separate changes in expert selection from changes in serving load, then test expert necessity through pruning. These interventions expose adapter-specific dependencies on rarely used experts that traffic statistics alone miss. 

## 3 Dense Models: From Adaptation Interface to Functional State Change 

GEPA, prompt tuning, and prefix tuning all optimize context while keeping the language model frozen, but they expose different parts of its computation to that optimization. GEPA rewrites natural-language tokens, prompt tuning learns embeddings inserted only at the input, and prefix tuning supplies learned keys and values to every attention block [Agrawal et al., 2026, Lester et al., 2021, Li and Liang, 2021]. These insertion sites define distinct routes by which an adaptation can remain available during generation: through textual instructions, through content states that inherit an input-level intervention, or through a layerwise attention channel. 3.2 Generic context produces substantial representation drift 

A length-matched padding prompt isolates the effect of adding context positions without task optimization. It changes residual geometry, degrades probe transfer, and lowers task performance. Padding therefore breaks any monotonic link between distance from the seed and adaptation quality (Figure 7a in Appendix B.5). The structure of the displacement leads to the same conclusion. Early in the stack, the dataset mean accounts for most of the shift energy under every condition, including padding. At later blocks, the centered remainder becomes high-rank for both adapted and padded contexts (Figure 7b). A large shared component and a structured per-example remainder therefore also arise when context is added without task optimization; neither signature identifies a useful adaptation by itself. This placebo changes the interpretation of the observational measurements. Distance, probe transfer, mean energy, and effective rank establish that the contexts induce different representations, but none identifies the part of the change sufficient to reproduce adapted behavior. Dense-model conclusion. The dense experiments form a single progression. Behavioral evaluation first separates label selection from answer construction; layerwise readouts then show how adapted information becomes available; and the padding placebo shows that the resulting representation drift is not specific to task improvement. Causal transfer isolates the finer distinction: the tested dataset mean is ineffective, while a matched-example late-state difference transfers most of the adapted output difference. Learned affine corrections recover much of the same behavior throughout free generation, even with one correction per example when trained with output supervision. This establishes behavioral transfer, but not that the maps reproduce the native adaptation mechanism. Every dense residual state still passes through the same feed-forward parameters. In an MoE backbone, the same state change can also alter which experts process the token. Routing therefore exposes a discrete intermediate decision that reveals whether adaptation changes not only the state, but also the parameters that act on it.

4.3 Frequency pruning removes experts the adapted model needs 

A concentrated load leaves many experts nearly idle: on this task the least-used half of a layer’s experts carries, on average over layers, only 2 to 13 percent of the routing mass, and the least-used three quarters 18 to 40 percent. Such experts are the natural candidates for removal. We prune them by masking, in every layer, the router logits of the least-used half or three quarters of the experts, ranked on the arm’s own calibration map. Removing little routing mass can still destroy readable answers (Table 5; full sweep in Appendix E.2). 

4.4 Rarely used super experts decide whether an adapted model survives 

Load is not the only way in which experts differ. Language models send much of their attention to a few initial tokens with little content, the attention sinks [Xiao et al., 2024], which are created by massive activations, a few hidden-state entries orders of magnitude larger than the rest [Sun et al., 2024, Gu et al., 2025]. In MoE models these are written by a handful of super experts with rare, extreme outputs, whose removal collapses the Qwen model studied by Su et al. [2026]. We recover experts 68, 92 and 82 of layers 1 to 3 on Qwen and identify expert 5 of layers 6 and 17 on gpt-oss (Appendix E.3). MoE conclusion. Adaptation reroutes an MoE model where it acts: GEPA keeps most expert assignments of the shared tokens, prompt and prefix tuning reassign more of them. Load statistics and pruning masks built from them are specific to each adapter, and load does not show which experts the model needs: a few rarely used super experts decide whether an arm survives pruning. 

## 5 Conclusion 

Prompt-based adaptation methods differ less in how much they change a frozen model than in where they act, with practical consequences for evaluation, interpretation and deployment. Under set parsing most of GEPA’s gain disappears while the continuous methods keep theirs, so an optimized prompt should be scored both ways before its gain is credited to task knowledge. A length-matched padding prompt reproduces the distance, probe, mean-energy and rank signatures of adaptation without improving the task, so representation metrics need such a placebo as a reference. An affine map from the seed state recovers most of the continuous gains without the adapted context and can even replace the last blocks, which makes such maps a practical probe of what an adaptation computes, although they need not reproduce the native mechanism. In MoE models, retraining the router alone recovers most of the adaptation gain, and the choice of adaptation is also a serving decision. Text-level optimization keeps most of the routing of shared tokens but lengthens every request, whereas continuous prompts reroute many of them, so expert placement, caches and pruning masks tuned on the base should be recomputed per adapter. Pruning by traffic alone is unsafe, since a few rarely used super experts decide whether a pruned model still answers and the adaptation decides whether it needs them. 9References

## D GEPA Prompt Examples 

Inspection of the frozen instructions in the GEPA sweep found that examples from GEPA’s validation data were sometimes copied directly into the prompt. This observation concerns the optimizer’s validation examples, not evidence of overlap with the held-out test set. Below is the full 𝑛 = 200 instruction reproduced in the workshop draft, with identity terms in the quoted comments masked by asterisks. The quoted instruction is preserved verbatim. 

GEPA with 𝑛 = 200 .

Classify the supplied text for abusive or harmful language. Determine every label supported by the text itself, using context and the actual target. Do not infer intent or add labels merely because a statement is political, controversial, negative, or mentions a protected group. Apply labels independently: 

• toxicity: Use for hostile, contemptuous, demeaning, strongly antagonistic, or abusive rhetoric. This is the broad label for toxic language and often co-occurs with insult. Sarcasm, ridicule, dismissive mockery, and hostile political rhetoric can be toxic even without profanity, a threat, or a protected-identity target. 

• obscene: Use only for profanity, vulgarity, sexually explicit language, or clearly obscene wording. Rudeness, political aggression, or a non-obscene mention of sex or identity is not enough. 

• threat: Use only when the text expresses, warns of, or explicitly advocates violence, harm, or other serious retaliation against a person or group. Do not infer a threat from anger, condemnation, predictions of punishment, saying someone deserves to suffer, proposing legal consequences, or hostile language without an actual intention or warning of harm. 

• insult: Use for a direct or clearly implied derogatory characterization of a person, group, audience, institution, or their conduct, including name-calling, belittling comparisons, ridicule, or commands to leave. Words such as “stupid,” “ridiculous,” “childish,” “incompetent,” “over his head,” “do nothing,” or similar contemptuous descriptions can qualify when directed at a person, group, argument, or institution. A hostile political characterization can therefore receive both toxicity and insult. Mere disagreement, factual criticism, or a negative policy assessment without belittling language is not automatically an insult. 

23 • identity_attack: Use only when hostility, degradation, exclusion, dehumanization, or denial of equal acceptance/treatment is directed at a protected identity or explicitly because of that identity (for example race, ethnicity, nationality, religion, sex, gender identity, or sexual orientation). Mentioning an identity, discussing discrimination, or criticizing beliefs, conduct, institutions, or policies is not by itself an identity attack. Calling someone “******,” “****-*******,” or similar is generally an accusation about conduct or beliefs, not an attack on the person’s protected identity. Political affiliation and ideological disagreement are not protected-identity attacks. Decision guidance: 1. Judge the wording and target, not whether the underlying political or factual claim is correct. 2. Broad or indirect hostile rhetoric can still be toxic. Political mockery aimed at a politician, party, legislature, or audience is not exempt. 3. Use insult when the wording belittles or ridicules a discernible target. An insult may target an argument or institution as well as an individual. 4. Toxicity and insult commonly apply together when contemptuous language is used. Toxicity may apply without insult when the hostility is general or lacks a clear derogatory characterization. 5. Do not label threat unless there is an actual threat, explicit call for harm, or expressed intention/warning of serious retaliation. 6. Do not label identity_attack merely because protected-category terms appear, or because the text accuses someone of prejudice. 7. Do not overread mild sarcasm, institutional criticism, or a hypothetical policy proposal as abuse when it contains no clearly degrading or hostile characterization of a target. Calibration: 

• “Stupid publicity stunt by another do nothing legislature.” → toxicity and insult: “stupid” and “do nothing” are contemptuous characterizations of the legislature. 

• “The idea ... is ridiculous. Anyone who uses this fallacious argument makes themselves look stupid.” →

toxicity and insult: the argument and its users are belittled. 

• “I would have thought that a new Brian Mulroney wing at a federal penitentiary (for wayward politicians) ... would be more appropriate. I’m certain that it would fill up fast.” → no labels: sarcastic political commentary/hypothetical institutional criticism, without sufficiently direct abusive language under this task’s calibration. 

• “There is no scientific evidence ... That is to be expected since there is none.” → no labels: criticism or assertion without abusive language. 

• “Trump is in way over his head ... his childish bluster.” → toxicity and insult: direct political mockery and belittling characterization. 

• “As long as you’re a ****** ... He deserves to suffer and no jury would deny him that.” → toxicity only unless other wording independently supplies a label: “******” is an accusation, and wishing or predicting suffering/legal punishment is not by itself a threat. 

• “BDS ... ****-******* and ****** ... crawl back in your cave.” → toxicity and insult; the accusations alone are not identity_attack, while “crawl back in your cave” is an insulting command. Return only the labels selected by the fixed output contract; if none apply, return NONE. Never provide an explanation.

E.5 Expert-parallel timing 

Each of 𝑁 GPUs holds 𝐸 /𝑁 consecutive experts of every MoE layer and a batch of tokens. A layer is one real expert-parallel forward: an all-to-all that sends every token to the devices of its selected experts, a grouped matrix product over the local experts (SwiGLU, the real expert shapes, random weights), and an all-to-all back. Its time is the slowest device’s, and a step is the sum over layers. Each token draws its 𝑘 distinct experts per layer from the arm’s measured expert shares over every routed position from the measured routing maps, so the per-device load follows the arm’s own load. The timing covers the MoE layers only, without attention or a serving framework, and is not an end-to-end latency. At 4096 tokens per device, where compute dominates, the base’s own imbalance costs more the fewer experts each device holds, and the adapted arms stay within 6 percent of the base on two and four devices and within 14 percent on eight (Table 20); at 512 tokens per device fixed costs dominate and every adapted arm lies within 6 percent of the base at every device count.

E.7 Replaying routing decisions 

We replay cached routes between the frozen Qwen base and the prompt- and prefix-tuned arms at 500 virtual tokens, in both directions, on the 2000 test rows. Each model first generates natively (greedy, at most 64 tokens), and its routes after top-𝑘 selection are cached in every layer. The recipient then generates again with the donor’s routes substituted at the prefill positions of the user turn, whose token IDs are identical in both models and checked; every other position, every hidden state and every decoding step remain the recipient’s own. GEPA changes the user turn itself and is not replayed. Three replays separate the terms of (5): support takes the donor’s expert set with the recipient’s own router weights renormalised over it, coefficients keeps the recipient’s set with weights from the donor’s router logits, and joint takes both. A matched random control replaces, per token and layer, exactly as many of the recipient’s experts as the donor’s set differs by, with experts drawn at random, and a shuffled control replays the joint routes of another test row of the same token geometry (1764 rows have one). Replaying a model’s own routes reproduces its native answers on every row. On these tokens the adapted arm replaces 21 (prompt) and 22 (prefix) percent of the base’s top-8 experts, changes at least one of them for 87 and 90 percent of tokens and layers, and the first-ranked one for 37 and 40 percent. The base trails the arms by 0 .373 and 0 .348 𝐹 1 (0 .459 against 0 .832 and 0 .807 in this evaluation). Replaying the arm’s routes into the base closes none of this gap for prompt tuning and 0 .034 of it for prefix tuning, where the coefficients alone give 0 .031 (Table 21). The expert set alone moves 𝐹 1 no more than the matched random control; paired against that control, the joint replay is higher by 0 .011 [0.001 , 0.021 ] and 0 .020 [0.009 , 0.030 ].Given the base’s routes, the adapted arms lose 0 .014 and 0 .023, against 0 .015 and 0 .010 for the matched random control. The shuffled routes, which differ from the recipient’s in more of their experts (38 and 39 percent), cost the adapted arms 0 .24 and 0 .39 and the base 0 .06. Within this scope the rerouting of the user tokens carries little of the adaptation gain on its own, and undoing it costs about what any change of its size costs. The replay acts on the prefill of the user turn only and leaves states and decoding to the recipient, so it does not show that routing is unnecessary for the adaptation, nor that the remaining state change suffices.
